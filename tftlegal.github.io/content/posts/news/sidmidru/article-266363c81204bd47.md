# aws terraform external-secret module

## Краткое содержание

Текст описывает Terraform-модуль для настройки AWS External Secret в EKS.  
Код модуля находится по пути `/infra-code/terraform_modules/aws_eks_external_secret`, где есть `external_secret.tf` и `variable.tf`.  
Модуль вызывается из проекта `/infra-code/projects/swt/aws-ohio/eks-infra-app.tf`.  
Для применения конфигурации предлагается выполнить `terraform apply --target module.external_secret`.  
В конце указана ссылка на исходную статью о Terraform-модуле для AWS external secret.
