# Proxmox Virtual Environment V3.0 with VM Template and Cloning Feature Released

## Краткое содержание

24 мая 2013 года Proxmox Server Solutions представила версию Proxmox VE 3.0 — открытой платформы виртуализации серверов на базе Debian 7.0 с поддержкой KVM и контейнеров.
Главное нововведение версии — функция шаблонов и клонирования виртуальных машин, позволяющая быстро создавать linked или полные клоны.
Клонирование помогает администраторам экономить время и дисковое пространство при развертывании виртуальных машин.
В Proxmox VE 3.0 Apache2 заменен новым событийным API-сервером pveproxy, который поддерживает HTTP keep-alive.
Добавлен bootlog daemon, позволяющий просматривать журнал загрузки через веб-интерфейс.
Proxmox VE 3.0 доступна для бесплатной загрузки, а компания также предлагает платную техническую поддержку.

## Полная статья

**VIENNA - May 24, 2013 -**Proxmox Server Solutions GmbH, developer of the open source server virtualization platform Proxmox Virtual Environment (Proxmox VE), today announces the release of version 3.0. The new version of the KVM and container-based virtualization solution is based on actual Debian 7.0 (Wheezy) and integrates VM template and cloning. Another major milestone of Proxmox VE 3.0 is the new event driven API server replacing Apache2. This new API server allows efficient support for HTTP keep-alive. The added bootlog daemon enables users to view the boot log on the GUI.

**VM Templates and Cloning**

Proxmox VE 3.0 integrates VM template and cloning feature, enabling administrators to easily generate their own VM template and clone it as often as they like in a couple of clicks. Two cloning modes are available: Linked and full clone. A linked clone VM requires only little disk space and stays connected to the base VM template. A full clone VM is a complete copy and is fully independant to the original VM or VM Template. The cloning feature enables enterprises a flexible and efficient deployment of VMs, saving administrating time and storage space.

**New event driven API server with support for HTTP keep-alive**

Proxmox VE 3.0 completely replaces Apache2 with a new event driven API server (pveproxy). This allows efficient support for HTTP keep-alive.
