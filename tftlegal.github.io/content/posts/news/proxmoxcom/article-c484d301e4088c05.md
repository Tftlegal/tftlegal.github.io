# Proxmox Mail Gateway 3.0: New Version integrates Commtouch Spam and Virus Security

## Краткое содержание

Proxmox Server Solutions выпустила версию Proxmox Mail Gateway 3.0, защищающую почтовые серверы от спама, вирусов, троянов и фишинга. В новом релизе добавлена интеграция двух антивирусных движков: ClamAV и облачной технологии Commtouch Zero-Hour Virus Outbreak Protection. Такое сочетание обеспечивает как традиционное сигнатурное сканирование, так и быстрое облачное обнаружение угроз без сигнатур. Продукт поддерживает высокодоступный кластер, веб-интерфейс управления и центр отслеживания сообщений, что упрощает администрирование. Установка возможна на физический сервер или в виртуализированной среде, включая Proxmox VE, VMware, Hyper-V, KVM и другие. Лицензия на один домен и неограниченное число пользователей начинается с 299 евро в год и включает обновления, поддержку и полный набор функций.

Download this press release in PDF in[English](https://www.proxmox.com/images/proxmox/press/Proxmox-Mail-Gateway-3-0_Commtouch-partnership.pdf)and[German](https://www.proxmox.com/images/proxmox/press/Proxmox-Mail-Gateway-3-0_Commtouch-Partnerschaft.pdf).

**VIENNA - August 3, 2012**– Proxmox Server Solutions GmbH, provider of network security and virtualization software, released a new version of their anti-spam and antivirus software Proxmox Mail Gateway this week. With version 3.0, Commtouch‘s high-performance services complement the antispam/antivirus stack (Spamassassin/ClamAV) used in Proxmox Mail Gateway.

„Proxmox Mail Gateway 3.0 now integrates two Anti-Virus Engines: ClamAV and Commtouch’s Zero-Hour Virus Outbreak Protection,“ explains Martin Maurer, CEO of Proxmox. „By integrating these two engines our customers benefit from a traditional, signature-based and high-performance virus detection as well as from the cloud-based and immediate signature-less Commtouch scanning.“

Proxmox Mail Gateway 3.0 enables businesses and individuals to protect their email servers against spam, viruses, trojans and phishing emails. The Proxmox High Availability (HA) Cluster consists of a master and several nodes. Configuration and data is synchronized to all cluster nodes over a VPN tunnel which provides high availability, high performance and a fully redundant data store. The web-based and user friendly management allows IT administrators to easily overview and control all functions. An innovative Message Tracking Center merges all available logs of the email traffic. No more puzzling over the question: Where is my email?

Installation of the Proxmox Mai Gateway 3.0 can easily be done in a couple of minutes with bare-metal (CD or USB) or by using a virtualization platform like Proxmox VE, VMware vSphere, Hyper-V, KVM, OpenVZ, Virtual box, Citrix XenServer, etc.. Linux Kernel (3.2) contains Vmware tools, Hyper-V integration services and paravirtualised drivers for Xen and KVM (virtio).

Proxmox Mail Gateway 3.0 can be downloaded as an ISO-Image-Download at[http://www.proxmox.com/downloads](https://www.proxmox.com/downloads)

The new Dual Virus Scanning functionality is delivered with Proxmox Mail Gateway Version 3.0 and license price starts at 299,- euros for a year for one email domain and unlimited users. This includes one year support, software updates, two Anti-Virus Engines (Commtouch Zero-Hour Virus Outbreak Protection and ClamAV), cloud-based Commtouch Recurrent Pattern Detection (RPD™) and GlobalView™ Mail Reputation Service and the complete feature set. Avira SAV is available as an additional virus scanner, with a license-per-user model.
