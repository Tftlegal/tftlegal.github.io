# Proxmox Backup Server (beta) released

## Краткое содержание

Proxmox Server Solutions представила первую бета-версию Proxmox Backup Server — открытого решения для резервного копирования серверов.  
Программа делает резервные копии и восстанавливает виртуальные машины, контейнеры и физические хосты.  
Решение оптимизировано для платформы Proxmox Virtual Environment и позволяет безопасно резервировать и реплицировать критичные данные.  
Поддерживаются инкрементальные бэкапы, дедупликация, сжатие и клиентское аутентифицированное шифрование.  
Сервер написан на Rust, что обеспечивает безопасность кода, высокую производительность и низкое потребление ресурсов.  
Управление осуществляется через веб-интерфейс и командную строку, а интеграция с Proxmox VE выполняется добавлением хранилища как цели резервного копирования.  
Beta-версия распространяется под лицензией GNU AGPL v3 и доступна для загрузки на сайте Proxmox.

](#wk-102)**VIENNA, Austria – July 10, 2020 –**Proxmox Server Solutions GmbH has announced today the first beta version of its brand new open-source server backup solution. The Proxmox Backup Server is an enterprise backup software that backups and restores virtual machines, containers, and physical hosts. Specially optimized for the open-source virtualization platform Proxmox Virtual Environment the client-server backup software allows to securely backup and replicate business critical data.

Proxmox Backup Server supports incremental backups, data deduplication, compression, and authenticated encryption. As implementation language, Proxmox uses Rust which guarantees a safe, high quality code base as well as high performance and low resource usage. Featuring strong encryption done on the client side, the Proxmox Backup Server allows users to backup data to not fully trusted targets.

The centrally managed software stack is quickly installed with the installation wizard known from other Proxmox products. With an intuitive web-based user interface and a command line it provides easy administration of all backup and restore jobs. Proxmox Backup Server seamlessly integrates into Proxmox VE – users just need to add the storage for the Proxmox Backup Server as a new storage backup target to Proxmox VE.
