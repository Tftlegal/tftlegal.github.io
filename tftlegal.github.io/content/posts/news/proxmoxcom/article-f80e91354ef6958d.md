# Proxmox expands enterprise storage options with Everpure FlashArray

## Краткое содержание

5 ноября 2026 года Proxmox Server Solutions объявила, что компания Everpure вошла в экосистему партнёров Proxmox в качестве официального Solution Provider. Высокопроизводительные всефлеш-массивы Everpure FlashArray теперь поддерживают Proxmox Virtual Environment по протоколам iSCSI, Fibre Channel, NVMe/TCP и NFS, обеспечивая централизованное общее хранилище для виртуальных машин и контейнеров. Интеграция позволяет использовать встроенные механизмы высокой доступности и live migration Proxmox VE без необходимости копирования дисков при перемещении виртуальных машин между узлами. Существующие клиенты FlashArray могут перейти на Proxmox VE без замены инфраструктуры хранения, а пользователи Proxmox получают официально поддерживаемый вариант всефлеш-накопителя. Руководство обеих компаний подчёркивает, что партнёрство расширяет выбор архитектур, снижает риски и повышает отказоустойчивость решений. Proxmox VE — открытая платформа, объединяющая KVM-виртуализацию, LXC-контейнеры, программно-определяемое хранилище и сетевые функции, — обслуживает более 2,3 млн хостов по всему миру.

## Полная статья

**VIENNA, Austria – November 05, 2026**– Enterprise software developer Proxmox Server Solutions today announced that Everpure, the company revolutionizing storage and data management, has joined the partner ecosystem as an official[Proxmox Solution Provider](https://www.proxmox.com/en/partners/find-partner/all/partner/everpure). Proxmox Virtual Environment is supported across the full Everpure FlashArray™ family of high-performance and efficient all-flash storage arrays, enabling organizations to run their virtualized workloads on Proxmox VE with FlashArray as their enterprise storage. This partnership provides customers with more choice, simplified operations, reduced risk, and enhanced business resiliency.

Everpure FlashArray delivers centralized shared storage for Proxmox VE clusters over iSCSI, Fibre Channel, NVMe/TCP, or NFS, supporting both virtual machines and containers. FlashArray will integrate directly with Proxmox VE, so the platform’s built-in high availability and live migration work seamlessly, with virtual machines moving between nodes without copying their disks.

Existing FlashArray customers can adopt Proxmox VE without replacing their storage infrastructure, while Proxmox VE users gain an officially supported all-flash storage option for their clusters.

“Choice in how customers architect virtualized and containerized workloads is only valuable if it comes with enterprise-grade reliability,” said Craig Robertson, AVP, Partners, EMEA & LatAm, Everpure. “Our partners will be able to design Proxmox VE solutions on FlashArray with confidence, using an architecture that fits each customer’s business needs and strategy.”

“Our solution partner ecosystem continues to grow, and with it the trust enterprises place in Proxmox VE,” said Thomas Lamprecht, CTO of Proxmox. “With Everpure, we welcome one of the best-known names in all-flash storage as a solution partner. Official support across the full FlashArray family allows organizations moving to Proxmox VE to retain their existing storage and the operational practices built around it.”
