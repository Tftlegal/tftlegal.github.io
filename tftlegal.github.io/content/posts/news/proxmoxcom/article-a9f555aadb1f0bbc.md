# Proxmox and Lightbits partner on native storage integration for Proxmox VE

## Краткое содержание

29 октября 2026 года Lightbits Labs, изобретатель протокола NVMe over TCP, объявила о вступлении в экосистему партнёров Proxmox в статусе официального Solution Provider. Благодаря нативному плагину Lightbits интегрируется с Proxmox VE, предоставляя высокопроизводительное блочное хранилище по NVMe/TCP на стандартных серверах с использованием существующей Ethernet-сети. Администраторы могут создавать, изменять, делать снапшоты и откатывать диски виртуальных машин прямо из интерфейса Proxmox VE без ручной настройки LVM или iSCSI. Функции live migration и high availability работают «из коробки», поскольку хранилище доступно всем узлам кластера. Решение ориентировано на чувствительные к производительности нагрузки — базы данных, аналитику и AI — и не требует Fibre Channel SAN или специализированного оборудования. Хранилище масштабируется независимо от узлов Proxmox VE, а репликация между узлами обеспечивает доступность данных при сбоях дисков или узлов.

## Полная статья

**VIENNA, Austria – October 29, 2026 –**Enterprise software developer Proxmox Server Solutions today announced that Lightbits Labs, inventor of the NVMe® over TCP storage protocol and Inferra™, an intelligent KV cache orchestration engine, has joined the Proxmox partner ecosystem as an official Solution Provider. Through a native storage plugin, Lightbits software-defined block storage integrates directly with Proxmox Virtual Environment, providing high-performance storage over NVMe/TCP on standard servers, using the Ethernet network already in place.

Administrators can create, resize, snapshot, and roll back virtual machine disks on Lightbits storage directly from Proxmox VE, without manual LVM or iSCSI setup. With shared access from all cluster nodes, built-in Proxmox VE features such as live migration and high availability work without additional configuration.

Proxmox VE environments running performance-sensitive workloads such as databases, analytics, or AI gain a high-performance block storage option that requires no Fibre Channel SAN or specialized hardware. Storage scales independently of the Proxmox VE nodes, and replication across storage nodes keeps volumes available in the event of drive or storage node failures.

Organizations already running Lightbits can now connect their existing storage clusters to Proxmox VE, while Proxmox VE users can choose Lightbits as storage for workloads where consistent low latency is essential.

“Proxmox VE users are choosing open, efficient infrastructure, and they expect the same from their storage,” said**Roiy Zysman, Director of Product Management at Lightbits Labs**. “With the native plugin, a Proxmox VE cluster gets the performance and resilience of NVMe over TCP block storage on the servers and network it already has, managed from the Proxmox VE interface. Becoming a Proxmox Solution Provider confirms that the integration meets Proxmox’s standards, and we look forward to serving the Proxmox community together.”

“Proxmox VE supports a wide range of storage technologies, so organizations can build their infrastructure the way it best suits them,” said**Tim Marx, COO of Proxmox Server Solutions**. “Lightbits extends this range with a natively integrated option for performance-sensitive workloads, available to existing Lightbits users and Proxmox VE users alike.”
