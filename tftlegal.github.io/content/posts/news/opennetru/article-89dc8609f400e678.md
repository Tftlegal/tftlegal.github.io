# Выпуск операционной системы Solaris 11.4 SRU95

## Краткое содержание

Oracle выпустила обновление Solaris 11.4 SRU 95.
Оно содержит ряд важных изменений и улучшений для ветки Solaris 11.4.
Для установки предложенных исправлений достаточно выполнить команду 'pkg update'.
Пользователи также могут воспользоваться бесплатной редакцией Solaris 11.4 CBE.
Эта редакция развивается по модели непрерывного выпуска новых версий.

## Полная статья

Компания Oracle[опубликовала](https://blogs.oracle.com/solaris/announcing-oracle-solaris-11-4-sru95-sru)выпуск операционной системы[Solaris 11.4 SRU 95](https://support.oracle.com/knowledge/Sun%20Microsystems/2433412_1.html)(Support Repository Update), в котором предложена серия значительных изменений и улучшений для ветки[Solaris 11.4](https://www.opennet.ru/opennews/art.shtml?num=49192). Для установки предложенных в обновлении исправлений достаточно выполнить команду 'pkg update'. Пользователи также могут[воспользоваться](https://www.opennet.ru/opennews/art.shtml?num=64963)бесплатной редакцией Solaris 11.4 CBE (Common Build Environment), развиваемой с использованием модели непрерывной публикации новых версий.

Среди изменений в новой версии:

- В команде "zpool monitor" реализована поддержка выбора нескольких[провайдеров](https://docs.oracle.com/en/operating-systems/solaris/oracle-solaris/11.4/manage-zfs/monitoring-zfs-pool-operations.html)(отслеживаемых подсистем, таких как send, receive, destroy, scrub и resilver) и задания провайдера по умолчанию.
- Добавлена возможность использования формата CTF (Compact C Type Format) с таблицей отладочных символов .SUNW_ldynsym для вывода информации о типах и именах функций.
- В компоновщик ld добавлена опция "-zrelax=relocfit" и флаг DF_SUNW_RELAX_RELOCFIT для ELF-файлов, включающие гибкий режим упаковки перемещений адресов (relocation).
- Обновлены версии программ, среди которых Ansible Core 2.21.1, Apache HTTP Server 2.4.67, BIND 9.20.23, Erlang 28.5.0.2, Firefox 140.10.0esr, Go 1.25.11, MySQL 8.4.10, OpenSSH 10.4p1, Rust 1.96.0, SQLite 3.53.2, Vim 9.2.0513.
- Устранены уязвимости в 7-Zip, Ansible Core, Apache HTTP Server, Apache Tomcat, BIND, Django, Elixir, Erlang, Firefox, Thunderbird, Go, GnuTLS, ImageMagick, libarchive, libexpat, libgcrypt, libsodium, MySQL, NSS, OpenSSH, Rust, SQLite, Squid, Vim и Wireshark, GNOME , Avahi, curl, libtiff, Memcached, Net-SNMP, ProFTPD, CUPS, jq, Kerberos, Node.js, Perl, Python, Samba и компонентах стека X11.
