## Полная статья

Опубликован выпуск[Issuerd 0.1.17](https://github.com/issuerd/issuerd)- сервера управления идентификацией и доступом (IAM), реализующего протоколы OpenID Connect и OAuth 2.x и совместимого с платформой[Keycloak](https://www.keycloak.org/)на уровне модели данных и управляющего REST API. Реализованы SSO, MFA (TOTP, WebAuthn/passkeys), федерация пользователей из LDAP и Kerberos/SPNEGO, вход через внешних провайдеров идентификации (OIDC, соцсети), страницы входа с настраиваемым оформлением и локализацией, декларативная первоначальная конфигурация из YAML при первом запуске. Сервер написан на Rust (unsafe-код запрещён на уровне атрибутов),[распространяется](https://github.com/issuerd/issuerd)под лицензией Apache 2.0 и поставляется одним самодостаточным бинарным файлом, в который встроены административная консоль и консоль пользователя. Сборки формируются для платформ Linux, Windows и macOS (amd64 и arm64).

Ключевая особенность проекта - непрерывная проверка соответствия официальному набору тестов OpenID Foundation Conformance Suite (5.3.2). Тестирование проводится в CI для каждого релиза в изолированном docker-окружении. Помодульные результаты хранятся в[репозитории](https://github.com/issuerd/issuerd/tests/conformance/COVERAGE.md), а полный пакет отчётов прикладывается к каждому релизу. Паритет с Keycloak контролируется набором тестов. В планах прохождение официальной сертификации.

Из протоколов, востребованных в сценариях с AI-агентами, реализованы DPoP (RFC 9449, привязка токена к ключу предъявителя), обмен токенами (RFC 8693, сужение полномочий при обмене токена) и CIBA (режим poll, подтверждение действий человеком). Также поддерживаются PAR (RFC 9126), JAR (RFC 9101), JARM, RAR (RFC 9396), динамическая регистрация клиентов (RFC 7591/7592), авторизация устройств (RFC 8628). Полный импорт 100 тысяч пользователей из MS Active Directory занимает около 30 секунд.
