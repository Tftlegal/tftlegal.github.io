# Релиз Chrome 155 c включением режима HTTPS-First и поддержки формата JPEG XL

## Краткое содержание

Google выпустила веб-браузер Chrome 155, одновременно ставший доступным и стабильный релиз свободного проекта Chromium, на котором он основан. Chrome отличается от Chromium наличием логотипов Google, модулей DRM, системы автообновлений, постоянной Sandbox-изоляции, ключей к Google API и передачей RLZ-параметров при поиске. Для пользователей, которым нужно больше времени на обновление, поддерживается отдельная ветка Extended Stable в течение 8 недель. Следующий выпуск — Chrome 156 — запланирован на 20 октября в рамках нового двухнедельного цикла разработки.

## Полная статья

Компания Google[опубликовала](https://chromereleases.googleblog.com/2026/10/stable-channel-update-for-desktop_086471744.html)релиз web-браузера[Chrome 155](http://www.google.com/chrome). Одновременно доступен стабильный выпуск свободного проекта[Chromium](http://dev.chromium.org/), выступающего основой Chrome. Браузер Chrome[отличается](https://chromium.googlesource.com/chromium/src/+/master/docs/chromium_browser_vs_google_chrome.md)от Chromium использованием логотипов Google, наличием системы отправки уведомлений в случае краха, модулями для воспроизведения защищённого от копирования видеоконтента (DRM), системой автоматической установки обновлений, постоянным включением Sandbox-изоляции, поставкой ключей к Google API и передачей[RLZ-параметров](https://www.opennet.ru/opennews/art.shtml?num=26822)при поиске. Для тех, кому необходимо больше времени на обновление, отдельно поддерживается ветка Extended Stable, сопровождаемая 8 недель. Следующий выпуск Chrome 156 в рамках нового[двухнедельного](https://www.opennet.ru/opennews/art.shtml?num=64907)цикла разработки запланирован на 20 октября.

Основные изменения в Chrome 155 ([1](https://chromeenterprise.google/resources/release-notes/),[2](https://developer.chrome.com/en/blog/),[3](https://blog.google/products-and-platforms/products/chrome/),[4](https://developer.chrome.com/release-notes/)):

- Для всех пользователей по умолчанию включена функция "HTTPS-First", выполняющая автоматическое перенаправление HTTP-запросов на HTTPS для публично доступных сайтов, размещаемых не в интранет сетях, таких как 192.168.0.1/16 и 10.0.0.0/8. Для обеспечения работы с сайтами, не поддерживающими HTTPS, реализован откат на HTTP, если после перенаправления не удаётся выполнить запрос по HTTPS или возникают проблемы с сертификатами. При попытке открытия сайта по HTTP выводится специальное предупреждение.
- [Включена](https://developer.chrome.com/blog/jpeg-xl-in-chrome?hl=en)по умолчанию поддержка декодирования изображений в формате JPEG XL. Реализация[основана](https://github.com/mozilla/standards-positions/pull/1064)на библиотеке[jxl-rs](https://github.com/libjxl/jxl-rs), написанной на Rust. JPEG XL позволяет добиться уменьшения размера файлов на 30-50% по сравнению с изображениями JPEG идентичного качества. Среди поддерживаемых расширенных возможностей: HDR, анимация, прозрачность, режим прогрессивной загрузки, плавное ухудшение качества при уменьшении битрейта, сжатие JPEG без потерь, поддержка до 4099 каналов и большой диапазон глубин цвета.
- Изменено визуальное оформление интерфейса для создания профилей (функциональность осталась прежней). Для платформы Windows добавлен новый этап ознакомления с созданием профилей, показываемый при первом запуске браузера (для Linux и macOS он появится в версии Chrome 158).[

- На странице chrome://extensions в меню управления дополнениями добавлен пункт для выставления оценок и написания рецензии на установленные дополнения, который при нажатии перебрасывает на соответствующие страницы в каталоге Chrome Web Store.[

- [Реализовано](https://chromestatus.com/feature/5082950457884672)полномочие media-playback-while-not-visible, позволяющее блокировать воспроизведение звука и видео внутри встроенных iframe-ов, когда они не находятся в зоне видимости.
- Добавлено CSS-свойство[margin-trim](https://drafts.csswg.org/css-box-4/#margin-trim), позволяющее избавиться от отступов перед первым и после последнего элемента внутри родительского контейнера.
- Добавлено CSS-свойство[text-decoration-skip-spaces](https://chromestatus.com/feature/4832783806627840), управляющее отображением декораторов (подчёркивание или зачёркивание) под пробелами в тексте.
- Добавлена CSS-функция[symbols()](https://drafts.csswg.org/css-counter-styles-3/#symbols-function)для упрощения настройки использования нестандартных маркеров в списках.
- В API[WebCrypto](https://wicg.github.io/webcrypto-modern-algos)добавлена поддержка криптоалгоритмов, стойких к подбору на квантовых компьютерах - ML-KEM и ML-DSA, а также алгоритмов ChaCha20-Poly1305 и X-Wing.
- В API[Window Management](https://www.w3.org/TR/window-management/#api-window-minimize-method)добавлены новые методы управления окном: maximize(), minimize() и restore() для раскрытия окна на весь экран, сворачивания или восстановления прежнего размера. Также добавлен метод setResizable() для управления возможностью вручную изменять границы окна. В CSS добавлены медиазапросы display-state и resizable, позволяющие определить свёрнуто или развёрнуто окно, и может ли окно менять размер.
- [Добавлены](https://chromestatus.com/feature/5122501071994880)новые встроенные цветовые пространства (PredefinedColorSpace) - srgb-linear и display-p3-linear.
- [Добавлена](https://chromestatus.com/feature/5191512456560640)поддержка текстовых модулей, импортируемых при помощи конструкции 'import ... with { type: "text" }'.

Кроме нововведений и исправления ошибок в новой версии устранено[247 уязвимостей](https://issues.chromium.org/issues?q=customfield1223088:0-M155). 4 проблемам присвоен критический уровень опасности, подразумевающий, что уязвимости позволяют обойти все уровни защиты браузера и выполнить код в системе за пределами sandbox-окружения. Все критические проблемы вызваны обращением к уже освобождённой памяти (use-after-free).
