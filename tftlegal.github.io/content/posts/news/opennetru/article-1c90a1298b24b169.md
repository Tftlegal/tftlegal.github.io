# В Ubuntu добавят интегрированный с рабочим столом AI-ассистент

## Краткое содержание

Разработчики Ubuntu анонсировали новое приложение — Ubuntu Launcher. Оно объединит в одном интерфейсе работу с приложениями, локальным контекстом и AI-ассистентом, заменив разрозненные AI-виджеты и утилиты. AI-функции будут реализованы как опциональные, которые пользователь может включить по желанию. В базовом режиме программа будет работать как обычный быстрый лаунчер. Таким образом, Ubuntu намерена предложить гибкое решение: от простого инструмента запуска до полноценной AI-интегрированной среды.

## Полная статья

Разработчики дистрибутива Ubuntu[анонсировали](https://discourse.ubuntu.com/t/beyond-a-launcher-a-new-way-to-interact-with-ubuntu/92365)работу над новым приложением Ubuntu Launcher, которое будет включать функциональность AI-ассистента. Вместо разрозненных AI-приложений и виджетов планируется предоставить пользователям единый интерфейс для взаимодействия с системой, связывающий приложения, локальный контекст и AI-ассистента. Функции, реализованные с привлечением AI, будут предложены в форме включаемой по желанию опции, а в базовом варианте программу можно будет использовать как просто быстрый лаунчер.

Ubuntu Launcher отображается поверх содержимого и позволяет выполнять как команды на естественном языке, так и предопределённые операции, например, поиск файлов, поиск и запуск приложений, вставка emoji и просмотр истории работы с буфером обмена. Заявлена возможность управления как с клавиатуры, так и через голосовой ввод. В настоящее время для тестирования в каталоге Snap доступен прототип[warty-prototype](https://snapcraft.io/warty-prototype), который представляет собой лишь симулятор для оценки макета интерфейса, созданный для начальной обкатки концепции. Первую рабочую тестовую версию планируют опубликовать в январе.

Задействованные во встроенном AI-ассистенте AI-модели будут выполняться только на системе пользователя без отправки данных в облачные сервисы. Процессы AI-сервисов будут изолированы от остальной системы и при доступе к системным ресурсам или данным потребуют подтверждения операций пользователем. Среди ключевых целей разработки отмечается быстрый запуск, низкое потребление ресурсов, бесшовная интеграция со средой рабочего стола и простота выполнения повседневных задач.
