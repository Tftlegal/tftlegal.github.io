# Microsoft опубликовал открытую платформу .NET 11

## Краткое содержание

Microsoft представила открытую платформу .NET 11, созданную путём объединения .NET Framework, .NET Core и Mono. На её основе можно разрабатывать многоплатформенные приложения для браузера, облака, десктопа, IoT и мобильных устройств. Для всех типов приложений используются единые библиотеки и общий процесс сборки. Сборки .NET SDK, .NET Runtime и ASP.NET Core Runtime доступны для Linux, macOS и Windows, тогда как .NET Desktop Runtime поставляется исключительно для Windows. Все наработки проекта распространяются под лицензией MIT.

## Полная статья

Компания Microsoft[представила](https://devblogs.microsoft.com/dotnet/announcing-dotnet-11/)выпуск открытой платформы[.NET 11](https://github.com/dotnet/core/tree/main/release-notes/11.0), созданной благодаря унификации продуктов .NET Framework, .NET Core и Mono. На основе .NET 11 можно создавать многоплатформенные приложения для браузера, облачных систем, рабочего стола, IoT-устройств и мобильных платформ, используя единые библиотеки и общий процесс сборки, не зависящий от типа приложения. Сборки .NET SDK 11, .NET Runtime 11 и ASP.NET Core Runtime 11[сформированы](https://dotnet.microsoft.com/download/dotnet/11.0)для Linux, macOS и Windows. .NET Desktop Runtime 11 поставляется только для Windows. Связанные с проектом[наработки](https://github.com/dotnet/runtime)[распространяются](https://github.com/dotnet/sdk)под лицензией MIT.

В состав .NET входит[Runtime](https://github.com/dotnet/runtime)с JIT-компилятором RyuJIT,[спецификации API](https://docs.microsoft.com/en-us/dotnet/standard/net-standard), библиотеки[WPF, Windows Forms, WinUI](https://www.opennet.ru/opennews/art.shtml?num=49718)и[Entity Framework](https://learn.microsoft.com/en-us/ef/), интерфейс командной строки[dotnet](https://docs.microsoft.com/en-us/dotnet/articles/core/tools/dotnet), а также[инструменты](https://github.com/dotnet/cli)для разработки микросервисов, библиотек, серверных, графических и консольных приложений. Отдельно поставляются стек для разработки web-приложений[ASP.NET Core 11.0](https://learn.microsoft.com/en-us/aspnet/core/?view=aspnetcore-11.0), ORM-прослойка[Entity Framework Core 11.0](https://learn.microsoft.com/ef/core/what-is-new/ef-core-11.0/whatsnew)(драйверы имеются, в том числе, для SQLite и PostgreSQL), библиотека[WPF 11](https://learn.microsoft.com/dotnet/desktop/wpf/whats-new/net110)(Windows Presentation Foundation), фреймворк[Windows Forms 11](https://learn.microsoft.com/dotnet/desktop/winforms/whats-new/net110)для разработки GUI, платформа[Aspire 11](https://aspire.dev/)для создания приложений Cloud Native, фреймворк[MAUI 11](https://learn.microsoft.com/dotnet/maui/whats-new/dotnet-11)для разработки многоплатформенных интерфейсов пользователя, а также выпуски языков[C# 15](https://learn.microsoft.com/dotnet/csharp/whats-new/csharp-15)и[F# 11](https://learn.microsoft.com/dotnet/fsharp/whats-new/fsharp-11). Поддержка .NET 11.0 и C# 15 включена в свободный редактор кода[Visual Studio Code](https://code.visualstudio.com/).

[Особенности](https://learn.microsoft.com/en-us/dotnet/core/whats-new/dotnet-11/overview)нового выпуска:

- В языке C# 15[добавлено](https://learn.microsoft.com/en-us/dotnet/csharp/whats-new/csharp-15)ключевое слово[union](https://devblogs.microsoft.com/dotnet/csharp-15-union-types/)для объявления типа, значение которого может быть только одним из заранее перечисленных типов-вариантов. Переменной union-типа можно присваивать значения любого из разрешённых типов, а при попытке присвоить значение типа, не указанного при объявлении, компилятор выдаст ошибку.

```

   public record class Cat(string Name);
   public record class Dog(string Name);
   public record class Bird(string Name);
 
  public union Pet(Cat, Dog, Bird);
```

Для классов предложен модификатор "closed", при помощи которого можно создавать закрытые иерархии (closed hierarchy), в которых наследование от базового класса с модификатором closed допускается только внутри той сборки, где он объявлен и на этапе компиляции известен полный набор прямых потомков. Union-типы и закрытые иерархии гарантируют, что в конструкции switch обработаны все возможные варианты, что позволяет обойтись без ветки "default" и переменной "_".

В новой версии C# также добавлена поддержка перехода из выражений "break" и "continue" на выставленные метки и расширены экспериментальные возможности по изоляции в unsafe-блоках кода, напрямую работающего с памятью (добавлена возможность применения unsafe для отдельных выражений).

- В языке F# 11[сокращено](https://github.com/dotnet/core/blob/main/release-notes/11.0/preview/rc2/fsharp.md)потребление памяти компилятором и уменьшено число операций выделения памяти при работе с коллекциями FSharp.Core. Добавлена возможность ограничения параллельно выполняемых асинхронных работ для предотвращения перегрузки. Добавлена предварительная поддержка[Runtime Async](https://learn.microsoft.com/en-us/dotnet/core/whats-new/dotnet-11/runtime#runtime-async).
- В[SDK](https://learn.microsoft.com/dotnet/core/whats-new/dotnet-11/sdk)по умолчанию включены[сервер MSBuild](https://learn.microsoft.com/dotnet/core/whats-new/dotnet-11/sdk#msbuild-server-enabled-by-default)и[предкомпилированный](https://learn.microsoft.com/dotnet/core/whats-new/dotnet-11/sdk#nativeaot-entry-point-for-the-dotnet-cli)(NativeAOT) вариант CLI-инструментария dotnet. Сокращён размер инсталляторов SDK для Linux и macOS за счёт дедупликации сборок.
- [Проведена](https://devblogs.microsoft.com/dotnet/performance-improvements-in-net-11/)оптимизация JIT-компилятора, удалены избыточные проверки границ и ветвлений, улучшена девиртуализация и расширено сворачивание операций в константы. В AOT-компиляторе задействован общий обработчик вызовов, позволивший сократить объём кода и повысить пропускную способность при интенсивном обращении к интерфейсам. Для Linux и macOS реализовано сохранение при сбоях трассировки стека и информации о модулях.
- Добавлен экспериментальный механизм[Runtime Async](https://learn.microsoft.com/dotnet/core/whats-new/dotnet-11/runtime#runtime-async)для замены генерируемого компилятором кода обработки async-операций на реализацию, управляющую приостановкой и возобновлением асинхронных операций на уровне runtime.
- В SDK[добавлен](https://learn.microsoft.com/aspnet/core/release-notes/aspnetcore-11#mcp-server-template-ships-with-the-net-sdk)шаблон сервера MCP для интеграции с AI-инструментами и сервисами. Для приложений, использующих AI-сервисы, добавлен набор абстракций[Microsoft.Extensions.AI](https://learn.microsoft.com/dotnet/ai/microsoft-extensions-ai)(MEAI). На базе этих абстракций сформирован[Microsoft Agent Framework](https://learn.microsoft.com/agent-framework/overview/agent-framework-overview)(MAF), который можно использовать для создания AI-агентов.
- В API[Process](https://learn.microsoft.com/dotnet/core/whats-new/dotnet-11/libraries#process-api-expansion)расширены возможности запуска процессов с перехватом их вывода и кодов завершения работы, а также контроля над наследуемыми дескрипторами.
- В API System.IO.Compression добавлена поддержка алгоритма сжатия Zstandard.
- [Добавлены](https://learn.microsoft.com/dotnet/core/whats-new/dotnet-11/libraries#in-memory-stream-adapters)новые адаптеры потоков ReadOnlyMemoryStream, WritableMemoryStream, ReadOnlySequenceStream и StringStream.
- Добавлена утилита[dotnetup](https://devblogs.microsoft.com/dotnet/introducing-dotnetup/)для установки и обновления SDK и runtime.
