# Выпуск программы для ведения заметок OutWiker 4.1

## Краткое содержание

Вышел новый выпуск программы для ведения заметок OutWiker 4.1.
Она хранит заметки как каталоги с текстовыми файлами и позволяет прикреплять к ним любые файлы.
Заметки можно оформлять с помощью HTML, вики-разметки или Markdown при наличии плагина.
Плагины также добавляют поддержку формул LaTeX и блоков кода с подсветкой синтаксиса.
Программа написана на Python с интерфейсом wxPython и распространяется под лицензией GPLv3.
Она доступна в сборках для Linux через snap и flatpak, а также для Windows.
