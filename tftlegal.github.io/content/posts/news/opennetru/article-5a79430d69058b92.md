# Выпуск openMERC, открытого движка для игры Soldier of Fortune

## Краткое содержание

openMERC — это открытый альтернативный движок для шутера от первого лица Soldier of Fortune (Raven Software, 2000). Код написан на C/C++ с использованием библиотеки SDL3 и распространяется под лицензией GPLv2. Методология «чистой комнаты» применялась поверх кодовой базы Yamagi Quake II. Для графики задействован OpenGL 3.2 (в Linux-сборке требуется драйвер с поддержкой OpenGL 3.3). Движок доступен для Linux, Windows и macOS. Для запуска игры необходимо установить pak-файлы из оригинальной Soldier of Fortune.

## Полная статья

Опубликован[openMERC](https://github.com/sidreshot/openMERC), альтернативный открытый движок для шутера от первого лица[Soldier of Fortune](https://ru.wikipedia.org/wiki/Soldier_of_Fortune_(%D0%B8%D0%B3%D1%80%D0%B0)), выпущенного компанией Raven Software в 2000 году. Код написан на языках C/C++ c задействованием библиотеки SDL3 с использованием методологии чистой комнаты поверх кодовой базы[Yamagi Quake II](https://github.com/yquake2/yquake2)и распространяется под лицензией GPLv2. Для графики задействован OpenGL 3.2 (Linux-сборка требует драйвер с поддержкой OpenGL 3.3). Сборки движка[подготовлены](https://github.com/sidreshot/openMERC/releases/tag/v0.2.4)для Linux, Windows и macOS. Для запуска игры требуется установка pak-файлов из оригинальной игры Soldier of Fortune.

Загружаются и рисуются все 75 штатных карт: модели Ghoul, туман, ландшафт, небо. Работают сохранения, смена уровня, консоль и выделенный сервер openMerc-ded. Меню масштабируется в зависимости от разрешения экрана, при выводе текста поддерживается латиница и кириллица. Сетевая игра возможна между клиентами и серверами openMERC, но не поддерживается с серверами и клиентами оригинальной игры. По умолчанию включены все графические эффекты, но каждый эффект можно выключить через меню "Видео".

Переписаны[19 эффектов из 41](https://github.com/sidreshot/openMERC/blob/main/docs/EFFECTS.md): динамический свет, освещённый дым, мягкие частицы, пулевые отверстия, кровь, ореол вокруг ламп, дождь и гроза, вода с отражениями и преломлением, всплески, виньетка попадания, ночное видение, контактные тени, стекло, капли на стёклах, попиксельный туман. Не переписаны огонь, огнемёт, взрывы, трассеры, вспышки выстрелов и речь персонажей.
