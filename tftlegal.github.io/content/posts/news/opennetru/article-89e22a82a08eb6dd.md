# Выпуск Lutris 0.5.23, платформы для упрощения запуска игр в Linux

## Краткое содержание

Вышел новый выпуск игровой платформы Lutris — версия 0.5.23. Платформа предназначена для упрощения установки, настройки и управления играми в операционной системе Linux. Проект написан на языке Python. Код распространяется под свободной лицензией GPLv3. Готовые сборки доступны в формате flatpak. Таким образом, пользователям Linux становится проще запускать и настраивать игровые библиотеки без лишних трудностей.

## Полная статья

[Опубликован](https://github.com/lutris/lutris/releases/tag/v0.5.23)выпуск игровой платформы[Lutris 0.5.23](https://lutris.net/), предоставляющей инструменты для упрощения установки, настройки и управления играми в Linux. Код проекта написан на языке Python и[распространяется](https://github.com/lutris/lutris)под лицензией GPLv3. Готовые сборки доступны в формате[flatpak](https://flathub.org/apps/net.lutris.Lutris).

Проектом поддерживается каталог для быстрого поиска и установки игровых приложений, позволяющий через единый интерфейс одним щелчком мыши запускать в Linux игры, не заботясь об установке зависимостей и настройках. Runtime-компоненты для запуска игр поставляются проектом и не привязываются к используемому дистрибутиву. Runtime представляет собой независимый от дистрибутива набор библиотек, включающий компоненты из SteamOS и Ubuntu, а также различные дополнительные библиотеки.

Предоставляется возможность установки игр, распространяемых через сервисы GOG, Steam, Epic Games Store, Battle.net, Amazon Games, Origin и Uplay. При этом сам по себе Lutris выступает лишь в роли посредника и не продаёт игры, поэтому для коммерческих игр пользователь должен самостоятельно приобрести игру в соответствующем сервисе (бесплатные игры можно запускать одним кликом из графического интерфейса Lutris).

Каждая игра в Lutris привязывается к сценарию загрузки и обработчику, описывающему окружение для запуска игры. Среди прочего предоставляются готовые профили с оптимальными настройками для запуска игр под управлением Wine. Кроме Wine игры могут запускаться при помощи эмуляторов игровых консолей, таких как[RetroArch](https://www.opennet.ru/opennews/art.shtml?num=53522),[Dosbox](https://www.opennet.ru/opennews/art.shtml?num=52911),[FS-UAE](https://fs-uae.net/),[ScummVM](https://www.opennet.ru/opennews/art.shtml?num=55946),[MESS/MAME](https://www.opennet.ru/opennews/art.shtml?num=43990)и[Dolphin](https://www.opennet.ru/opennews/art.shtml?num=44665).

Среди изменений в новой версии:

- Интегрирована поддержка инструментария[gogdl](https://github.com/asb/gogdl)для загрузки игр из сервиса GOG с использованием[GOG depot](https://docs.gog.com/bc-depots/)и инкрементальных обновлений, а также с возможностью установки дополнений (DLC).
- Добавлена поддержка синхронизации сохранений в играх с облаком GOG.
- Реализована возможность загрузки файлов из GOG в несколько потоков и возобновления прерванных загрузок.
- Добавлены источники загрузки игр GameJolt и DLsite.
- Добавлена поддержка импорта игр из[Playtron](https://www.playtron.one/).
- Улучшена аутентификация и обработка ошибок при использовании сервиса[Humble Bundle](https://www.humblebundle.com/). Предоставлена возможность выбора между Linux- и Windows-версииями игр при установке из Humble Bundle.
- Обеспечен показ релизов для игр Amazon.
- Реализовано автоматическое обновление просроченных токенов Epic Games без необходимости осуществления ручного повторного входа. Ускорена синхронизация библиотеки игр с каталогом Epic Games Store.
- В меню добавлена опция "Kill all Wine processes" для принудительного завершения всех процессов Wine.
- При загрузке данных и обращении к API задействованы системные настройки прокси, применяемые в KDE и GNOME.
- По молчанию обеспечена загрузка GE-Proton через прослойку[umu](https://github.com/Open-Wine-Components/umu-launcher)(Unified Linux Wine Game Launcher).
- Для GPU без поддержки Vulkan 1.3 задействован форк[DXVK Sarek](https://www.opennet.ru/opennews/art.shtml?num=63608).
- Реализована отложенная загрузка эмуляторов libretro и систем MAME.
- Ускорен запуск приложения за счёт переноса проверки GPU и сканирование библиотеки игр на более поздний этап.
- Проведена оптимизация производительности конфигураций с большим числом игр в библиотеке.
