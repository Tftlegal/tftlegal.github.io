# Доступен порт Wine для OpenBSD

## Краткое содержание

Представлен проект порта Wine — прослойки для запуска Windows-приложений — под операционную систему OpenBSD. Ключевая проблема состоит в том, что OpenBSD запрещает установку регистра gsbase из пользовательского пространства. При этом Windows-приложения активно используют данный регистр для обращения к локальной памяти потока (thread-local storage). В результате стандартный запуск Wine-приложений в OpenBSD оказывается невозможным. Для обхода этого ограничения в проекте реализована эмуляция префикса сегмента %gs в машинных командах. Таким образом, необходимость прямого записи в gsbase устраняется на уровне трансляции инструкций. Это позволяет Windows-программам корректно обращаться к потоковой памяти без модификации самой OpenBSD.
