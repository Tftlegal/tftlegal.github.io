# Репозиторий Nitter вновь переведён в архивный режим, а сервис XCancel прекратил работу

## Краткое содержание

Nitter — альтернативный интерфейс для просмотра сообщений X (Twitter) без регистрации учётной записи. После недавнего возобновления разработки репозиторий проекта снова перевели в архивный режим, а сайт вывели из строя. Схожий сервис XCancel также прекратил работу. Вместе с тем продолжают работать независимые Nitter-прокси, поддерживаемые энтузиастами. Действуют и сервисы перенаправления на рабочие прокси. Среди таких адресов — nitt.tr, twit.0r.cx и xxcancel.com.

## Полная статья

После недавнего[возобновления](https://www.opennet.ru/opennews/art.shtml?num=66222)разработки репозиторий проекта[Nitter](https://nitter.net/), развивающего альтернативный интерфейс для просмотра сообщений из социальной сети X (Twitter) без регистрации учётной записи, вновь[переведён](https://github.com/zedeus/nitter)в архивный режим, а сайт выведен из строя. Следом прекратил работу и сервис[XCancel](https://xcancel.com/), предоставляющий похожую функциональность. При этом пока[продолжают работать](https://status.d420.de/)поддерживаемые энтузиастами[независимые прокси](https://codeberg.org/mv12star/shitter/wiki/Instances)на базе платформы Nitter и сервисы перенаправления на рабочие прокси (nitt.tr, twit.0r.cx, xxcancel.com).

Проект[Nitter](https://github.com/zedeus/nitter)развивает свободный (GPLv3) фронтенд для доступа к X.com без навязывания JavaScript, аналитики, трекеров и сторонних сервисов, возвращён из архивного режима. Работа Nitter была[остановлена](https://www.opennet.ru/opennews/art.shtml?num=66138)в конце августа после получения от компании X Corp уведомления с требованием прекращения незаконной деятельности ([cease and desist](https://en.wikipedia.org/wiki/Cease_and_desist)) под угрозой предъявления судебного иска. В уведомлении утверждалось, что сервисы нарушают специфичные для отдельных штатов и федеральные законы США, включая, принятый в Техасе[Закон о вредоносном доступе к компьютерам](https://statutes.capitol.texas.gov/Docs/CP/htm/CP.143.htm)(§ 143.001 и § 33.02) и[Закон Лэнхема](https://en.wikipedia.org/wiki/Lanham_Act)о товарных знаках (15 U.S.C. §§ 1114, 1125)». Разработчикам Nitter вменялось незаконное обращение к API X.com и связанными с ними данными, а также получение доступа к учётным записям X и токенам сессий в нарушение правил сервиса.
