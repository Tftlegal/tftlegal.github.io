# Прекращена разработка Redict, консервативного форка СУБД Redis

## Краткое содержание

Дрю ДеВолт, известный создатель окружения Sway, языка Hare, почтового клиента Aerc и платформы SourceHut, объявил о списании СУБД Redict в разряд устаревших. Выпуск Redict 7.3.6, выпущенный год назад, станет последним, и дальнейшие обновления не планируются. Проект изначально ставил целью консервативное сопровождение кодовой базы без расширения функциональности. Разработчики обосновали это тем, что Redis уже достиг зрелости и обладает всеми необходимыми возможностями. Отдельно отмечается, что Redict перешёл на лицензию LGPLv3 для вносимых исправлений, тогда как исходный код остался под лицензией BSD.

## Полная статья

Дрю ДеВолт (Drew DeVault), автор пользовательского окружения Sway, языка программирования Hare, почтового клиента Aerc и платформы совместной разработки SourceHut,[объявил](https://redict.io/posts/2026-11-17-redict-deprecated/)о переводе СУБД[Redict](https://redict.io/)в разряд устаревших. Сформированный год назад выпуск[Redict 7.3.6](https://codeberg.org/redict/redict/releases/tag/7.3.6)останется последним, больше обновлений публиковать не планируют. Redict был нацелен на консервативное сопровождение кодовой базы без наращивания функциональности, так как, по мнению разработчиков, Redis достиг зрелости и содержит все необходимые возможности. Redict также примечателен переходом на использование лицензии LGPLv3 для вносимых исправлений (старый код оставался под лицензией BSD).

Проект потерял смысл после того, как Redis[перешёл](https://www.opennet.ru/opennews/art.shtml?num=63175)на свободную лицензию AGPLv3, а[Valkey](https://valkey.io/), продолживший развитие кодовой базы под лицензией BSD, продемонстрировал способность сопровождать код в долгосрочной перспективе. Дрю ДеВолт рекомендовал пользователям перейти на использование Valkey, несмотря на пермиссивную лицензию, так как несмотря на доступность кода Redis под лицензией AGPL, для передачи изменений в него требуется подписание соглашения о передаче имущественных прав на код, что не исключает очередной переход на проприетарную лицензию в будущем. Для миграции с Redict на Valkey достаточно установить пакет с Valkey и переименовать файл конфигурации из /etc/redict.conf в /etc/valkey.conf.

Изначально Redis поставлялся под разрешительной лицензией BSD, позволявшей не открывать свои изменения, после чего в 2024 году[перешёл](https://www.opennet.ru/opennews/art.shtml?num=60820)на проприетарные лицензии RSALv2 (Redis Source Available License v2) и SSPLv1 (Server Side Public License v1). В 2025 году Redis стал доступен под лицензией AGPLv3, особенностью которой является наличие ограничений для приложений, обеспечивающих функционирование сетевых сервисов. При использовании AGPL-компонентов в работе сетевых сервисов, разработчик обязан предоставить пользователю исходный код всех внесённых в эти компоненты изменений, даже если лежащее в основе сервиса программное обеспечение не распространяется и используется исключительно во внутренней инфраструктуре для организации работы сервиса.
