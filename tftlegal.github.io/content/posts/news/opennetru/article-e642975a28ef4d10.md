# XNU Linux для загрузки ядра и пользовательского окружения macOS в Linux

## Краткое содержание

Хэян Чжоу, один из создателей платформы Deno Deploy, опубликовал проект XNU Linux. Он позволяет собрать ядро XNU и загрузить его в виде модуля ядра Linux для запуска пользовательской среды macOS. XNU — гибридное ядро, входящее в открытый проект Darwin и используемое в macOS; оно сочетает микроядро Mach, подсистемы ядра FreeBSD и C++ API IOKit для написания драйверов. Благодаря загрузке XNU как модуля в Linux можно запустить штатный графический интерфейс macOS. В таком окружении работают обычные macOS-приложения, включая браузер Safari.

## Полная статья

Хэян Чжоу ([Heyang Zhou](https://su3.io/)), один из создателей платформы[Deno Deploy](https://deno.com/deploy), опубликовал проект[XNU Linux](https://github.com/AFK-surf/xnulinux), позволяющий собрать и загрузить ядро[XNU](https://github.com/apple-oss-distributions/xnu)в качестве модуля ядра Linux, и использовать его для выполнения пользовательского окружения macOS в Linux. XNU применяется в macOS, является частью открытого проекта Darwin и представляет собой гибридное ядро, сочетающее микроядро Mach, подсистемы ядра FreeBSD и C++ API IOKit для написания драйверов. Загрузив XNU как модуль ядра можно внутри Linux запустить штатное графическое окружение macOS, в котором будут выполняться приложения macOS, включая браузер Safari.

Ядро XNU собирается из предоставляемого компанией Apple исходного кода и запускается в Linux в форме модуля ядра xnu.ko, который напрямую взаимодействует с CPU и блоком управления памятью (MMU), что позволяет бок о бок на одном CPU выполнять процессы Linux и macOS без привлечения гипервизора. Для доступа ядра XNU к памяти, файлам, таймерам, обработке исключений, сети и GPU через ядро Linux создан модуль-прослойка fki.ko (Foreign Kernel Interface).

Модуль с ядром XNU работает в собственном адресном пространстве - ядро XNU получает от Linux непрерывный блок физической памяти и управляет им через свой pmap, а часть адресного пространства для пользовательских процессов используется в Linux и XNU совместно. Каждый виртуальный CPU для macOS оформлен как поток ядра Linux, закреплённый за физическим ядром CPU. Для доступа к дисковому образу с macOS, дисплею, клавиатуре, мыши, Ethernet и GPU предоставляются драйверы-прослойки. Графический API Metal реализован поверх Vulkan через прослойку[metal2vulkan](https://github.com/steelbrain/metal2vulkan).

Разработанный проектом связующий модуль ядра и сопутствующие утилиты[распространяются](https://github.com/AFK-surf/xnulinux/)под лицензией GPLv2, компоненты модуля ядра XNU поставляются под лицензией APSL-2.0, заимствованные из проекта[macOS-DroidVM](https://github.com/Droid-VM/macOS-DroidVM)драйверы XnuDisplay, XnuEthernet и XnuInput доступны под лицензией BSD. В XNU Linux также задействованы наработки проекта[UniXNU](https://github.com/UniXNU/UniXNU), позволяющего запускать macOS и iOS на ARM64-системах не от Apple. Разработка XNU Linux ведётся с использованием AI-ассистента Claude. В качестве примера продемонстрирован запуск в Ubuntu Linux системного диска с macOS, созданного инсталлятором Apple. В настоящее время поддерживается только запуск на ARM-компьютерах Apple с чипами M1 и новее.
