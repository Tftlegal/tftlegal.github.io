# За неделю после релиза загружено более миллиона копий LibreOffice 26.8

## Краткое содержание

The Document Foundation опубликовала статистику загрузок LibreOffice 26.8.
За первую неделю релиз скачали 1,031 млн раз.
Эта цифра учитывает только загрузки с официальной страницы проекта.
Пользователи дистрибутивов, которые получают LibreOffice из стандартных репозиториев, не включены в статистику.
Поэтому общее число пользователей может быть больше.
