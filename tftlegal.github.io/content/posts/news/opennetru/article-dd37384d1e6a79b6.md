# Выпуск Proxmox VE 9.3, дистрибутива для организации работы виртуальных серверов

## Краткое содержание

Вышел релиз Proxmox Virtual Environment 9.3. Это специализированный Linux-дистрибутив, построенный на базе Debian GNU/Linux. Система предназначена для развёртывания и обслуживания виртуальных серверов. В качестве технологий виртуализации используются LXC (контейнерная) и KVM (полная). Proxmox VE позиционируется как альтернатива таким коммерческим решениям, как VMware vSphere, Microsoft Hyper-V и Citrix Hypervisor. Размер установочного ISO-образа составляет 1,7 ГБ.

## Полная статья

[Опубликован](https://forum.proxmox.com/threads/proxmox-virtual-environment-9-3-released.187800/)релиз[Proxmox Virtual Environment 9.3](https://pve.proxmox.com), специализированного Linux-дистрибутива на базе Debian GNU/Linux, нацеленного на развертывание и обслуживание виртуальных серверов с использованием LXC и KVM, и способного выступить в роли замены таких продуктов, как VMware vSphere, Microsoft Hyper-V и Citrix Hypervisor. Размер установочного[iso-образа](http://download.proxmox.com/iso/)1.7 ГБ.

Proxmox VE предоставляет средства для развёртывания полностью готовой системы виртуальных серверов промышленного уровня с управлением через web-интерфейс, рассчитанный на управление сотнями или даже тысячами виртуальных машин. Дистрибутив имеет встроенные инструменты для организации резервного копирования виртуальных окружений и доступную из коробки поддержку кластеризации, включая возможность миграции виртуальных окружений с одного узла на другой без остановки работы. Среди особенностей web-интерфейса: поддержка безопасной VNC-консоли; управление доступом ко всем доступным объектам (VM, хранилище, узлы и т.п.) на основе ролей; поддержка различных механизмов аутентификации (MS ADS, LDAP, Linux PAM, Proxmox VE authentication).

В[новом выпуске](http://pve.proxmox.com/wiki/Roadmap#Proxmox_VE_9.3):

- Осуществлена синхронизация с пакетной базой Debian 13.8. Подготовлен пакет с ядром Linux[7.3](https://www.opennet.ru/opennews/art.shtml?num=66499)(по умолчанию поставляется пакет с ядром 7.0). Задействованы выпуски[QEMU 11.1](https://www.opennet.ru/opennews/art.shtml?num=65269),[LXC 7.0](https://www.opennet.ru/opennews/art.shtml?num=65327),[OpenZFS 2.4](https://www.opennet.ru/opennews/art.shtml?num=64448), Ceph 20.2.5/21.2.0.
- В web-интерфейс добавлена страница 'Datacenter → SAN' для централизованной настройки общей сети хранения (SAN, Storage Area Network) на базе LVM, развёрнутой поверх iSCSI, Fibre Channel и NVMe-oF (NVMe over Fabrics), с возможностью оценки состояния LUN (Logical Unit Number) на всех узлах в реальном времени. Также добавлена поддержка централизованной настройки Multipath в одном месте, без необходимости изменения настроек на каждом узле кластера.
- В LVM-хранилищах с предварительным выделением сразу всего заявленного дискового пространства (thick-provisioned) стабилизирована поддержка работы со снапшотами как с цепочками связанных дисковых разделов (Volume-Chain).
- В web-интерфейсе на странице "Datacenter > Storage" реализована возможность добавления и изменения настроек сторонних плагинов с поддержкой дополнительных хранилищ. Web-формы для настройки подобных плагинов генерируются динамически на основе схемы данных, указанной в плагине.
- Реализовано присвоение всем гостевым системам уникальных идентификаторов, сохраняющихся после миграции и при восстановлении из резервной копии, даже если после восстановления гостевой системе присвоен иной VMID или она была перенесена из другого кластера.
- В web-интерфейс на страницу "Datacenter → HA" добавлены инструменты для управления режимом технического обслуживания (maintenance) кластера высокой доступности, например, теперь можно в один клик включить или отключить режим обслуживания для всего кластера или отдельных узлов, без использования API или утилиты командной строки ha-manager.
- В панели System Log реализована возможность структурированного просмотра логов с выделением цветами важных событий, таких как перезагрузки, и возможностью фильтрации отдельных свойств. На страницу "Node → System" добавлены панель "API Access Log" для просмотра лога обращений к API. На страницу "Node → Updates" добавлена панель "APT History" для просмотра недавних операций с пакетами.
- Добавлен новый визуальный редактор правил фильтрации уведомлений, использующий древовидное представление вместо плоского списка и поддерживающий режим drag&drop для создания сложных вложенных условий.
- В инсталлятор встроены возможности для настройки VLAN и объединения нескольких сетевых интерфейсов (bond) при развёртывании сети управления кластером.
- В стеке программно определяемых сетей (SDN, Software-Defined Networking) улучшена изоляция сети для простых зон (Simple zones), в которых теперь могут использоваться отдельные экземпляры VRF (Virtual Routing and Forwarding) для изоляции таблиц маршрутизации. Добавлена поддержка мониторинга состояния интерфейсов и пиров WireGuard.[
