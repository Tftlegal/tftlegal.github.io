# Выпуск Bazzite 45, дистрибутива для любителей компьютерных игр

## Краткое содержание

Выпущена версия 45 дистрибутива Bazitte, ориентированного на любителей компьютерных игр. Проект основан на наработках Fedora Kinoite 45 и Fedora Silverblue 45. Эти редакции представляют собой атомарно обновляемые варианты Fedora Linux. Они используют рабочие столы KDE и GNOME соответственно. Сборки дистрибутива подготовлены для широкого спектра устройств: ПК, ноутбуков, телеприставок и игровых консолей. Среди целевых платформ в частности названы Steam Deck, Asus Ally, GPD, Ayn и MSI Claw.

## Полная статья

[Представлен](https://universal-blue.discourse.group/t/bazzite-45-is-here/12702)выпуск дистрибутива[Bazitte 45](https://bazzite.gg/), ориентированного на любителей компьютерных игр. Дистрибутив основан на наработках проектов[Fedora Kinoite 45](https://fedoraproject.org/atomic-desktops/kinoite/)и[Fedora Silverblue 45](https://fedoraproject.org/atomic-desktops/silverblue/), развивающих атомарно обновляемые[редакции](https://www.opennet.ru/opennews/art.shtml?num=54407)Fedora Linux с рабочими столами KDE и GNOME. Сборки[сформированы](https://bazzite.gg/#image-picker)для ПК, ноутбуков, телеприставок и игровых консолей, таких как Steam Deck, Asus Ally, GPD, Ayn и MSI Claw.

По[данным](https://www.opennet.ru/opennews/art.shtml?num=65157)сервиса ProtonDB проект Bazzite занимает четвёртое место (9.5%) в рейтинге популярности дистрибутивов Linux, применяемых любителями компьютерных игр, уступая лишь CachyOS (21.1%), Arch Linux (14.9%) и Linux Mint (10.6%). На пользователей Bazzite 44[приходится](https://flathub.org/en/statistics)около 9.6% трафика в каталоге Flathub. Для сравнения доля пользователей Fedora 44 в Flathub оценивается в 10.9%, Cachyos - 4.1%, Arch Linux - 2.9%.

Дистрибутив поставляется в форме монолитного образа, не разделяемого на отдельные пакеты и обновляемого как единое целое. Приложения устанавливаются в формате Flatpak или в форме контейнеров. Для запуска Android-игр задействован Waydroid. В состав входит Steam и подборка компонентов, востребованных любителями компьютерных игр, а также дополнительные драйверы для игровых контроллеров и Wi-Fi. В системные компоненты внесены оптимизации для повышения отзывчивости и улучшения поддержки HDR и VRR.

В новой версии:

- Компоненты дистрибутива обновлены до[Fedora 45](https://www.opennet.ru/opennews/art.shtml?num=66607). Предложены новые версии KDE Plasma 6.8.2 и GNOME 51.1. Графический стек обновлён до Mesa 26.2.6.
- Задействовано ядро Linux 7.2.15 с патчами от проекта[OGC](https://www.opennet.ru/opennews/art.shtml?num=64705), оптимизированное для повышения производительности и эффективности при выполнении компьютерных игр.
- Обновлены компоненты[InputPlumber](https://github.com/shadowblip/InputPlumber)для управления игровыми контроллерами и устройствами ввода.
- Добавлены сервисы bpftune и bpfrag для автоматической оптимизации настроек сетевого стека ядра для игр.
- OpenCL runtime ROCm переведён на использование OpenCL-драйверов Mesa в образах без проприетарных драйверов NVIDIA.
- Добавлена начальная поддержка игровой консоли Acer Predator Atlas 8 и стабилизирована поддержка консоли ROG XBOX Ally X20.[

- Добавлен графический интерфейс для выполнения операций с файловой системой Btrfs.

- При установке приложения[CoolerControl](https://gitlab.com/coolercontrol/coolercontrol)командой "ujust install-coolercontrol" задействован docker-контейнер.
- В библиотеке[extest](https://github.com/Supreeeme/extest)с реализацией X11-расширения XTEST, применяемой для использования Steam Input в окружениях на базе Wayland, добавлена поддержка[64-разрядной версии](https://www.opennet.ru/opennews/art.shtml?num=66482)клиента Steam.
- Фреймворк[fcitx](https://github.com/fcitx/fcitx5), применяемый для управления методами ввода, теперь устанавливается из официального Flatpak-пакета.
- Реализованы возможности, необходимые для использования[Easy Anti Cheat 2](https://www.opennet.ru/opennews/art.shtml?num=66477)в Linux. Добавлено приложение (ujust check-anticheat) для проверки соответствия текущего окружения требованиям Epic Games.[

- Переработан сборочный инструментарий. Для сжатия загружаемых при обновлении данных задействован алгоритм ZSTD, а для разбивки системного образа на слои - инструментарий[chunkah](https://github.com/coreos/chunkah).
- [Добавлена](https://github.com/ublue-os/bazzite/pull/5986)функция временного запуска SSH-сервера при которой SSH-сервер функционирует только в рамках текущего сеанса и после перезапуска не запускается.
- Обновлено приложение Bazzite Portal, реализующее экран приветствия, запускаемый при первом входе в систему и предлагающий возможности для изменения базовых настроек и установки дополнительных приложений. Добавлена информация об обновлениях пакетов Bazzite и Homebrew, а также приложений в формате Flatpak. Реализован индикатор состоянии обновления. Предложено несколько стилей[анимированных пиктограмм](https://global.discourse-cdn.com/free1/uploads/univeral_blue/original/2X/3/320712e470c067694b65e9762d5f4286967fdb2e.gif)для области уведомлений.[
