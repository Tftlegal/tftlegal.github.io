# Оценка затрат времени на поддержание пакетов с открытым ПО в Google

## Краткое содержание

Компания Google опубликовала результаты исследования, посвящённого затратам времени инженеров на обновление пакетов с открытым исходным кодом. Эти пакеты используются во внутренних продуктах компании. Данные были получены на основе опроса 346 сотрудников Google, непосредственно участвующих в процессе обновления пакетов. В ходе опроса выяснялось, сколько времени инженер тратит на подготовку обновлённой версии пакета. Отдельным вопросом стала возможность предсказания связанных трудозатрат. Для этого предполагается использовать метрики, оценивающие сложность поддержки исходного кода. Таким образом, работа направлена на поиск связи между характеристиками кода и реальными усилиями, необходимыми для его обновления.
