# Разработчики Ubuntu начали тестирование системы распознавания речи Myna

## Краткое содержание

Canonical выпустила предварительную версию системы распознавания речи Myna и голосовые инструменты ввода текста для Ubuntu. Готовые сборки доступны для версий Ubuntu 24.04 LTS, 26.04 LTS и 26.10 в пакетах под архитектуры amd64 и amd64v3. Поддерживается работа в окружениях GNOME, использующих протокол Wayland. Для распознавания речи можно выбрать одну из трёх AI-моделей: Whisper, Parakeet или Funasr. Все модели выполняются локально на устройстве. Система поддерживает распознавание речи на разных языках.

## Полная статья

Компания Canonical[опубликовала](https://ubuntu.com//blog/myna-speech-to-text-technology-preview-available)предварительную версию системы распознавания речи[Myna](https://www.opennet.ru/opennews/art.shtml?num=65709)и построенных на её основе инструментов голосового ввода текста, интегрируемых в Ubuntu. Готовые сборки сформированы для Ubuntu 24.04 LTS, Ubuntu 26.04 LTS и Ubuntu 26.10 в пакетах для архитектур amd64 и amd64v3. Поддерживается работа в окружениях GNOME, использующих протокол Wayland. Для распознавания речи на выбор могут использоваться AI-модели Whisper, Parakeet или Funasr, выполняемые локально и поддерживающие разные языки.

Для интеграции с рабочим столом подготовлено дополнение к GNOME Shell - Myna Shell. Голосовой ввод активируется комбинацией клавиш Super+J, после чего можно продиктовать текст вслух и ещё раз нажать Super+J для окончания сеанса диктовки. Диктуемый текст вставляется в текущее приложение через симуляцию клавиатурного ввода.

В конфигуратор добавлена секция для настройки активирующей комбинации клавиш, индикации запуска/остановки распознавания, автоотключения после определённого времени тишины и режима подстановки текста (по мере произнесения или разом после завершения диктовки), а также выбора AI-модели. Предоставляется движок для аппаратного ускорения выполнения моделей распознавания речи на системах с GPU NVIDIA (другие варианты ускорения появятся позднее).
