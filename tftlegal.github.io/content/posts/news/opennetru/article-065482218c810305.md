# Уязвимость в Exim, допускающая удалённое выполнение кода

## Краткое содержание

Вышел корректирующий выпуск почтового сервера Exim версии 4.100.2. В нём устранена уязвимость, которой на данный момент не присвоен идентификатор CVE. Суть проблемы — переполнение буфера при декодировании специально сформированных заголовков. При успешной эксплуатации атакующий может выполнить произвольный код удалённо. Более того, вредоносный код может запускаться с привилегиями root. Уязвимость затрагивает все версии Exim начиная с 4.100. Пользователям рекомендуется как можно скорее перейти на исправленный выпуск 4.100.2.
