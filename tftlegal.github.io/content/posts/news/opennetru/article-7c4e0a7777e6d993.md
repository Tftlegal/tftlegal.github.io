# Проект borland-reborn воссоздал исходный код компилятора Borland C++ 2.0

## Краткое содержание

Энтузиастам удалось воссоздать исходный код компилятора и препроцессора Borland C++ 2.0. Код был написан на языке Си. Реконструкция была проведена на основе анализа исполняемых файлов. Оригинальные бинарники были выпущены в 1991 году для платформы MS-DOS. При компиляции восстановленного кода формируются исполняемые файлы BCC.EXE и CPP.EXE. Полученные файлы совпадают с оригиналами побайтово. Это подтверждает точность проведённой реконструкции.

## Полная статья

Энтузиасты смогли[воссоздать](https://github.com/abedegno/borland-reborn)исходный код на языке Си компилятора и препроцессора[Borland C++ 2.0](https://en.wikipedia.org/wiki/Borland_C%2B%2B)на основе анализа исполняемых файлов, выпущенных в 1991 году для MS-DOS. В результате компиляции воссозданного кода формируются исполняемые файлы BCC.EXE и CPP.EXE, байт в байт совпадающие с оригиналами.

Помимо этого[подготовлен](https://github.com/abedegno/borland-reborn/releases/tag/bcc20-v0.2.0)порт Borland C++ 2.0 для современных систем, позволяющий собрать компилятор и препроцессор для Linux и Windows. В 1874 из 1880 проверочных компиляций разного кода порт сгенерировал объектные и ассемблерные файлы, идентичные исходным (в 6 сборках из-за специфичных для DOS особенностей работы с памятью компилятор выдавал ошибку). В качестве основного применения порта называется сборка декомпилированных старых игр.
