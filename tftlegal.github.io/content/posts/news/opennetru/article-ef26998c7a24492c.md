# Независимый браузер Ladybird перешёл на стадию альфа-тестирования

## Краткое содержание

Вышел первый альфа-релиз веб-браузера Ladybird, который использует собственную независимую движковую платформу и интерфейс на базе Qt. Проект придерживается концепции «только браузер и ничего лишнего». На текущем этапе браузер уже способен корректно работать с большинством сайтов, включая Twitch, Gmail и YouTube, хотя отдельные страницы всё ещё отображаются с ошибками. Код написан на C++ и Rust и распространяется под лицензией BSD. Готовые сборки доступны для Linux (в форматах Flatpak, deb и rpm для Ubuntu и Fedora) и macOS.

## Полная статья

[Представлен](https://ladybird.org/posts/alpha/)первый альфа-выпуск web-браузера[Ladybird](https://ladybird.org/), развивающего собственный движок, независимый от других проектов, и предлагающего интерфейс на основе Qt. Продукт соответствует концепции "только браузер и ничего лишнего". На данной стадии браузер уже пригоден для работы с большинством сайтов, включая Twitch, Gmail и YouTube, но пока полностью не избавлен от ошибок и проблем при просмотре некоторых сайтов. Код проекта написан на языках C++ и Rust и[распространяется](https://github.com/LadybirdBrowser/ladybird)под лицензией BSD. Готовые сборки[сформированы](https://ladybird.org/download/)для Linux (Flatpak, deb и rpm для Ubuntu и Fedora) и macOS.

Среди возможностей Ladybird: поддержка актуальных стандартов HTML, CSS и JavaScript, наличие JIT-компилятора для JavaScript, движок для выполнения WebAssembly, возможность аппаратного ускорения декодирования видео, режим приватного просмотра, восстановление сеансов, откат изменений (undo/redo), менеджер загрузок, встроенный просмотрщик PDF, интерфейс для навигации по истории посещений и блокировщик нежелательного контента, основанный на библиотеке adblock-rust от проекта Brave. Для автоматизации работы с браузером поддерживается технология[WebDriver](https://developer.mozilla.org/en-US/docs/Web/WebDriver), а для отладки сайтов имеется протокол, совместимый с Firefox DevTools.

Браузер использует многопроцессную архитектуру, в которой интерфейс пользователя и отрисовка страниц разделены по отдельным процессам. Страницы разных сайтов обрабатываются в отдельных процессах, изолированных от остальной системы при помощи sandbox-изоляции. В отдельные процессы также вынесены операции установки сетевых соединений и декодирования изображений для каждого сайта.

Проектом развиваются web-движок[LibWeb](https://github.com/LadybirdBrowser/ladybird/tree/master/Libraries/LibWeb); JavaScript-интерпретатор[LibJS](https://github.com/LadybirdWebBrowser/ladybird/tree/master/Userland/Libraries/LibJS); движок LibWasm для WebAssembly; криптографические библиотеки LibCrypto и LibTLS; HTTP-клиент LibHTTP с поддержкой HTTP/1.1; библиотека LibGfx с функциями 2D-графики, декодирования и отрисовки изображений; LibUnicode с функциями для поддержки Unicode и локализации; LibMedia для воспроизведения звука и видео; механизм межпроцессного взаимодействия LibIPC.

Браузер[Ladybird](https://ladybird.org/)развивается Андреасом Клингом, который когда-то работал в компании Nokia и занимался разработкой KHTML, а затем в Apple был одним из разработчиков Safari. Изначально проект был создан как приложение для операционной системы[SerenityOS](https://www.opennet.ru/opennews/art.shtml?num=50753), но летом 2024 года был[выделен](https://www.opennet.ru/opennews/art.shtml?num=61301)в отдельный проект и[получил](https://www.opennet.ru/opennews/art.shtml?num=61474)пожертвование в 1 млн. долларов.
