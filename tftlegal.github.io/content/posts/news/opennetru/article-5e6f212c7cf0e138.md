# Прошивки для превращения плат ESP8266 и ESP32 в аналоговую радиостанцию

## Краткое содержание

Проект ESP-AnalogRadio представляет набор открытых прошивок для микроконтроллеров ESP8266 и ESP32, которые позволяют использовать встроенный радиочастотный модуль (обычно предназначенный для Wi-Fi и Bluetooth) для генерации и приёма аналоговых радиосигналов. Поддерживаются амплитудная (AM), частотная (FM) и однополосная (SSB) модуляции в диапазонах 2,4 и 5 ГГц, причём в FM-режиме доступна передача стереозвука. Поскольку сигналы передаются на частотах, используемых Wi-Fi, их нельзя принять на обычных бытовых AM/FM радиоприёмниках. Для приёма требуется либо второй аналогичный модуль, либо SDR-устройство с поддержкой диапазонов 2,4/5 ГГц, например HackRF. Весь код прошивок распространяется под лицензией GPLv3.

## Полная статья

Проект[ESP-AnalogRadio](https://github.com/kaboom748/ESP-AnalogRadio)развивает набор открытых прошивок для микроконтроллеров ESP8266 и ESP32 Classic/C5/C6, использующих встроенный радиочастотный модуль (RF), штатно применяемый для Wi-Fi и Bluetooth, для генерации и приёма аналоговых радиосигналов с амплитудной (AM), частотной (FM) и однополосной (SSB) модуляцией в диапазонах 2.4 ГГц и 5 ГГц. В FM-режиме реализована поддержка стереозвука. Поскольку сигнал передаётся на частотах Wi-Fi, приём на бытовые AM/FM радиоприёмники невозможен и для приёма требуется вторая подобная плата или SDR-устройство с поддержкой диапазонов 2.4/5 ГГц, например,[HackRF](https://www.opennet.ru/opennews/art.shtml?num=37570). Код прошивок[открыт](https://github.com/kaboom748/ESP-AnalogRadio)под лицензией GPLv3

Управляющий интерфейс реализован в форме web-приложения, выполняющего кодирование и декодирование 12-битного PCM-звука и использующего API Web Serial для потоковой передачи данных по USB-порту. Микроконтроллер в свою очередь осуществляет радиочастотную синхронизацию и модуляцию. Дополнительно подготовлены самодостаточные варианты прошивок, позволяющие разместить звуковые данные в разделе LittleFS и воспроизводить их напрямую с Flash-памяти.
