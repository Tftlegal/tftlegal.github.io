# Для рабочего стола MATE опубликован композитный сервер Polo, использующий Wayland

## Краткое содержание

Вышел релиз композитного сервера Polo версии 1.0. Он предназначен для запуска рабочего окружения MATE. Polo воссоздаёт возможности штатного оконного менеджера Marco, однако использует протокол Wayland вместо X11. В одном приложении объединены функции композитного сервера, оконного менеджера и менеджера сеансов. Код написан на языках C и Vala с применением библиотеки libweston. Проект распространяется под лицензией GPLv3.

## Полная статья

[Опубликован](https://discourse.ubuntu.com/t/introducing-polo-a-mate-wayland-compositor/91698)релиз композитного сервера[Polo 1.0](https://github.com/KeremSoke/polo/releases/tag/v1.0.0), созданного для запуска среды рабочего стола[MATE](https://mate-desktop.org/)и воссоздающего возможности штатного оконного менеджера Marco, но с использованием протокола Wayland вместо X11. Polo сочетает функции композитного сервера, оконного менеджера и менеджера сеансов. Код Polo написан на языках C и Vala с использованием библиотеки libweston и[распространяется](https://github.com/KeremSoke/polo)под лицензией GPLv3.

При запуске MATE поверх Polo работоспособны такие возможности, как управление окнами, мозаичная компоновка, виртуальные рабочие столы, буфер обмена, эффекты (куб с проекциями виртуальных рабочих столов, шатающиеся окна, постепенное затухание и т.п.), запуск X11-приложений через XWayland, многомониторные конфигурации, масштабирование вывода, горячее подключение дисплеев, создание скриншотов и скринкастов, комбинации клавиш, политики управления окнами и темы оформления.

В Polo также интегрированы средства для управления сеансами и настройками, что позволяет использовать его для замены mate-session-manager и mate-settings-daemon, а также организации автозапуска, завершения работы и сохранения сеансов. Поддерживаются применяемые в MATE интерфейсы D-Bus и настройки GSettings/dconf. Специфичные для Polo расширенные настройки вынесены в отдельную иерархию org.mate.polo.

Изначально проект MATE экспериментировал с сеансом на базе Wayland, используя композитный сервер[Wayfire](https://wayfire.org/). Проект Polo развивается с оглядкой на потребности проекта MATE, в отличие от Wayfire, который спроектирован для обособленного использования и не рассчитан на работу с другими средами рабочего стола, что потребовало для его интеграции с MATE создания плагинов, добавления хаков и принятия компромиссов.
