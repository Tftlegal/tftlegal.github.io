# Опубликованы сборки Raspberry Pi OS для ноутбуков и ПК на базе архитектуры x86_64

## Краткое содержание

Проект Raspberry Pi выпустил новую версию дистрибутива Raspberry Pi OS 2026-10-06 (Raspbian). Одновременно был анонсирован Live-образ объёмом 2,6 ГБ для компьютеров на архитектуре x86_64. Как и сборки для ARM-платформ Raspberry Pi, эта версия основана на пакетной базе Debian 13. Помимо загрузки с USB-накопителя, вариант для ПК включает инсталлятор Calamares. Это позволяет установить систему на стационарный жёсткий диск или SSD. Таким образом, Raspberry Pi OS теперь доступна не только на одноплатных компьютерах, но и на обычных ПК.

## Полная статья

Проект Raspberry Pi[опубликовал](https://downloads.raspberrypi.com/raspios_arm64/release_notes.txt)новую версию дистрибутива[Raspberry Pi OS 2026-10-06](https://www.raspberrypi.com/software/operating-systems/)(Raspbian) и[объявил](https://www.raspberrypi.com/news/raspberry-pi-desktop-now-available-for-pc-and-mac/)о формировании[Live-сборки](https://www.raspberrypi.com/software/operating-systems/#raspberry-pi-desktop)([2.6 ГБ](https://downloads.raspberrypi.com/rpd_x86/images/rpd_x86-2026-10-06/)), предназначенной для установки на компьютеры c процессорами на базе архитектуры x86_64. Как и сборки для ARM-плат Raspberry Pi новый вариант построен на пакетной базе Debian 13. Помимо загрузки с USB-носителей версия для ПК включает инсталлятор Calamares, позволяющий установить систему на стационарный жёсткий диск или SSD.

[

![](/news/opennetru/article-9d9f32400363fc46/image-01.jpg)

](https://www.raspberrypi.com/app/uploads/2026/10/20261006_073722_grim-1536x960.jpg)

В состав сборки для ПК среди прочего включён сервис[Raspberry Pi Connect](https://www.raspberrypi.com/software/connect/), предназначенный для удалённого подключения к рабочему столу дистрибутива Raspberry Pi OS через web-браузер. Среда рабочего стола базируется на композитном сервере labwc, использующем библиотеку wlroots от проекта Sway.

[

![](/news/opennetru/article-9d9f32400363fc46/image-02.jpg)

](https://www.raspberrypi.com/app/uploads/2026/09/20260915_072006_grim-1536x864.jpg)

Среди изменений в новой версии Raspberry Pi OS: поставка более качественных пиктограмм для меню, появление всплывающих подсказок о сути виджетов и конфигураторе Control Centre, поддержка автомонтирования шифрованных дисков, добавление на панель виджетов для показа заряда аккумуоятора и вызова экранной клавиатуры squeekboard.

Также можно отметить общую модернизацию оформления среды рабочего стола и добавление новой dock-панели в дополнение к классической панели задач. Вместо старого меню программ предложены два виджета для запуска приложений - полноэкранный интерфейс навигации по доступным программам c функцией поиска и встраиваемый в панель виджет, сочетающий список открытых окон и область для быстрого запуска приложений.

[

![](/news/opennetru/article-9d9f32400363fc46/image-03.jpg)

](https://www.raspberrypi.com/app/uploads/2026/09/launcher-1-1536x804.jpg)[

![](/news/opennetru/article-9d9f32400363fc46/image-04.jpg)

](https://www.raspberrypi.com/app/uploads/2026/09/appmenu.jpg)

Новая dock-панель допускает размещение одновременно со старой панелью задач, например, старая панель может быть закреплена в верхней части окна для отображения индикаторов состояния, а новая dock-панель размещена в нижней части и отвечать за показ списка окон и интерфейса запуска приложений. Состав и размещение панелей настраивается в конфигураторе.
