# Выпуск мобильной платформы /e/OS 4.3

## Краткое содержание

Вышел релиз мобильной платформы /e/OS 4.3, ориентированной на защиту конфиденциальности пользовательских данных. Проект основан Гаэлем Дювалем, известным как создатель дистрибутива Mandrake Linux. Платформа поддерживает 287 моделей смартфонов, для наиболее популярных из которых формируются фирменные сборки прошивки. На базе устройств OnePlus, Fairphone, Teracube, HIROH и Pixel выпускаются собственные редакции гаджетов с предустановленной /e/OS. Эти устройства распространяются под брендом Murena и включают модели Murena One, Murena 2, Murena Fairphone 4/5/6, Murena Teracube 2e, Murena Pixel 5/7 и Murena SHIFTphone 8.

## Полная статья

[Представлен](https://e.foundation/leaving-apple-google-welcome-e-os-4-3-join-the-final-days-of-e-os-summer-photo-contest/)выпуск мобильной платформы[/e/OS 4.3](https://e.foundation/e-os/), сфокусированной на конфиденциальности пользовательских данных. Платформа основана Гаэлем Дювалем ([Gaël Duval](https://en.wikipedia.org/wiki/Ga%C3%ABl_Duval)), создателем дистрибутива Mandrake Linux. Проект[поддерживает](https://doc.e.foundation/devices)287 моделей смартфонов и[формирует](https://e.foundation/get-e-os/)сборки прошивок для наиболее популярных из них. На базе смартфонов OnePlus, Fairphone, Teracube, HIROH и Pixel[подготовлены](https://murena.com/shop/)собственные редакции устройств, распространяемые с предустановленной прошивкой /e/OS под брендами Murena One, Murena 2, Murena Fairphone 4/5/6, Murena Teracube 2e, Murena Pixel 5/7 и Murena SHIFTphone 8.

Прошивка /e/OS[развивается](https://doc.e.foundation/what-s-e)как ответвление от платформы[LineageOS](https://www.opennet.ru/opennews/art.shtml?num=60609)(на базе Android), избавленное от привязки к сервисам и инфраструктуре Google для исключения передачи телеметрии на серверы Google и повышения уровня конфиденциальности. Среди прочего, блокируется и неявная отправка информации, например, обращения к серверам Google при проверке доступности сети, резолвинге DNS и определении точного времени.

В поставку входит пакет[microG](https://www.opennet.ru/opennews/art.shtml?num=47505), предлагающий независимые аналоги сервисов Google, что позволяет обойтись без установки проприетарных компонентов. Для определения местоположения по Wi-Fi и базовым станциям (без GPS) прослойка[UnifiedNlp](https://github.com/microg/UnifiedNlp), способная работать через BeaconDB, OpenWlanMap, openBmap, OpenCellID, lacells.db и другие альтернативные сервисы. Вместо поисковой системы Google предлагается метапоисковый сервис[Murena Find](https://murena.qwant.com/)на основе поискового движка[Qwant](https://www.qwant.com/).

Для синхронизации точного времени вместо обращения к NTP-серверу Google запросы отправляются на серверы из коллекции[NTP Pool](https://www.ntppool.org/en/), а вместо DNS-серверов Google (8.8.8.8) используются DNS-серверы текущего провайдера. В web-браузере по умолчанию включён блокировщик рекламы и скриптов для отслеживания перемещений. Для синхронизации файлов и данных приложений разработан собственный сервис, совместимый с[инфраструктурой](https://gitlab.e.foundation/e/infra/ecloud-selfhosting)на основе Nextcloud. Серверные компоненты основаны на открытом ПО и[доступны](https://gitlab.e.foundation/e)для установки на подконтрольных пользователю системах.

Интерфейс пользователя включает собственное окружение для запуска приложений[BlissLauncher](https://gitlab.e.foundation/e/os/BlissLauncher), улучшенную систему уведомлений, новый экран блокировки и иное стилевое оформление. В BlissLauncher задействован разработанный для /e/OS набор автоматически масштабируемых пиктограмм и отдельная подборка виджетов (например, виджет для показа прогноза погоды).

Проектом также развивается собственный менеджер аутентификации, позволяющий использовать для всех сервисов единую учётную запись (user@murena.io), регистрируемую в процессе первой установки. Учётную запись можно использовать для получения доступа к своему окружению с других устройств или через Web. В облаке Murena Cloud бесплатно предоставляется 1ГБ для хранения своих данных, синхронизации приложений и резервных копий.

Среди входящих в состав приложений: почтовый клиент[Mail](https://gitlab.e.foundation/e/os/mail)(форк K9-Mail), web-браузер[Cromite](https://github.com/uazo/cromite)(на базе Chromium), программа для работы с камерой[OpenCamera](https://sourceforge.net/p/opencamera/code/ci/master/tree/), программа для отправки мгновенных сообщений[QKSMS](https://github.com/moezbhatti/qksms), система для ведения заметок[nextcloud-notes](https://github.com/stefan-niedermann/nextcloud-notes), PDF-просмотрщик[MJ PDF](https://github.com/mudlej/mj_pdf), планировщик[opentasks](https://github.com/dmfs/opentasks), программа для работы с картами[Magic Earth](https://www.magicearth.com/), галерея фотографий[gallery3d](https://gitlab.e.foundation/e/os/android_packages_apps_Gallery2),[файловый менеджер](https://gitlab.e.foundation/e/os/android_packages_apps_DocumentsUI), каталог приложений[App Lounge](https://gitlab.e.foundation/e/os/apps).

Основные[изменения](https://gitlab.e.foundation/e/os/releases/-/releases/)в /e/OS 4.3:

- Перенесены обновления и исправления из платформы[LineageOS 23](https://lineageos.org/), построенной на кодовой базе[Android 16](https://www.opennet.ru/opennews/art.shtml?num=63388). Прошивка /e/OS для смартфона Fairphone 4 обновлена до Android 16.
- В приложение /e/OS Backup добавлен вывод сведений о следующем запланированном резервном копировании. Обеспечено сохранение в резервной копии настроек виджета с прогнозом погоды и выбранных обоев. Добавлены оптимизации для приостановки резервного копирования при низком заряде аккумулятора. Добавлено определение использования системы[Seedvault](https://github.com/GrapheneOS/platform_external_seedvault)для создания шифрованных резервных копий для продолжения её использования вместо /e/OS Backup.
- В прошивке для смартфона Gigaset GS6 улучшена аутентификация по отпечаткам пальцев, добавлен обработчик для выбора действий при удержании кнопки Action и решена проблема с аварийным завершением работы приложений microG.
- Обновлены прошивки для компонентов смартфонов Fairphone 6 и Fairphone 4.
- В менеджере учётных записей улучшена синхронизация контактов для адресной книги.
- В менеджере паролей прекращено автозаполнение полей с одноразовыми паролями.
- Для устройств OnePlus, Samsung, Xiaomi и Sony Xperia налажена сборка образов для восстановления (recovery.img).
