# Новые версии Wine 11.22 и Wine-staging 11.22

## Краткое содержание

Вышел экспериментальный выпуск Wine 11.22 — открытой реализации Win32 API. Проект позволяет запускать Windows-приложения на других операционных системах. Новая версия продолжает линейку после выпуска 11.21. С момента выхода предыдущей версии было закрыто 34 отчёта об ошибках. В код было внесено 323 изменения. Выпуск носит экспериментальный характер, что предполагает возможную нестабильность.

## Полная статья

[Опубликован](https://www.winehq.org/news/2026111301)экспериментальный выпуск открытой реализации Win32 API -[Wine 11.22](https://www.winehq.org/). С момента выпуска[11.21](https://www.opennet.ru/opennews/art.shtml?num=66580)был закрыто 34 отчёта об ошибках и внесено 323 изменения.

Наиболее важные[изменения](https://gitlab.winehq.org/wine/wine/-/releases/wine-11.22):

- Данные локали обновлены до БД[Unicode CLDR](https://cldr.unicode.org/)(Unicode Common Locale Data Repository) версии 49.
- В режиме эмуляции архитектуры x86 на системах ARM64 реализована поддержка процессорных инструкций AVX.
- Реализована рандомизация адресного пространства (ASLR).
- Улучшены метрики глифов в шрифте Tahoma (Tahoma Bold[не показывался](https://bugs.winehq.org/show_bug.cgi?id=26037)жирным).
- Переделан код для проверки структуры XML-документов (DTD, Document Type Definition) в реализации библиотеки MSXML (Microsoft XML Core Services).
- Закрыты отчёты об ошибках, связанные с работой приложений: FreeCommander, ImgBurn 2.5.5.0, fastone image viewer 5.9, Logos Bible Software, Crossrunner, Kubios HRV Scientific, Razer installer, BSG Launcher, CloneCD, Notepad++, WinSCP, Samsung Magician 9.
- Закрыты отчёты об ошибках, связанные с работой игр: Guild Wars 2, Perry Rhodan - The Adventure, Overwatch 2, Star Citizen, Black Mirror II/III, F.E.A.R. 3, Dragon Age: Origins, Alan Wake, Alan Wake's American Nightmare.

Параллельно[сформирован](https://list.winehq.org/hyperkitty/list/wine-devel@list.winehq.org/thread/I4DP6TSGDEWF3BNA7VPCC25K3HC3FMGU/)выпуск проекта[Wine Staging 11.22](https://github.com/wine-staging/wine-staging/), предоставляющего расширенные сборки Wine, включающие не полностью готовые или рискованные патчи, пока непригодные для принятия в основную ветку Wine. По сравнению с Wine в Wine Staging предоставляется[282 дополнительных патча](https://github.com/wine-staging/wine-staging/tree/master/patches)(в прошлой версии было 275). В новом выпуске Wine Staging осуществлена синхронизация с кодовой базой Wine 11.22, обновлён код vkd3d и ws2_32-af_unix. В основной состав Wine перенесён[патч](https://github.com/wine-staging/wine-staging/blob/40ab84054fe2ead6c689de31405ba36269e9ee3a/patches/odbc32-fixes/0022-odbc32-SQLBindCol-remap-unicode-field-when-using-ANS.patch#L22)с реализацией SQLDescribeColW на базе ANSI-драйвера в библиотеке dbc32. Удалён патч ntdll-ForceBottomUpAlloc, который больше не требуется после исправления ошибки в основной кодовой базе.
