# Выпуск FluxCast 0.2.6, инструмента для трансляции рабочего стола Linux на Smart TV

## Краткое содержание

Вышла версия FluxCast v0.2.6.
Это проект для стриминга рабочего стола Linux на экраны Smart TV.
Поддерживаются протоколы Wi-Fi Direct (Miracast), DLNA и Chromecast.
Главная цель проекта — минимальная задержка трансляции.
Исходный код написан на Python и распространяется под лицензией GPLv3.
