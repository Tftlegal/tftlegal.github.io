# Выпуск открытого API-клиента Kurlo 3.1

## Краткое содержание

Вышел новый выпуск Kurlo 3.1 — графического интерфейса для отладки и тестирования API. Проект позиционируется как альтернатива популярным инструментам Postman, Insomnia, Bruno и Yaak. Приложение написано на Go и Svelte с использованием фреймворка Wails. В отличие от многих аналогов, Wails задействует системный WebView вместо встроенного движка Chromium. Kurlo распространяется под лицензией MIT. Готовые сборки доступны для Linux (в формате AppImage), Windows и macOS.

## Полная статья

[Опубликован](https://github.com/stormhop/kurlo/releases/tag/v3.1.0)выпуск[Kurlo 3.1](https://github.com/stormhop/kurlo/), графического интерфейса для отладки и тестирования API, развиваемого как альтернатива системам[Postman](https://www.postman.com/),[Insomnia](https://insomnia.rest/),[Bruno](https://www.usebruno.com/)и[Yaak](https://yaak.app/). Код написан на Go и[Svelte](https://github.com/sveltejs/svelte)с использованием фреймворка[Wails](https://github.com/wailsapp/wails), который вместо встроенного движка Chromium использует системный WebView, и[распространяется](https://github.com/stormhop/kurlo)под лицензией MIT. Готовые сборки[формируются](https://github.com/stormhop/kurlo/releases/tag/v3.1.0)для Linux (AppImage), Windows и macOS.

Основные возможности

- Запросы HTTP, GraphQL, gRPC, WebSocket, Socket.IO, SSE и MCP.
- Коллекции хранятся в виде YAML-файлов, которые можно держать в Git-репозитории вместе с кодом API. Для работы с Git предусмотрен встроенный интерфейс.
- Импорт из Postman, Insomnia, Bruno, OpenAPI и HAR. Скрипты Postman (pm.test, pm.expect, pm.sendRequest) переносятся как есть.
- Есть эмуляция проверок браузера: CORS-запрос preflight и ограничения CSP connect-src проверяются по спецификациям Fetch и CSP3. Это позволяет ещё до релиза увидеть в клиенте ошибку, которую получит браузер.
- Локальный mock-сервер, консольная утилита для запуска коллекций в системах непрерывной интеграции и MCP-сервер.
- Опциональный AI-агент, работающий с выбранной пользователем моделью (OpenRouter, Ollama, LM Studio, собственный API-ключ) либо через Claude Code и Codex. Изменения применяются только после подтверждения пользователем, пароли и ключи модели не передаются.
- Отсутствие привязки к учётной записи, платных функций и сбора телеметрии.
- Возможность работы без доступа к интернету, в том числе в закрытых контурах; для AI-агента можно использовать локальную модель через Ollama или LM Studio.

Изменения в версии 3.1

- Синхронизация коллекции со спецификацией OpenAPI, загружаемой по URL или из файла в репозитории. Для CI добавлена команда "kurlo openapi check", выводящая добавленные, изменённые и удалённые операции.
- Переменные, задаваемые на уровне отдельного запроса (vars).
- Авторизация JWT Bearer: токен подписывается при каждой отправке, поддерживаются алгоритмы HS, RS, PS и ES.
- Проверки ответа (код статуса, время, заголовки, поля JSON) без написания скриптов (assertions).
- Отмена удаления и список недавно удалённых элементов (Undo).
- Цветовая маркировка окружений (чтобы запрос случайно не был отправлен на рабочий сервер) и изменение порядка запросов в режиме drag-n-drop.
- Ускорены открытие, сохранение и прокрутка рабочих пространств с тысячами запросов и примеров на всех ОС.
