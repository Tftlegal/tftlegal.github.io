# Выпуск UDisks 2.12.0, инструментария для управления дисками в Linux

## Краткое содержание

Через два года разработки опубликован релиз пакета UDisks версии 2.12.0. Пакет включает системный фоновый процесс, библиотеки и утилиты для управления дисками и устройствами хранения. UDisks предоставляет D-Bus API для работы с разделами дисков, MD RAID, loop-монтированием блочных устройств и оперирования файловыми системами. Дополнительно в комплект входят модули для мониторинга и управления BTRFS, iSCSI, libStorageManagement, LVM2 и LVM Cache. Пакет активно используется в приложениях GNOME и различных графических конфигураторах для работы с дисковыми разделами.

## Полная статья

После двух лет разработки[опубликован](https://github.com/storaged-project/udisks/releases/tag/udisks-2.12.0)релиз пакета[UDisks 2.12.0](https://github.com/storaged-project/udisks), включающего системный фоновый процесс, библиотеки и инструментарий для организации доступа и управления дисками, устройствами хранения и связанными с ними технологиями. UDisks[предоставляет](http://storaged.org/doc/udisks2-api/latest/)D-Bus API для работы с дисковыми разделами, настройки MD RAID, работы с блочными устройствами в файле (loop-монтирование), манипуляций с файловыми системами и т.п. Дополнительно поставляются модули для мониторинга и управления BTRFS, iSCSI, libStorageManagement, LVM2 и LVM Cache. Например, UDisks используется в приложениях GNOME для работы с дисковыми разделами и в различных графических конфигураторах.

В[новой версии](https://github.com/storaged-project/udisks/blob/master/NEWS):

- Добавлена команда "udisksctl drive-set-standby" для настройки таймаута перевода накопителя в спящий режим.
- Для настройки loop-устройств теперь всегда запрашивается авторизация через PolKit (org.freedesktop.udisks2.loop-setup).
- В API Filesystem.Mount() ограничено использование опции "as-user", которая теперь требует обязательно авторизации, используя реальный идентификатор пользователя. Изменение внесено по следам недавно[исправленной](https://github.com/storaged-project/udisks/releases/tag/udisks-2.11.2)уязвимости[CVE-2026-7867](https://github.com/storaged-project/udisks/security/advisories/GHSA-j42g-v9jw-6ph3), позволявшей без авторизации выполнить операцию mount от имени другого пользователя, включая root, через манипуляции с опцией 'as-user' при обращении по D-Bus к обработчику Filesystem.Mount.
- Реализован перерасчёт размера NVMe-устройств с учётом доступных пространств имён, в ситуациях когда контроллер не возвращает параметр TNVMCAP (Total NVM Capacity) с данными о размере.
- В API Encrypted.Unlock() и в /etc/crypttab добавлена поддержка флага "discard", при помощи которого можно включить применение команды TRIM с зашифрованными разделами (по умолчанию не используется, так как потенциально позволяет определить распределение пустых и занятых блоков на диске).
