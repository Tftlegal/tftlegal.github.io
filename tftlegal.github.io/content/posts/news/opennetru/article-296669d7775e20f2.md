# Доступна СУБД SQLite 3.54 с оптимизациями, расширением CLI и прекращением поддержки Windows XP

## Краткое содержание

Вышел релиз SQLite 3.54 — популярной легковесной системы управления базами данных. В отличие от традиционных серверных СУБД, SQLite реализована в виде подключаемой библиотеки, что позволяет встраивать её прямо в приложение. Исходный код SQLite распространяется как общественное достояние (public domain). Это означает, что anyone может свободно использовать, модифицировать и распространять его без каких-либо ограничений. Использование базы не требует оплаты и не привязано к конкретным целям — коммерческим или некоммерческим. Финансирование разработки проекта обеспечивает специально созданный для этих целей консорциум. Таким образом, SQLite остаётся полностью бесплатным и открытым решением с устойчивой моделью поддержки.

## Полная статья

[Опубликован](https://www.sqlite.org/changes.html)релиз[SQLite 3.54](http://sqlite.org/), легковесной СУБД, оформленной в виде подключаемой библиотеки. Код SQLite[распространяется](https://github.com/sqlite/sqlite)как общественное достояние (public domain), т.е. может использоваться без ограничений и безвозмездно в любых целях. Финансовую поддержку разработчиков SQLite осуществляет специально созданный[консорциум](https://www.sqlite.org/consortium.html).

Основные[изменения](https://sqlite.org/releaselog/3_54_0.html):

- Проведены оптимизации, позволившие ускорить прохождение теста speedtest1 примерно на 4% по сравнению с прошлой версией и на 7.5% по сравнению с выпуском 3.51 годичной давности. Результаты могут меняться в зависимости от вида нагрузки, сборочных опций, CPU, компилятора и операционной системы.
- В утилите sqlite реализована возможность использования[escape-последовательностей](https://www.sqlite.org/cliprompt.html#esccd)для показа дополнительной информации о состоянии в приглашении командной строки, например, "/x" для сведений об открытой транзакции, "/r" для БД в режиме только для чтения, "/m" для БД, хранимой только в оперативной памяти, "/f" для вставки имени файла с БД, "/v" для показа версии SQLite, "/:" и "/;" для построения условных выражений, "/u" и "/h" для вставки имени пользователя и хоста. Настройка шаблона приглашения командной строки осуществляется через переменные окружения SQLITE_PS1 и SQLITE_PS2.
- В утилите sqlite в команду "[.mode](https://www.sqlite.org/climode.html)" добавлены опции "--ifmt", "--rowcount on" и "--titles always" для настройки[формата](https://www.sqlite.org/printf.html#fmtdetail)чисел с плавающей запятой и управления показом счётчика строк и заголовка. Заменён обработчик команды ".diskused". По умолчанию оставлен заголовок с именами столбцов, если запрос не вернул строк, а также отключена чистка нулевых байтов при выводе blob-ов в Unix-системах.
- В планировщике запросов ускорено выполнение операций UPDATE в ситуациях, когда имеются индексы по выражениям, но индексируемое значение не меняется. Оптимизировано выполнение операций "expr OR TRUE" и "expr OR FALSE". Обеспечено игнорирование выражения DISTINCT в SELECT-подзапросах, указанных справа от оператора "IN". Ускорена обработка и снижено потребление памяти при указании в UNION-запросах выражения "LIMIT 1".
- В команде[ALTER TABLE](https://www.sqlite.org/lang_altertable.html)обеспечен вывод ошибки для любых попыток добавления, удаления или переименования столбцов с зарезервированными именами "ROWID", "_ROWID_" и "OID".
- Добавлена SQL-функция[diskused()](https://www.sqlite.org/diskusedfunc.html)для оценки места, которое таблицы и индексы занимают на накопителе.
- В SQL-функции printf() и format() добавлены подстановки "%J" и "%j" для вывода в формате JSON.
- В функции работы с датами и временем добавлены модификаторы "[weekday -N](https://www.sqlite.org/lang_datefunc.html#wdmod)" и "[end of](https://www.sqlite.org/lang_datefunc.html#eomod)".
- На системах с поддержкой флага[O_TMPFILE](https://man7.org/linux/man-pages/man2/open.2.html)в функции open(), данный режим задействован при создании временных файлов.
- Прекращена поддержка старых версий ОС Windows, включая Windows CE и Windows XP. В качестве минимальной версии заявлена Windows Vista.
