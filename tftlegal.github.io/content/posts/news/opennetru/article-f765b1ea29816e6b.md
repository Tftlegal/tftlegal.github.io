# Выпуск системы шифрования дисковых разделов VeraCrypt 1.26.30

## Краткое содержание

Вышел новый выпуск VeraCrypt 1.26.30 — форка прекратившего существование проекта TrueCrypt. Ключевое отличие VeraCrypt — замена алгоритма RIPEMD-160 на SHA-512 и SHA-256, а также увеличение числа итераций хэширования. Проект также упростил сборку для Linux и macOS и устранил проблемы, выявленные при аудите исходного кода TrueCrypt. Собственный код распространяется под лицензией Apache 2.0, а заимствованные фрагменты из TrueCrypt — под TrueCrypt License 3.0. Готовые сборки доступны для Linux, FreeBSD, Windows и macOS.

## Полная статья

[Опубликован](https://github.com/veracrypt/VeraCrypt/releases/tag/VeraCrypt_1.26.30)выпуск проекта[VeraCrypt 1.26.30](https://www.veracrypt.fr/en/), развивающего форк системы шифрования дисковых разделов TrueCrypt,[прекратившей](https://www.opennet.ru/opennews/art.shtml?num=39889)своё существование. VeraCrypt примечателен заменой используемого в TrueCrypt алгоритма RIPEMD-160 на SHA-512 и SHA-256, увеличением числа итераций хэширования, упрощением процесса сборки для Linux и macOS, устранением[проблем](https://veracrypt.codeplex.com/discussions/569777#PostContent_1313325), выявленных в процессе[аудита](https://www.opennet.ru/opennews/art.shtml?num=39573)исходных текстов TrueCrypt. Разработанный проектом VeraCrypt код[распространяется](https://veracrypt.fr/code/)под лицензией Apache 2.0, а заимствования из TrueCrypt продолжают поставляться под лицензией TrueCrypt License 3.0. Готовые сборки[формируются](https://veracrypt.fr/en/Downloads.html)для Linux, FreeBSD, Windows и macOS.

Среди[изменений](https://www.veracrypt.fr/en/Release%20Notes.html)в новой версии:

- Устранено несколько уязвимостей:[Переполнение буфера](https://github.com/veracrypt/VeraCrypt/security/advisories/GHSA-4j3p-7hp7-xw73)(CVE-2026-77372) при десериализации запросов в привилегированном сервисе.[Получение](https://github.com/veracrypt/VeraCrypt/security/advisories/GHSA-wf3r-pjv3-fcxx)прав root из-за некорректной работы инсталлятора со временными файлами в директории /tmp.[Оставление](https://github.com/veracrypt/VeraCrypt/security/advisories/GHSA-f3px-f8h2-fm4c)расшифрованных данных после отмонтирования в macOS при использовании FUSE-T (CVE-2026-108982).[Повышение привилегий](https://github.com/veracrypt/VeraCrypt/security/advisories/GHSA-w98h-pqh6-wfjj)в версии для Windows.
- Добавлена поддержка доступных на запись разделов, размещаемых в файлах на совместных хранилищах без root-доступа (например, GVfs или NFS в режиме root_squash).
- Cкрипт mount.veracrypt переписан на POSIX shell.
- Улучшена очистка данных токенов.
- В Linux улучшена работа с носителями в режиме только для чтения.
- Добавлена защита от утечки в дочерние процессы файловых дескрипторов, связанных с привилегированными сервисами и аутентификацией.
- Обеспечено определение возможностей CPU до запуска базовых сервисов для задействования аппаратного ускорения при работе с монтируемыми разделами.
- В диалоги генерации файла с ключами, проверки производительности хэшей и настройки пула случайных чисел добавлена поддержка хэш-функции BLAKE2b-512.
- В OpenBSD в интерфейс командной строки и графический конфигуратор добавлена возможность создания разделов FFS.
