# Релиз Tewi 3.0.0, текстового интерфейса для управления torrent-клиентами

## Краткое содержание

Вышел релиз Tewi 3.0.0 — консольного приложения с текстовым интерфейсом (TUI) для управления BitTorrent-клиентами. Программа поддерживает подключение к четырём демонам: Transmission, qBittorrent, Deluge и rTorrent. Пользователь может просматривать и управлять списком торрентов, добавлять новые закачки и выполнять поиск на популярных трекерах. Доступны несколько режимов отображения: карточки, компактный и однострочный. Приложение позволяет просматривать детальную информацию по торрентам — файлы, трекеры, пиры. Также реализовано управление категориями и метками.

## Полная статья

[Состоялся](https://github.com/anlar/tewi/releases/tag/v3.0.0)выпуск[Tewi 3.0.0](https://github.com/anlar/tewi/), консольного приложения с текстовым интерфейсом (TUI) для управления BitTorrent-клиентами. Программа позволяет подключаться к демонам Transmission, qBittorrent, Deluge и rTorrent, просматривать и управлять списком торрентов, добавлять новые закачки, выполнять поиск по популярным трекерам. Поддерживаются различные режимы отображения (карточки, компактный, однострочный), просмотр детальной информации о торрентах (файлы, трекеры, пиры), управление категориями и метками, переключение альтернативных лимитов скорости. Интерфейс построен на базе библиотеки[Textual](https://textual.textualize.io/). Код написан на Python и[распространяется](https://github.com/anlar/tewi/)под лицензией GPLv3+.

Основные изменения с версии[2.0.0](https://www.opennet.ru/opennews/art.shtml?num=64392):

- Добавлена поддержка rTorrent (0.9.7 и новее): подключение напрямую через SCGI или через XML-RPC поверх HTTP (при указании "--path"). Поддерживаются почти все возможности остальных клиентов, кроме переключения альтернативных лимитов скорости. Категории хранятся в формате ruTorrent, поэтому совместимы с ним.
- Список торрентов переписан на Textual Line API. Отрисовываются только видимые строки, поэтому загрузка, обновление и прокрутка заметно ускорены.
- Добавлена постраничная и полустраничная навигация по списку торрентов ("Ctrl+F"/"Ctrl+B", "Ctrl+D"/"Ctrl+U").
- Добавлена фильтрация торрентов по имени ("F") и новые фильтры по статусу.
- Появилась возможность добавить торрент по его хешу.
- Добавлен множественный выбор файлов торрента для групповой смены приоритета.
- Добавлено открытие файлов из детальной информации о торренте по нажатию "Enter".
- Добавлено отображение общих лимитов скорости клиента (в дополнение к альтернативным).
- В заголовок добавлен статус подключения к клиенту (показывается потеря связи с демоном).
- Добавлен выбор тем оформления Textual: dracula, monokai, nord и др. ("T", опция "--theme", полный список: "--list-themes").
- В файле конфигурации разрешено указание переменных окружения ("${VAR_NAME}"), например, для передачи хранимых отдельно паролей и API-ключей.
- Реализована генерация скриптов автодополнения для bash, zsh и tcsh ("--print-completion"). В пакет PyPI включено готовое автодополнение для Bash.
- Добавлена поддержка[Prowlarr](https://github.com/Prowlarr/Prowlarr)с возможностью поиска по всем индексаторам сразу или выбора отдельных ("--prowlarr-multi"). Индексаторы можно указывать в пресетах поиска.
- Добавлена поддержка[Bitmagnet](https://bitmagnet.io/), self-hosted BitTorrent-индексатора и DHT-краулера. При поиске в деталях отображаются метаданные контента (тип, название, эпизоды, разрешение, кодек и источник видео).
- Добавлены пресеты поиска (именованные комбинации поисковых провайдеров и категорий).
- Добавлена сортировка результатов поиска по различным атрибутам ("s").
- Добавлен компактный режим отображения результатов поиска с минимумом столбцов ("V").
- Обеспечено запоминание последних выбранных при поиске индексаторов и категорий ("W").
