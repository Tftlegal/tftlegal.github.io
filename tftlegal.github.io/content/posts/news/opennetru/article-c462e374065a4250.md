# Релиз Firefox 158

## Краткое содержание

Состоялся релиз web-браузера Firefox 158. Одновременно были сформированы обновления для веток с длительным сроком поддержки. Речь идёт о версиях 153.5.0 и 115.43.0. В рамках нового двухнедельного цикла формирования релизов в стадию бета-тестирования переведена ветка Firefox 159. Релиз этой версии намечен на 27 октября.

## Полная статья

[Состоялся](https://www.mozilla.org/en-US/firefox/158.0/releasenotes/)релиз web-браузера[Firefox 158](https://www.mozilla.org/en-US/firefox/158.0/releasenotes/)и сформированы обновления[прошлых веток](https://www.mozilla.org/en-US/firefox/organizations/all/)с длительным сроком поддержки -[153.5.0](https://www.mozilla.org/en-US/firefox/153.5.0/releasenotes/)и[115.43.0](https://www.mozilla.org/en-US/firefox/115.43.0/releasenotes/). В рамках нового[двухнедельного цикла](https://www.opennet.ru/opennews/art.shtml?num=65900)формирования релизов на стадию[бета-тестирования](https://firefox.com/channel)[переведена](https://www.mozilla.org/en-US/firefox/159.0beta/releasenotes/)ветка Firefox 159, релиз которой намечен на 27 октября.

Основные новшества в Firefox 158 ([1](https://www.mozilla.org/en-US/firefox/158.0/releasenotes/),[2](https://developer.mozilla.org/en-US/docs/Mozilla/Firefox/Releases/158),[3](https://bugzilla.mozilla.org/buglist.cgi?query_format=advanced&resolution=FIXED&target_milestone=158%20Branch&limit=0&short_desc_type=anywords&short_desc=Allow Enable Add Drop Support Implement)):

- [Включена](https://developer.chrome.com/blog/jpeg-xl-in-chrome?hl=en)по умолчанию поддержка декодирования изображений в формате JPEG XL. В HTTP-заголовок Accept добавлен MIME-тип "image/jxl". Как и в Chrome добавленная в Firefox реализация JPEG-XL[основана](https://github.com/mozilla/standards-positions/pull/1064)на библиотеке[jxl-rs](https://github.com/libjxl/jxl-rs), написанной на Rust. JPEG XL позволяет добиться уменьшения размера файлов на 30-50% по сравнению с изображениями JPEG идентичного качества. Среди поддерживаемых расширенных возможностей: HDR, анимация, прозрачность, режим прогрессивной загрузки, плавное ухудшение качества при уменьшении битрейта, сжатие JPEG без потерь, поддержка до 4099 каналов и большой диапазон глубин цвета.
- В режим "[Smart Window](https://support.mozilla.org/kb/smart-window)", предоставляющий отдельное пространство взаимодействия с AI, добавлена возможность автозаполнения форм. При клике на поле в web-форме AI предлагает варианты, созданные с учётом открытых вкладок и ранее запомненных данных автозаполнения. Возможность активирована для части пользователей.
- В настройках фона на странице, показываемой при открытии новой вкладки, обеспечено сохранение истории всех загруженных фоновых изображений, а не только самого последнего изображения. Все выбранные пользователем изображения можно посмотреть в секции "Your images".[

- Улучшено сохранение страниц в формате PDF и вывод на печать в Linux и macOS. Решены проблемы с отрисовкой PDF, такие как игнорирование математических символов.
- Реализован перевод на белорусский язык.
- За счёт применения субпиксельного позиционирования прокрутки (без округления до целых экранных пикселей) повышена плавность прокрутки на экранах с высокой плотностью пикселей или при изменении масштаба страницы.
- В CSS-функцию calc() добавлена поддержка[типизированной арифметики](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Values_and_units/Using_typed_arithmetic), позволяющей выполнять арифметические операции с учётом заданных единиц измерения, например, calc(50vw + 2rem), calc(1000px / 2) или calc(40deg + 2rad).
- В API[Notification](https://developer.mozilla.org/en-US/docs/Web/API/Notification/Notification)и метод[ServiceWorkerRegistration.showNotification()](https://developer.mozilla.org/en-US/docs/Web/API/ServiceWorkerRegistration/showNotification)добавлена опция[navigate](https://developer.mozilla.org/docs/Web/API/Notification/navigate), определяющая URL для перехода после клика на уведомление.
- Для элементов ввода с атрибутом 'autocomplete="webauthn"'[реализован](https://html.spec.whatwg.org/multipage/form-control-infrastructure.html#autofill-processing-model)показ[всплывающего](https://github.com/w3c/webauthn/blob/main/explainers/conditional-ui.md)окна беспарольной авторизации по отпечатку пальца или лицу.
- В свойство[PerformanceResourceTiming.deliveryType](https://developer.mozilla.org/docs/Web/API/PerformanceResourceTiming/deliveryType)добавлена поддержка значения "cache" для идентификации ресурсов, полученных из кэша.
- Добавлена поддержка WebGL-расширения[EXT_polygon_offset_clamp](https://registry.khronos.org/webgl/extensions/EXT_polygon_offset_clamp/).
- В версии[Firefox для Android](https://www.firefox.com/en-US/firefox/158.0/releasenotes/)предоставлена возможность размещения панели со списком вкладок в верхней или нижней части окна.
- Сформирована новая редакция Firefox Enterprise, особенности которой описаны в[отдельном обзоре](https://www.opennet.ru/opennews/art.shtml?num=66455).

Кроме новшеств и исправления ошибок, в Firefox 158 устранено[77 уязвимостей](https://www.mozilla.org/en-US/security/advisories/mfsa2026-106/), у 30 из которых выставлен высокий уровень опасности. Большинство уязвимостей вызваны проблемами при работе с памятью, такими как переполнения буферов и обращение к уже освобождённым областям памяти. Потенциально данные проблемы способны привести к выполнению кода злоумышленника при открытии специально оформленных страниц.
