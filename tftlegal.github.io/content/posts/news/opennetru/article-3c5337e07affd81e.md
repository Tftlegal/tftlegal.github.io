# Доступен WaySwitch 1.0, автоматический корректор ввода не в той раскладке клавиатуры

## Краткое содержание

Опубликован первый выпуск приложения WaySwitch, предназначенного для автоматической коррекции текста, введённого в неправильной раскладке клавиатуры или при включённом Caps Lock, а также для исправления частых опечаток. Программа позиционируется как аналог Punto Switcher, но ориентирована на Linux-окружения, работающие по протоколу Wayland. Поддерживается широкий набор сред: GNOME, KDE Plasma, Sway, Hyprland, Xfce, MATE, Budgie и LXQt. Код написан на Python с привлечением AI-инструментов и распространяется под лицензией MIT. Пользовательский интерфейс реализован на библиотеке GTK, при этом доступны отдельный виджет для KDE и модуль для панели Waybar. Готовые пакеты для установки распространяются в форматах deb и rpm.

## Полная статья

[Опубликован](https://github.com/Wetoshkin/WaySwitch/releases/tag/v1.0.0)первый выпуск приложения[WaySwitch](https://github.com/Wetoshkin/WaySwitch), реализующего возможности для автокорректировки текста, введённого не в той раскладке клавиатуры или при включении Caps Lock, а также исправления распространённых опечаток. Программа позиционируется как аналог[Punto Switcher](https://ru.wikipedia.org/wiki/Punto_Switcher), работающий в Linux-окружениях на базе протокола Wayland. Поддерживается работа в GNOME, KDE Plasma, Sway, Hyprland, Xfce, MATE, Budgie и LXQt. Код проекта написан на языке Python с использованием AI-инструментов и[открыт](https://github.com/Wetoshkin/WaySwitch)под лицензией MIT. Графический интерфейс создан с использованием библиотеки GTK, но также доступны виджет для KDE и модуль для панели Waybar. Готовые пакеты[собраны](https://github.com/Wetoshkin/WaySwitch/releases/tag/v1.0.0)в форматах deb и rpm.

Основные возможности:

- Автоматическая корректировка и смена раскладки после нажатия пробела без использования горячих клавиш и без переключения раскладки вручную (например, после ввода "ghbdtn " выполнится замена на "привет " и включится русскоязычная раскладка).
- Автозамена и переключение раскладки по первым четырём латинским буквам, если ввод не соответствует ни одному слову из словаря.
- Ручная корректировка последнего слова по двойному нажатию клавиши Shift и целой фраз по тройному нажатию Shift.
- Исправление выделенного текста, транслитерация (Привет -> Privet) и числа прописью (1250 -> "одна тысяча двести пятьдесят"). Работает только в GNOME.
- Исправление опечаток, таких как две заглавные буквы в начале слова, буквы 'ю' и 'б' вместо точки и запятой, слитное написание частиц, пропущенный пробел.
- Ведение списка исключений для слов и программ (например, запрет на автоисправление в терминале и IDE).

Для перехвата событий ввода используется evdev через /dev/input/event*. При выявлении нажатия пробела фоновый процесс декодирует накопленные в буфере нажатия в текущей и альтернативной раскладках по таблицам libxkbcommon. Решение о замене ввода принимается по словарю и модели символьных триграмм. Исправление производится через симуляцию переключения раскладки, набора Backspace и подстановки нового ввода.
