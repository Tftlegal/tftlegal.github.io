# Релиз фреймворка Qt 6.12 LTS

## Краткое содержание

Компания Qt выпустила релиз фреймворка Qt 6.12.
Это обновление продолжает стабилизацию и расширение возможностей ветки Qt 6.
В новой версии заявлена поддержка Windows 10 и новее, macOS 13 и новее, а также ряда актуальных дистрибутивов Linux.
Поддерживаются мобильные платформы iOS 17+ и Android 9+, а также webOS, WebAssembly и несколько встраиваемых систем.
Среди них упомянуты INTEGRITY, VxWorks, FreeRTOS и QNX.
Исходный код компонентов Qt распространяется по лицензиям LGPLv3 и GPLv2.

## Полная статья

Компания Qt Company[опубликовала](https://www.qt.io/blog/qt-6.12-released)релиз фреймворка[Qt 6.12](https://download.qt.io/development_releases/qt/6.11/), в котором продолжена работа по стабилизации и наращиванию функциональности ветки Qt 6. В Qt 6.12[предоставлена](https://doc-snapshots.qt.io/qt6-6.12/supported-platforms.html)поддержка платформ Windows 10+, macOS 13+, Linux (Ubuntu 22.04/24.04, openSUSE 16, SUSE 15 SP6, RHEL 9.6/10.0, Debian 11.6/12), iOS 17+, Android 9+(API 23+), webOS, WebAssembly, INTEGRITY, VxWorks, FreeRTOS и QNX. Исходный код компонентов Qt[поставляется](https://github.com/qt/qtbase)под лицензиями LGPLv3 и GPLv2.

Qt 6.12 получил статус[LTS-выпуска](https://www.qt.io/development/qt-framework/qt-lts?hsLang=en), для которого обновления будут формироваться в течение пяти лет для обладателей[коммерческой лицензии](https://www.opennet.ru/opennews/art.shtml?num=52259). Для некоммерческих пользователей время сопровождения составит полгода (до формирования нового значительного выпуска). Поддержка прошлой LTS-ветки Qt 6.8 продлится до октября 2029 года, а поддержка позапрошлой LTS-ветки Qt 6.5 прекращена в этом году.

Основные[изменения](https://doc-snapshots.qt.io/qt6-dev/whatsnew612.html)в[Qt 6.12](https://code.qt.io/cgit/qt/qtreleasenotes.git/about/qt/6.12.0/release-note.md):

- Признан готовым для широкого применения модуль[Qt Canvas Painter](https://www.qt.io/blog/2d-rendering-introducing-qt-canvas-painter), предоставляющий API для аппаратно ускоренной отрисовки 2D-контента и использующий шейдеры для создания сложных визуальных эффектов. Отрисовка осуществляется при помощи движка RHI (Rendering Hardware Interface), поддерживающего различные 3D API (OpenGL, Vulkan, Metal и Direct 3D). На базе Canvas Painter реализован экспериментальный элемент Canvas2D, созданный с оглядкой на HTML-спецификацию[Canvas 2D Context](https://html.spec.whatwg.org/multipage/canvas.html#2dcontext)и упрощающий использования JavaScript для отрисовки фигур.[

![](/news/opennetru/article-a769cd50e8a8f18f/image-01.png)

](https://www.qt.io/hs-fs/hubfs/Canvas2D%20Oscillograph.png?width=2696&height=1832&name=Canvas2D%20Oscillograph.png)
- Добавлен экспериментальный модуль[StyleKit](https://doc.qt.io/qt-6/qtlabsstylekit-index.html), явно разделяющий структуру компонентов интерфейса пользователя и атрибуты стилей, что позволяет избавиться от дублирования кода при реализации светлых, тёмных и высококонтрастных тем оформления. StyleKit предоставляет единый QML API для описания стилей, позволяющий добиться единого стиля в гибридных приложениях, сочетающих классические виджеты и элементы на базе Qt Quick.[

![](/news/opennetru/article-a769cd50e8a8f18f/image-02.png)

](https://www.qt.io/hs-fs/hubfs/Qt612-ReleaseBlog-StyleKitDarkModeExample.webp?width=1240&height=1226&name=Qt612-ReleaseBlog-StyleKitDarkModeExample.webp)
- Расширены возможности модуля[Qt Graphs](https://www.qt.io/development/qt-framework/graphs). Для 2D-графиков реализованы новые свойства для кастомизации меток осей и добавлена поддержка логарифмических осей. Добавлены встроенные действия для масштабирования и панорамирования. Добавлена опция для отрисовки при помощи высокопроизводительного бэкенда на базе модуля CanvasPainter, позволяющего визуализировать большие объёмы быстро меняющихся данных.
- В Qt Quick добавлены QML-типы[Safe Area](https://doc.qt.io/qt-6/qml-qtquick-safearea.html),[Context Menu](https://doc.qt.io/qt-6/qml-qtquick-controls-contextmenu.html),[Double Spin Box](https://doc.qt.io/qt-6/qml-qtquick-controls-doublespinbox.html)и[Search Field](https://doc.qt.io/qt-6/qml-qtquick-controls-searchfield.html)для вывода неперекрываемого содержимого, контекстных меню, форм ввода чисел и полей отправки поисковых запросов. Расширен QML-тип[FlexboxLayout](https://doc.qt.io/qt-6/qml-qtquick-layouts-flexboxlayout.html), предназначенный для адаптивной раскладки элементов интерфейса в соответствии с концепцией Flexbox, применяемой в CSS для упрощения вертикального выравнивания элементов.
- В модуль[Vector Image](https://doc.qt.io/qt-6/qml-qtquick-vectorimage-vectorimage.html), позволяющий интегрировать в сцены Qt Quick векторные изображения для создания масштабируемых элементов интерфейса, добавлены дополнительные свойства и возможности анимации для изображений в форматах SVG и Lottie.
- Расширен класс[QRangeModel](https://doc-snapshots.qt.io/qt6-6.12/qrangemodel.html), предоставляющий обвязку над QAbstractItemModel для прямого[использования](https://www.qt.io/blog/a-model-for-all-ranges?hsLang=en)в элементах интерфейса на базе QML и Qt Quick любых перечисляемых типов из C++, включая std::vector, std::tuples и std::array. В новой версии встроена поддержка сортировки данных, реализованы новые свойства для контроля за перемещением в режиме "Drag & Drop", ускорен поиск через метод match(), а также предоставлены настройки для заголовков и отдельных строк/элементов.
- А модуль[gRPC](https://doc-snapshots.qt.io/qt6-6.12/qtgrpc-index.html)добавлены средства для сжатия сообщений на стороне клиента и ограничения размера входящих сообщений от сервера.
- В QML-движке[реализован](https://www.qt.io/blog/hot-reload-in-qt-6.12)механизм Hot Reload, позволяющий редактировать QML-код на лету во время выполнения программы и наблюдать через qmlpreview результат без перезапуска и остановки выполнения приложения.
- Предоставлена LTS-поддержка платформы[HarmonyOS](https://en.wikipedia.org/wiki/HarmonyOS), что упрощает перенос существующих Qt-приложения на смартфоны, планшеты, ПК и автомобильные информационно-развлекательные системы Huawei.
- [Выполнены](https://www.qt.io/development/qt-framework/easier-cra-compliance?hsLang=en)требования европейского закона[Cyber Resilience Act](https://www.opennet.ru/opennews/art.shtml?num=60358)(CRA), нацеленные на поддержание безопасности продукта, оперативное устранение уязвимостей на протяжении жизненного цикла и раскрытие сведений об уязвимостях и инцидентах с безопасностью. В исходном коде выделены компоненты, критически важные с точки зрения безопасности, организована публикация информации о тестировании безопасности и гарантирована интеграция актуальных версий сторонних библиотек.
