# Релиз файлового менеджера Strata 1.0, развиваемого для Omarchy Linux

## Краткое содержание

Вышел релиз файлового менеджера Strata версии 1.0, изначально создававшегося для дистрибутива Omarchy Linux, собравшего около 23 млн долларов на разработку. При этом Strata не привязан к Omarchy и может работать в любых других дистрибутивах Linux. Графический интерфейс построен на библиотеке GTK4 и рассчитан на окружения на базе Wayland. При разработке особое внимание уделялось удобству управления с клавиатуры, безопасности и высокой производительности. Код написан на языке Rust и распространяется под лицензией MIT.

## Полная статья

[Опубликован](https://github.com/lgse/strata/releases/tag/v1.0.0)релиз файлового менеджера[Strata 1.0](https://stratafiles.io/), развиваемого специально для дистрибутива[Omarchy Linux](https://omarchy.org/), собравшего около 23 млн долларов на разработку. При этом проект не привязан к Omarchy Linux и может работать в любых других дистрибутивах. Графический интерфейс формируется с использованием библиотеки GTK4 и рассчитан на работу в окружениях на базе Wayland. Особое внимание при разработке уделяется удобству управления при помощи клавиатуры, безопасности и высокой производительности. Код написан на языке Rust и[распространяется](https://github.com/lgse/strata)под лицензией MIT.

Предоставляется три режима навигации по файловой системе: колонки Миллера, сетка пиктограмм и отсортированный список. В режиме[колонок Миллера](https://en.wikipedia.org/wiki/Miller_columns)по мере перемещения по иерархии ФС каждый новый уровень вложенности открывается в новой вертикальной колонке справа от текущей. Для одновременной работы с разными частями ФС предоставляются вкладки и возможность разделения панели на части.

[

![](/news/opennetru/article-1220de5b172880c9/image-01.png)

](https://github.com/lgse/strata/raw/main/docs/assets/strata-columns.png)

В правой части интерфейса отображается область предпросмотра, позволяющая без открытия нового окна просматривать код, картинки, видео, HTML-файлы и документы, а также прослушивать звуковые файлы. Вызываемые при предпросмотре обработчики выполняются в отдельном процессе, изолированном при помощи прослойки[Bubblewrap](https://www.opennet.ru/opennews/art.shtml?num=66151)(нет доступа к сети, ограничены ресурсы и возможен только доступ на чтение). При отображении видео применяется аппаратное ускорение с привлечением GPU.

Доступна бесшовная навигация по содержимому архивов и возможность обращения к сетевым ресурсам (smb, ftp, sftp, WebDAV) как к виртуальным ФС. Поддерживаются темы оформления, локализация на разные языки, специфичные для разных типов файлов контекстные меню и декорирование, история навигации, фильтрация вывода, рекурсивный и индексируемый поиск имён файлов, удаление файлов в пакетном режиме. Интерфейс не блокируется при выполнении длительных операций, например, можно отменить загрузку при ожидании показа содержимого очень больших директорий. Возможно подключение собственных скриптов для вызова из контекстных меню дополнительных действий с файлами и директориями.
