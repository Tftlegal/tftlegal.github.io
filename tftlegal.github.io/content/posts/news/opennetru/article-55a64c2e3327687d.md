# Графический редактор Affinity портируют для Linux

## Краткое содержание

Компания Canva объявила о подготовке Linux-версии пакета Affinity, предназначенного для редактирования растровых и векторных изображений, а также компьютерной вёрстки. Порт для Linux находится в активной разработке, однако конкретные сроки выхода первого релиза пока не определены. В тот же день была выпущена версия Affinity для планшетов iPad. До этого редактор распространялся исключительно для Windows и macOS. Пользователям Linux оставалось запускать программу через Wine.

## Полная статья

Представители компании Canva[сообщили](https://x.com/Affinity/status/2117276850795790442)о подготовке Linux-версии пакета[Affinity](https://en.wikipedia.org/wiki/Affinity_(software)), предоставляющего возможности для редактирования растровых и векторных изображений, а также компьютерной вёрстки. Утверждается, что порт для Linux находится в активной разработке, но время публикации первого релиза для Linux пока не определено. Помимо этого сегодня[выпущена](https://www.canva.com/newsroom/news/affinity-for-ipad/)редакция Affinity для планшетов iPad. До этого редактор распространялся только для Windows и macOS, а пользователям Linux приходилось[запускать](https://github.com/ryzendew/Linux-Affinity-Installer)его через Wine.

Affinity является одним из основных конкурентов продуктам Adobe Photoshop, Illustrator и InDesign, и отличается высокой производительностью из-за активного использования возможностей GPU и распараллеливания операций по разным ядрам CPU. Пакет пользуется популярностью у дизайнеров, иллюстраторов и фотографов благодаря бесплатной базовой версии с классическим профессиональным набором инструментов, которую можно использовать для личных и коммерческих проектов. Монетизация осуществляется через поставку AI-функций по платной подписке и использование платных сервисов[Canva](https://ru.wikipedia.org/wiki/Canva).
