# Выпуск qBittorrent 5.3.0

## Краткое содержание

Вышел релиз торрент-клиента qBittorrent версии 5.3.0, написанного на C++ с использованием тулкита Qt. Проект позиционируется как открытая альтернатива µTorrent, близкая к нему по интерфейсу и функциональности. Среди ключевых возможностей: встроенный поисковый движок, подписка на RSS, поддержка множества BEP-расширений и удалённое управление через веб-интерфейс. Также доступны последовательная загрузка, расширенные настройки торрентов и пиров, планировщик пропускной способности, IP-фильтр и поддержка UPnP/NAT-PMP. Код распространяется под лицензией GPLv2+. Собираемые версии доступны для Linux, Windows и macOS.

## Полная статья

[Опубликован](https://www.qbittorrent.org/news.php)выпуск торрент-клиента[qBittorrent 5.3.0](https://www.qbittorrent.org/), написанного с использованием тулкита Qt и развиваемого в качестве открытой альтернативы µTorrent, приближенной к нему по интерфейсу и функциональности. Среди возможностей qBittorrent: интегрированный поисковый движок, возможность подписки на RSS, поддержка многих BEP-расширений, удалённое управление через web-интерфейс, режим последовательной загрузки в заданном порядке, расширенные настройки для торрентов, пиров и трекеров, планировщик пропускной способности и IP-фильтр, интерфейс для создания торрентов, поддержка UPnP и NAT-PMP. Код проекта написан на языке С++ и[распространяется](https://github.com/qbittorrent/qBittorrent)под лицензией GPLv2+. Сборки[формируются](https://www.qbittorrent.org/download)для Linux, Windows и macOS.

Среди[изменений](https://github.com/qbittorrent/qBittorrent/releases/tag/release-5.3.0):

- Осуществлён переход на использование по умолчанию библиотеки[libtorrent 2.1.x](https://www.opennet.ru/opennews/art.shtml?num=65886), вместо ветки 1.2.x, поддержка которой сохранена в форме опции, так как бэкенд на базе libtorrent 2.1.x пока отстаёт по производительности операций чтения, что приводит к снижению скорости выгрузки данных с клиента при сидировании.
- [Добавлена](https://github.com/qbittorrent/qBittorrent/pull/24043)опция, позволяющая прервать раздачу только при достижении всех выставленных лимитов.

![](/news/opennetru/article-c8c84c21e197281d/image-01.png)

- В интерфейс создания торрентов[добавлена](https://github.com/qbittorrent/qBittorrent/pull/24346)опция для игнорирования файлов, имена которых начинаются с точки.

![](/news/opennetru/article-c8c84c21e197281d/image-02.png)

- В список пиров[добавлен](https://github.com/qbittorrent/qBittorrent/pull/23989)столбец "Contribution" с информацией о загрузках и скачиваниях для каждого пира.

![](/news/opennetru/article-c8c84c21e197281d/image-03.png)

- В статистику[добавлена](https://github.com/qbittorrent/qBittorrent/pull/24152)метрика для оценки задержек и времени ожидания анонсов трекера.

![](/news/opennetru/article-c8c84c21e197281d/image-04.png)

- В контекстное меню фильтров[добавлен](https://github.com/qbittorrent/qBittorrent/pull/24260)элемент "Force start torrents" для принудительного запуска торрентов.

![](/news/opennetru/article-c8c84c21e197281d/image-05.png)

- В интерфейс[добавлена](https://github.com/qbittorrent/qBittorrent/pull/24090)кнопка "Open Destination Folder" для открытия целевого каталога.
- [Добавлена](https://github.com/qbittorrent/qBittorrent/pull/24304)поддержка указания нескольких получателей email-уведомлений.
- [Добавлена](https://github.com/qbittorrent/qBittorrent/pull/24336)поддержка параметра "so" (select only) в Magnet-ссылках, позволяющего выбирать только определённые файлы из раздачи.
- [Добавлена](https://github.com/qbittorrent/qBittorrent/pull/23829)поддержка фильтрации списка торрентов по хэшу (infohash).
- [Добавлена](https://github.com/qbittorrent/qBittorrent/pull/23157)поддержка блокировки диапазонов адресов, а не только отдельных IP.
- [Добавлены](https://github.com/qbittorrent/qBittorrent/pull/24870)настройки I2P PeX для обмена пирами внутри сети I2P и параметры рандомизации числа hop-ов.
- Реализован параметр[seeding_outgoing_connections](https://github.com/qbittorrent/qBittorrent/pull/24158)для управления исходящими соединениями при сидировании.
- [Переработан](https://github.com/qbittorrent/qBittorrent/pull/24641)код для управления резервными копиями torrent-файлов.
- [Добавлена](https://github.com/qbittorrent/qBittorrent/pull/24776)возможность закрывать вкладки с результатами поиска средней кнопкой мыши.
- В Web-интерфейсе по умолчанию[включён](https://github.com/qbittorrent/qBittorrent/pull/23887)виртуальный список торрентов (в таблицах[отрисовываются](https://github.com/qbittorrent/qBittorrent/issues/23862)только видимые на экране строки), повышена отзывчивость интерфейса, ускорены операции фильтрации вывода, усилена защита от межсайтового скриптинга (CSRF), реализована возможность ограничения числа одновременных активных сессий, добавлена возможность добавления торрента одним кликом (без открытия отдельного диалога), реализован индикатор свободного места на диске, добавлены кнопки для приостановки и возобновления всего сеанса,[появилась](https://github.com/qbittorrent/qBittorrent/pull/24842)возможность импорта и экспорта правил загрузки RSS, обеспечено сохранение вкладок с результатами поиска между перезапусками,[реализовано](https://github.com/qbittorrent/qBittorrent/pull/24984)общее окно управления загрузками RSS.
