# Уязвимости в LXD, Incus, Flatpak, GitLab, Radicle, ядре Linux, WordPress,  OpenVPN, NTFS-3G, FreeRDP, CUPS и Dovecot

## Краткое содержание

Несколько недавно выявленных опасных уязвимостей, позволяющих получить root-доступ в системе или добиться удалённого выполнения кода.

## Полная статья

Несколько недавно выявленных опасных уязвимостей, позволяющих получить root-доступ в системе или добиться удалённого выполнения кода.

- [7 уязвимостей](https://discourse.ubuntu.com/t/security-advisory-multiple-vulnerabilities-found-in-canonical-lxd/88330)в системе управления контейнерами[LXD](https://github.com/canonical/lxd)и[11 уязвимостей](https://discuss.linuxcontainers.org/t/incus-7-5-has-been-released/27273)в форке[Incus](https://linuxcontainers.org/incus/try-it/). Несколько уязвимостей, помеченные как критические, позволяют локальным непривилегированным пользователям изменить любые файлы в системе или выполнить свой код с правами root. Уязвимости устранены в выпусках LXD 6.9, 5.21.8, 5.0.10 и 4.0.14, а также в[Incus 7.5.1](https://github.com/lxc/incus/releases/tag/v7.5.1). Проблемы вызваны некорректной обработкой файловых путей, проблемами при работе с символическими ссылками и отсутствием проверки входных данных в коде для миграции и резервного копирования изолированных окружений или загрузки системных образов:

- [CVE-2026-85526](https://github.com/canonical/lxd/security/advisories/GHSA-h85r-gjgx-g2rv)- перезапись произвольных файлов в системе при обработке резервной копии, содержащей в subvolumes[].path путь к точке монтирования вида "../../../../etc/cron.d".
- [CVE-2026-85185](https://github.com/canonical/lxd/security/advisories/GHSA-27q7-qwhm-c34p)- запись и удаление произвольных файлов через указание в именах подразделов btrfs путей с "../".
- [CVE-2026-87799](https://github.com/canonical/lxd/security/advisories/GHSA-fmc3-3cpq-6whr)- запись в произвольный файл в системе через подстановку символических ссылок при миграции виртуальных машин.
- [CVE-2026-87798](https://github.com/canonical/lxd/security/advisories/GHSA-mr8v-hx34-hfvf)- выход за пределы базового каталога виртуальной машины при рекурсивной передаче файлов.
- [CVE-2026-86334](https://github.com/canonical/lxd/security/advisories/GHSA-g4cm-f533-78hq)- выход за пределы базового каталога при экспортировании образа с внешнего сервера.
- [CVE-2026-86335](https://github.com/canonical/lxd/security/advisories/GHSA-j7p3-5g2v-69j8)- доступ к приватным образам виртуальных машин других пользователей.
- [CVE-2026-97335](https://github.com/canonical/lxd/security/advisories/GHSA-p456-92fx-44xh)- обход ограничений доступа к проектам.

- [Уязвимости](https://www.openwall.com/lists/oss-security/2026/09/22/22)в системе самодостаточных пакетов Flatpak. Проблемы устранены в выпуске Flatpak 1.18.1. Среди наиболее опасных уязвимостей:

- CVE-2026-90616 -[использование](https://github.com/flatpak/flatpak/security/advisories/GHSA-8688-9x26-hhxj)символических ссылок для обхода sandbox-изоляции и получения полного доступа к файловой системе хоста;
- [Повышение](https://github.com/flatpak/flatpak/security/advisories/GHSA-qrwq-7qwx-q9rp)привилегий до пользователя root через подстановку символической ссылки (CVE не назначен);
- CVE-2026-9627 -[запись файлов](https://github.com/flatpak/flatpak/security/advisories/GHSA-fqx6-vh4p-42cg)с правами root через манипуляции с файловыми путями;
- CVE-2026-96275 -[запись файлов](https://github.com/flatpak/flatpak/security/advisories/GHSA-fqx6-vh4p-42cg)с правами root через манипуляции с символическими ссылками;
- CVE-2026-96276 -[запись файлов](https://github.com/flatpak/flatpak/security/advisories/GHSA-8qxj-x646-phcm)с правами root через подстановку "../" в файловые пути при выполнении команды "flatpak build-init";
- CVE-2026-96279 -[чтение произвольных файлов](https://github.com/flatpak/flatpak/security/advisories/GHSA-9rww-v4mm-x4jg)в основной системе через выставление жёсткой ссылки при извлечении архива OCI.
- CVE-2026-92162 -[доступ к файлам](https://github.com/flatpak/flatpak/security/advisories/GHSA-v2gw-v9h5-9q4x)вне базового каталога через подстановку "../" в параметры DeployAppstream.
- CVE-2026-96280 -[переполнение буфера](https://github.com/flatpak/flatpak/security/advisories/GHSA-jr92-2v97-wgvc)в обработчике дельта-обновлений OCI на 32-разрядных системах.

- [Две критические уязвимости](https://docs.gitlab.com/releases/patches/patch-release-gitlab-19-4-1-released/)в платформе для организации совместной разработки GitLab, позволяющие удалённому аутентифицированному пользователю выполнить свой код на сервере через подстановку специально оформленного регулярного выражения в настройки CI/CD. Уязвимости присутствуют в парсере регулярных выражений и вызваны двойным освобождением памяти (CVE-2026-89078) и целочисленным переполнением (CVE-2026-93577). Проблемы устранены в выпусках GitLab 19.4.1, 19.3.3, 19.2.7.
- [Две критические уязвимости](https://radicle.dev/2026/09/23/disclosure-of-vulnerability-in-network-protocol)в сетевом протоколе, применяемом на узлах децентрализованной платформы совместной разработки[Radicle](https://www.opennet.ru/opennews/art.shtml?num=65030). Первая уязвимость позволяет просматривать данные, которыми обмениваются узлы через мониторинг трафика. Вторая уязвимость даёт возможность подделать идентификатор узла и получить доступ к приватным репозиториям. В комбинации уязвимости позволяют извлекать содержимое любых репозиториев с узлов Radicle.
- [Уязвимость](https://security-tracker.debian.org/tracker/CVE-2026-23239)в ядре Linux, вызванная обращением к уже освобождённой памяти (use-after-free) из-за состояния гонки в модуле espintcp, применяемом для инкапсуляции протокола ESP (Encapsulating Security Payload) в TCP ([ESP-in-TCP](https://android.googlesource.com/kernel/common/%2B/7d998f6b7365d/net/xfrm/espintcp.c),[RFC 8229](https://datatracker.ietf.org/doc/html/rfc8229)). Проблема[устранена](https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/commit/?id=e1512c1db9e8794d8d130addd2615ec27231d994)в ядре в феврале перед релизом 7.0. Несколько дней назад для уязвимости был создан[рабочий эксплоит](https://github.com/m0x41nos/RustyTux), позволяющий выполнить код с правами root в системе. Работа эксплоита продемонстрирована в CentOS Stream 9 и Ubuntu 26.04 LTS.
- [Критическая уязвимость](https://github.com/WordPress/wordpress-develop/security/advisories/GHSA-7hp8-65ch-5whp)(CVE-2026-87902) в системе управления контентом WordPress, позволяющая неаутентифицированному посетителю сайта выполнить PHP-код на сервере, через манипуляцию с шаблонами страниц, при наличии на сервере файла pearcmd.php (доступен в официальном docker-образе и в конфигурации cPanel по умолчанию). Проблема также[проявляется](https://forums.classicpress.net/t/critical-unauthenticated-path-traversal-vulnerability-patched-in-wordpress-core/6775)в форке ClassicPress. Уязвимость активно эксплуатируется злоумышленниками для захвата контроля над сайтами. Исправление выпущено для 25 веток WordPress, начиная с 7.1.2 и заканчивая 4.7.37.
- [7 уязвимостей в OpenVPN](https://github.com/OpenVPN/openvpn/releases/tag/v2.6.23), среди которых проблемы, вызванные двойным освобождением памяти ([CVE-2026-84471](https://www.cve.org/CVERecord?id=CVE-2026-84471)), неверным экранированием спецсимволов при запуске командного интерпретатора ([CVE-2026-84256](https://www.cve.org/CVERecord?id=CVE-2026-84256)) и однобайтовым переполнением буфера при разборе опций DHCP ([CVE-2026-81738](https://www.cve.org/CVERecord?id=CVE-2026-81738)). Проблемы устранены в выпуске[OpenVPN 2.6.23](https://github.com/OpenVPN/openvpn/releases/tag/v2.6.23).
- [8 уязвимостей](https://www.openwall.com/lists/oss-security/2026/09/23/4)в пакете NTFS-3G, потенциально позволяющие добиться выполнения кода с правами root при обработке специально оформленных разделов или дисковых образов с ФС NTFS. Все уязвимости вызваны переполнением буфера. Проблемы[устранены](https://github.com/tuxera/ntfs-3g/releases/tag/2026.9.18)в версии NTFS-3G 2026.9.18.
- [Уязвимость](https://www.openwall.com/lists/oss-security/2026/09/01/2)во FreeRDP, позволяющая установить RDP-соединение с сервером без аутентификации. Проблема устранена в выпуске FreeRDP 3.31.0.
- [Уязвимость](https://github.com/containers/bubblewrap/security/advisories/GHSA-pxhw-h44j-8pfx)(CVE-2026-87766) в инструментарии для организации работы изолированных окружений[Bubblewrap](https://github.com/containers/bubblewrap/), позволяющая записать файлы за пределы sandbox-окружения во время настройки контейнера через манипуляции с символическими ссылками.
- Опубликован[эксплоит](https://github.com/v12-security/pocs/tree/main/cups/cups2root)к уязвимости в сервере печати CUPS, позволяющий локальному пользователю получить права root в системе через перезапись файла /etc/cups/cups-files.conf (указав этот файл в качестве URI принтера) и замену вызова cups-exec. Обновление CUPS с исправлением пока[не выпущено](https://github.com/OpenPrinting/cups/tags).
- [Обращение к уже освобождённой памяти](https://documentation.open-xchange.com/dovecot/security/advisories/html/2026/oxdc-adv-2026-0003.html)(CVE-2026-42007) в IMAP-сервере Dovecot, позволяющее аутентифицированному пользователю добиться выполнения своего кода на сервере через использование специально оформленного Sieve-скрипта. Уязвимость устранена в выпуске[Dovecot 2.4.5](https://github.com/dovecot/core/releases/tag/2.4.5).
