# 673 уязвимости в продуктах Oracle

## Краткое содержание

Компания Oracle выпустила плановое обновление Critical Patch Update.  
Оно предназначено для устранения критических проблем и уязвимостей в продуктах компании.  
Сентябрьский выпуск затрагивает большое количество программных компонентов.  
Всего было исправлено 673 уязвимости.  
Обновление помогает снизить риски атак и нестабильной работы ПО.  
Пользователям рекомендуется установить патчи как можно скорее.

## Полная статья

Компания Oracle[опубликовала](https://blogs.oracle.com/security/september-2026-critical-security-patch-update)плановый выпуск обновлений своих продуктов (Critical Patch Update), нацеленный на устранение критических проблем и уязвимостей. В сентябрьском обновлении устранены[673 уязвимости](https://www.oracle.com/security-alerts/cspusep2026.html).

Некоторые проблемы:

- [19 уязвимостей](https://www.oracle.com/security-alerts/cspusep2026.html#AppendixOVIR)в VirtualBox. Самой серьёзной проблеме (CVE-2026-87273) присвоен уровень опасности 8.6 из 10, ещё 5 проблемам, из которых 4 специфичны для Windows, присвоен уровень 7.8 из 10. Судя по уровню опасности указанные уязвимости позволяют получить доступ к хост-окружению из гостевой системы. Проблемы устранены в выпуске[VirtualBox 7.2.18](https://www.opennet.ru/opennews/art.shtml?num=66289).
- В числе продуктов Oracle Communications[отмечена](https://www.oracle.com/security-alerts/cspusep2026.html#AppendixCGBU)одна локально эксплуатируемая уязвимость в сервере MySQL, имеющая уровень опасности 6.5 из 10.
- Из связанных с Java SE проблем[отмечены](https://www.oracle.com/security-alerts/cspusep2026.html#AppendixJAVA)три уязвимости в виртуальной машине[GraalVM](https://www.graalvm.org/), эксплуатируемые удалённо по HTTP (уровень опасности 8.1 из 10).
- В Solaris проблем в отчёте не отмечено и корректирующие выпуски[не сформированы](https://blogs.oracle.com/solaris/category/sol).
