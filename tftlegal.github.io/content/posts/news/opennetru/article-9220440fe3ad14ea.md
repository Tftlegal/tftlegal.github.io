# Выпуск дистрибутива Pop!_OS 26.04, развивающего рабочий стол COSMIC

## Краткое содержание

Компания System76, выпускающая ноутбуки, ПК и серверы с предустановленным Linux, представила новый выпуск дистрибутива Pop!_OS 26.04. Дистрибутив построен на пакетной базе Ubuntu 26.04 и использует собственное окружение рабочего стола COSMIC. Проект распространяется под лицензией GPLv3. ISO-образы доступны для двух архитектур: x86_64 и ARM64. Для x86_64 подготовлены два варианта: стандартный образ объёмом 2,8 ГБ и отдельная сборка для систем с видеокартами NVIDIA. Образ для ARM64 составляет 2,7 ГБ.

## Полная статья

Компания[System76](https://en.wikipedia.org/wiki/System76), специализирующаяся на производстве ноутбуков, ПК и серверов, поставляемых с Linux,[опубликовала](https://system76.com/blog/post/pop_os-26-04-lts-has-landed)выпуск дистрибутива[Pop!_OS 26.04](https://pop.system76.com/). Pop!_OS основан на пакетной базе[Ubuntu 26.04](https://www.opennet.ru/opennews/art.shtml?num=65274)и поставляется с собственным окружением рабочего стола[COSMIC](https://www.opennet.ru/opennews/art.shtml?num=64410). Наработки проекта[распространяются](https://github.com/system76/)под лицензией GPLv3. ISO-образы[сформированы](https://system76.com/download-pop/)для архитектур x86_64 ([2.8 ГБ](https://iso.pop-os.org/26.04/amd64/generic/8/pop-os_26.04_amd64_generic_8.iso")+ отдельная[сборка](https://iso.pop-os.org/26.04/amd64/nvidia/8/pop-os_26.04_amd64_nvidia_8.iso)для систем с GPU NVIDIA) и ARM64 ([2.7 ГБ](https://iso.pop-os.org/26.04/arm64/generic/1/pop-os_26.04_arm64_generic_1.iso)).

Дистрибутив ориентирован на людей, использующих компьютер для создания чего-то нового, например, занимающихся разработкой контента, программных продуктов, 3D-моделей, графики, музыки или научной работой. Компания System76 начала разработку собственной редакции дистрибутива Ubuntu после решения Canonical перевести Ubuntu с Unity на GNOME Shell - разработчики System76 занялись созданием новой темы оформления на базе GNOME, но затем поняли, что готовы предложить пользователям иное окружение рабочего стола, предоставляющего гибкие средства для настройки под текущий рабочий процесс. Изначально пользовательское окружение в Pop!_OS основывалось на модифицированной оболочке GNOME Shell и наборе собственных дополнений, но начиная с прошлого выпуска Pop!_OS проект перешёл на собственную среду рабочего стола COSMIC.

В новой версии:

- Осуществлён переход на пакетную базу[Ubuntu 26.04](https://www.opennet.ru/opennews/art.shtml?num=65274).
- Реализованы созвездия тем оформления (Constellation), позволяющие одним кликом установить полный набор компонентов, влияющих на внешний вид, таких как тема оформления, шрифты, цветовая схема, пиктограммы и обои рабочего стола. Вместо раздельного включения подобных компонентов в разных частях конфигуратора готовый набор теперь можно включить на одной странице "Settings > Desktop > Appearance". Возможен выбор светлого или тёмного режима оформления, точечная настройка отдельных параметров набора и применение эффекта Frosted Glass (размывает фоновое изображение, которое перекрывает окно, в стиле матового стекла по аналогии с эффектом Liquid Glass в macOS).[

![](/news/opennetru/article-9220440fe3ad14ea/image-05.png)

- В состав включена экранная клавиатура ([cosmic-osk](https://github.com/pop-os/cosmic-osk)) для ввода при помощи сенсорных экранов или гёймпадов.

![](/news/opennetru/article-9220440fe3ad14ea/image-06.png)

- Добавлена поддержка удалённого подключения к рабочему столу.
- Расширены средства для людей с ограниченными возможностями, например, добавлена поддержка масштабирования курсора, появилась функция поиска курсора (кратковременное увеличение курсора при быстром движении из стороны в стороны), улучшен инструмент для увеличения областей экрана (лупа).
- Добавлена возможность настройка порядка смены виртуальных рабочих столов при зацикленном переключении между ними.
- Улучшена поддержка полноэкранного режима захвата курсора мыши с его удержанием его внутри окна игры.
- Улучшен автоматический выбор GPU в системах с гибридной графикой (интегрированный GPU + дискретная видеокарта).
