# Выпуск Phosh 0.59, GNOME-окружения для смартфонов

## Краткое содержание

Вышел релиз Phosh 0.59 — экранной оболочки для мобильных устройств, построенной на технологиях GNOME и библиотеке GTK. Изначально проект разрабатывался компанией Purism как аналог GNOME Shell для смартфона Librem 5, а затем стал неофициальным проектом GNOME. Оболочка применяется в Nura (postmarketOS), Mobian, ALT Mobile, Droidian, прошивках для устройств Pine64 и мобильной редакции Fedora. Phosh использует собственный композитный сервер Phoc, работающий поверх Wayland, а также встроенную экранную клавиатуру. Все наработки проекта распространяются под лицензией GPLv3+.

## Полная статья

[Опубликован](https://phosh.mobi/releases/rel-0.59.0/)релиз[Phosh 0.59](https://gitlab.gnome.org/World/Phosh/phosh/), экранной оболочки для мобильных устройств, основанной на технологиях GNOME и библиотеке GTK. Окружение изначально развивалось компанией Purism в качестве аналога GNOME Shell для смартфона Librem 5, но затем вошло в число неофициальных проектов GNOME и задействовано в[Nura](https://www.opennet.ru/opennews/art.shtml?num=61380)(postmarketOS),[Mobian](https://www.opennet.ru/opennews/art.shtml?num=53151),[ALT Mobile](https://www.opennet.ru/opennews/art.shtml?num=65104),[Droidian](https://droidian.org/), некоторых прошивках для устройств Pine64 и редакции[Fedora для смартфонов](https://www.opennet.ru/opennews/art.shtml?num=53822). Phosh использует композитный сервер[Phoc](https://gitlab.gnome.org/World/Phosh/phoc), работающий поверх Wayland, а также собственную экранную клавиатуру. Наработки проекта[распространяются](https://gitlab.gnome.org/World/Phosh/)под лицензией GPLv3+.

Среди[изменений](https://phosh.mobi/releases/rel-0.59.0/):

- В экранной клавиатуре Stevia реализована поддержка голосового ввода (для распознавания речи задействована библиотека[Vosk](https://github.com/alphacep/vosk-api)).
- Добавлена возможность настройки длины PIN-кода для разблокировки экрана.
- В быстрые настройки добавлена кнопка для запуска/остановки SSH-сервера. Добавлена возможность создания скриншотов без вызова внешних утилит. По умолчанию показана кнопка для управления доступом к информации о местоположении.
- В панель добавлен новый плагин с реализацией индикатора активности камеры.
- Ускорена отрисовка миниатюр за счёт переноса большей части связанных с отрисовкой операций на сторону композитного сервера phoc.
- В композитном сервере phoc появилась возможность изменения числа виртуальных рабочих столов на лету. Реализован Wayland-протокол[phoc-foreign-toplevel-identifier-v1](https://gitlab.gnome.org/World/Phosh/phoc/-/commit/dd68607798ed688bcac653b3f73ce5109e8d11b5)для присвоению окнам верхнего уровня не меняющихся уникальных идентификаторов.
- В конфигуратор phosh-mobile-settings добавлены средства настройки плагинов для верхней панели.
- В xdg-desktop-portal-phosh, прослойке для доступа к внешним ресурсам из изолированных окружений, реализована поддержка монтирования USB-накопителей и сетевых хранилищ.
- В мастере первого запуска (phosh-first-boot) появилась новая панель для задания имени устройства. В панель создания пользователей добавлена опция для блокировки учётной записи root.
- В gmobile, набор обработчиков для работы GNOME на мобильных устройствах, добавлена поддержка экранных панелей и кнопок выхода из спящего режима для устройств SHIFT8 и Motorola Moto G10.
- Обновлены версии зависимостей: GNOME 51, ModemManager 1.25.95, wlroots 0.20.2, callaudiod 0.1.10, Calls 51.1, cellbroadcastd 0.0.3, feedbackd 0.8.11, feedbackd-device-themes 0.8.10, iio-sensor-proxy 3.9, mmsd-tng 2.6.4 и wys 0.1.12.
