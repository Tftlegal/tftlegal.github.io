# Исследователи из Anthropic воссоздали формирование seed-параметров стандартных эллиптических кривых ECDSA

## Краткое содержание

Исследователи из компании Anthropic определили происхождение seed-параметров, задающих форму эллиптических кривых ECDSA (P-192, P-224, P-256, P-384, P-521), стандартизированных NIST. Им удалось воссоздать алгоритм, по которому эти параметры были первоначально сгенерированы. Полученный результат подтверждает надёжность стандарта ECDSA. При этом он опровергает популярную конспирологическую теорию о том, что параметры, изначально разработанные в АНБ, были намеренно подобраны для внедрения скрытых уязвимостей. Таким образом, в стандартизированных кривых не было закладывающего backdoor-механизма, компрометирующего алгоритм цифровой подписи.

## Полная статья

Группа исследователей из компании Anthropic[объявила](https://www.anthropic.com/research/ecdsa-curve-origins)об успешном определении происхождения исходных seed-параметров, задающих форму эллиптических кривых[ECDSA](https://ru.wikipedia.org/wiki/ECDSA)P-192, P-224, P-256, P-384 и P-521, стандартизированных Национальным институтом стандартов и технологий США ([NIST](https://ru.wikipedia.org/wiki/%D0%9D%D0%B0%D1%86%D0%B8%D0%BE%D0%BD%D0%B0%D0%BB%D1%8C%D0%BD%D1%8B%D0%B9_%D0%B8%D0%BD%D1%81%D1%82%D0%B8%D1%82%D1%83%D1%82_%D1%81%D1%82%D0%B0%D0%BD%D0%B4%D0%B0%D1%80%D1%82%D0%BE%D0%B2_%D0%B8_%D1%82%D0%B5%D1%85%D0%BD%D0%BE%D0%BB%D0%BE%D0%B3%D0%B8%D0%B9)). Воссозданный алгоритм генерации seed-параметров подтверждает надёжность ECDSA и опровергает популярную конспирологическую теорию о том, что исходные параметры для стандартизированных эллиптических кривых, изначально разработанных в АНБ, были специально подобраны для оставления слабых мест, компрометирующих алгоритмы цифровой подписи ECDSA.

Появлению подобной теории заговора способствовала непрозрачность процесса выбора seed-параметров на фоне[выявление](https://www.opennet.ru/opennews/art.shtml?num=38768)потенциального бэкдора в генераторе псевдослучайных чисел Dual_EC_DRBG, входившем в стандарт NIST. Информация о том, как были сгенерированы параметры для инициализации стандартизированных в NIST эллиптических кривых, не раскрывалась.[Предполагалось](https://saweis.net/posts/nist-curve-seed-origins.html), что параметры были созданы в 1997 году на основе хэшей от фраз, экспромтом придуманных Джерри Солинасом (Jerry Solinas), но затем забытых.

В ходе проведённого в Anthropic исследования AI-модель Claude определила, что seed-параметры были созданы с использованием псевдослучайных чисел, полученных при помощи входящей в стандартную Си-библиотеку функции[lrand48](https://pubs.opengroup.org/onlinepubs/7908799/xsh/drand48.html), инициализированной значениями текущего эпохального времени. Наводкой на возможность использования случайных чисел, полученных через функцию lrand48, послужили характерные для её использования шаблоны, такие как возврат только 31 старшего бита из 48-битного внутреннего состояния генератора псевдослучайных чисел.

Для восстановления состояния генератора псевдослучайных чисел был применён алгоритм[редукции базиса](https://ru.wikipedia.org/wiki/%D0%90%D0%BB%D0%B3%D0%BE%D1%80%D0%B8%D1%82%D0%BC_%D0%9B%D0%B5%D0%BD%D1%81%D1%82%D1%80%D1%8B_%E2%80%94_%D0%9B%D0%B5%D0%BD%D1%81%D1%82%D1%80%D1%8B_%E2%80%94_%D0%9B%D0%BE%D0%B2%D0%B0%D1%81%D0%B0), после чего с имеющимися seed-параметрами перебором сопоставлялись SHA-1 хэши от получаемых через lrand48 наборов чисел необходимой длины. Попытки повторялись c переинициализацией генератора через функцию srand48() для моментов времени в 1997-1998 годах, в которых происходила разработка ECDSA. При этом оказалось, что не все подходящие для надёжных эллиптических кривых значения принимались создателями ECDSA, некоторые значения пропускались, но подобные единичные пропуски трактуются не как злонамеренные действия, а как отсутствие точных сведений о критериях выбора.

![](/news/opennetru/article-f84baecce109057a/image-01.png)

Для шести вариантов эллиптических кривых ECDSA также удалось определить происхождение базовых точек, которые оказались сгенерированы с помощью генератора псевдослучайных чисел из библиотеки[FreeLIP](https://cr.yp.to/speed/mult/freelip.html)с использованием простых значений инициализации, таких как 20000 для P-192 и 20420 для prime239v1.

За определение происхождения seed-параметров исследователям из Anthropic[присуждена](https://words.filippo.io/seeds-solved/)учреждённая три года назад[премия](https://words.filippo.io/seeds-bounty/)в $36864, которую команда исследователей пожертвовала некоммерческой организации ISRG, развивающей проект Let’s Encrypt. Учредивший премию криптограф Филиппо Валсорда (Filippo Valsorda) заявил, что теперь лично ставит кривые ECDSA выше Curve25519, Ed25519 и X25519, и будет рекомендовать их в первую очередь.
