# Релиз дистрибутива Manjaro Linux 27.0

## Краткое содержание

Вышел релиз дистрибутива Manjaro Linux 27.0, основанного на Arch Linux и рассчитанного на начинающих пользователей. Ключевое преимущество — упрощённый процесс установки с автоматическим определением оборудования и установкой необходимых драйверов. Manjaro поставляется в виде live-сборок с графическими окружениями KDE, GNOME и Xfce для архитектуры x86_64. Также планируются сборки для платформ на базе процессоров ARM, которые пока недоступны. При поддержке сообщества дополнительно развиваются версии с окружениями Budgie, Cinnamon, Sway, COSMIC, Deepin, LXQt и i3.

## Полная статья

[Представлен](https://forum.manjaro.org/t/stable-update-2026-11-23-gnome-51-plasma-6-8-cinnamon-6-8-cosmic-1-11-0/191404)релиз дистрибутива[Manjaro Linux 27.0](http://manjaro.org/), построенного на основе Arch Linux и ориентированного на начинающих пользователей. Дистрибутив[примечателен](http://manjaro.org/about/)наличием упрощённого и дружественного пользователю процесса установки, поддержкой автоматического определения оборудования и установки необходимых для его работы драйверов. Manjaro[поставляется](https://manjaro.org/products/download/x86)в виде live-сборок с графическими окружениями KDE, GNOME и Xfce, формируемых для архитектуры x86_64 и различных плат на базе процессоров ARM (в настоящее время сборки ещё недоступны). При участии сообщества[дополнительно](https://osdn.net/projects/manjaro-community/storage/)[развиваются](https://wiki.manjaro.org/index.php?title=Desktop_Environments_and_Window_Managers)сборки с Budgie, Cinnamon, Sway, COSMIC, Deepin, LXQt и i3.

Для управления репозиториями в Manjaro используется собственный инструментарий BoxIt, спроектированный по образу Git. Репозиторий поддерживается по принципу непрерывного включения обновлений (rolling), но новые версии проходят дополнительную стадию стабилизации. Кроме собственного репозитория, имеется поддержка использования[репозитория AUR](https://wiki.archlinux.org/index.php/Arch_User_Repository)(Arch User Repository). Дистрибутив снабжён графическим инсталлятором и графическим интерфейсом для настройки системы.
