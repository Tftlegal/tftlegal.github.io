# В Firefox для iOS встроен блокировщик рекламы

## Краткое содержание

Mozilla объявила о появлении встроенного блокировщика рекламы в Firefox для iOS.
Он блокирует рекламные блоки и код для отслеживания пользователей ещё до их загрузки.
В мобильной версии используется компонент Ad Blocker, а не adblock-rust из настольного Firefox.
Функция отключена по умолчанию.
Пользователи могут сами включить её для защиты от рекламы и трекинга.
