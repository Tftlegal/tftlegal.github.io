# Выпуск системы потокового видеовещания OBS Studio 33.0

## Краткое содержание

Вышел новый выпуск OBS Studio — версия 33.0. Это пакет, предназначенный для потокового вещания, композинга и записи видео. Исходный код написан на языках C и C++. Программа распространяется под лицензией GPLv2. Готовые сборки доступны для трёх платформ: Linux (в формате flatpak), Windows и macOS.

## Полная статья

[Опубликован](https://github.com/obsproject/obs-studio/releases/tag/33.0.0)выпуск[OBS Studio 33.0](https://obsproject.com/), пакета для потокового вещания, композитинга и записи видео. Код написан на языках C/C++ и[распространяется](https://github.com/obsproject/obs-studio/)под лицензией GPLv2. Сборки[сформированы](https://obsproject.com/download)для Linux ([flatpak](https://flathub.org/apps/com.obsproject.Studio)), Windows и macOS.

Целью разработки OBS Studio было создание переносимого варианта приложения[Open Broadcaster Software](https://sourceforge.net/projects/obsproject/)(OBS Classic), не привязанного к платформе Windows, поддерживающего OpenGL и расширяемого через плагины. Отличием также является использование модульной архитектуры, подразумевающей разделение интерфейса и ядра программы. Поддерживается перекодирование исходных потоков, захват видео во время игр и стриминг в PeerTube, Twitch, Facebook Gaming, YouTube, DailyMotion и другие сервисы. Для обеспечения высокой производительности возможно использование механизмов аппаратного ускорения (например, NVENC, Intel QSV, Apple Video Toolbox и VAAPI).

Предоставляется поддержка композитинга с построением сцены на основе произвольных видеопотоков, данных с web-камер, карт захвата видео, изображений, текста, содержимого окон приложений или всего экрана. В процессе вещания допускается переключение между несколькими предопределёнными вариантами сцен (например, для переключения представлений с акцентом на содержимое экрана и изображение с web-камеры). Программа также предоставляет инструменты для микширования звука, фильтрации при помощи VST-плагинов, выравнивая громкости и подавления шумов.

Ключевые[изменения](https://github.com/obsproject/obs-studio/releases/tag/33.0.0):

- Источники вещания на базе браузера ([Browser Source](https://obsproject.com/kb/browser-source)) и панели с web-контентом переведены на новый выпуск инструментария[CEF 150](https://github.com/chromiumembedded/cef)(Chromium Embedded Framework). Ранее использовался CEF 127, выпущенный в июле 2024.
- Полностью[переделана](https://obsproject.com/kb/legacy-plugin-locations)загрузка плагинов. Официальные плагины размещены в отдельном подкаталоге "Core", а неофициальные пока продолжают загружаться из старых мест.
- Улучшено выравнивание (snapping) источников контента в окне предпросмотра. Добавлен новый визуальный индикатор, показывающий по какой границе выровнен элемент. Обеспечена привязка источников по осям, а не только при приближении вплотную к объектам ([видео](https://github.com/obsproject/obs-studio/pull/12298)с демонстрацией). Убрана привязка к скрытым элементам.
- Улучшены поля ввода чисел, ввод в которых больше не блокируется в некоторых ситуациях, а числа не обрезаются. Значения теперь обновляются только по нажатию Enter, которое не закрывает окно. Добавлена поддержка изменения значений нажатием "Shift + ↑/↓". Обеспечена корректная работа курсора при перетаскивании.
- На системах ARM64 включена поддержка ускорения кодирования видео при помощи NVENC (NVIDIA Encoder).
- Для звуковых и видео эффектов NVIDIA задействована новая версия NVIDIA Broadcast SDK.
- В Safe Mode прекращён запуск WebSocket Server.
- В режиме захвата вывода игр улучшено определение полноэкранных игр.
- Улучшено определение прозрачности при захвате экрана macOS.
- Прекращена поддержка Ubuntu 24.04.
