# В конфигурационных файлах curl случайно реализована полнота по Тьюрингу

## Краткое содержание

В утилите Curl выявлена возможность реализации любых вычислимых функций через конструкции в её конфигурационных файлах. Данное свойство проявляется исключительно в версиях Curl 8.12–8.16. Причина — непреднамеренная достижение полноты по Тьюрингу. Конкретно речь идёт о создании машин Тьюринга на базе конфигурационного языка Curl. Ключевыми механизмами служат два фактора: извлечение байтовых диапазонов из значений переменных и неограниченная глубина вложенности при подключении внешних конфигурационных файлов. В совокупности эти возможности позволяют выразить произвольный алгоритмический вычисление. Таким образом, в указанном диапазоне версий Curl фактически превращается в универсальный вычислительную среду через свои конфиги.

## Полная статья

[Выявлена](https://seriot.ch/computation/curl.html)возможность создания любых вычислимых функций при помощи конструкций в файлах конфигурации утилиты[Curl](https://curl.se/). Данная особенность проявляется только в версиях Сurl с 8.12-8.16 и вызвана непреднамеренной реализацией[полноты по Тьюрингу](https://ru.wikipedia.org/wiki/%D0%9F%D0%BE%D0%BB%D0%BD%D0%BE%D1%82%D0%B0_%D0%BF%D0%BE_%D0%A2%D1%8C%D1%8E%D1%80%D0%B8%D0%BD%D0%B3%D1%83), позволяющей создавать[машины Тьюринга](https://ru.wikipedia.org/wiki/%D0%9C%D0%B0%D1%88%D0%B8%D0%BD%D0%B0_%D0%A2%D1%8C%D1%8E%D1%80%D0%B8%D0%BD%D0%B3%D0%B0), используя возможность извлекать байтовые диапазоны из значений переменных и неограниченную глубину вложенности при подключении внешних конфигурационных файлов.

В качестве примера при помощи Curl организована симуляция работы двухсчетчиковой регистровой машины ([машины Минского](https://ru.wikipedia.org/wiki/%D0%9C%D0%B0%D1%88%D0%B8%D0%BD%D0%B0_%D0%9C%D0%B8%D0%BD%D1%81%D0%BA%D0%BE%D0%B3%D0%BE)) для сложения чисел и реализации программы "[99 бутылок пива](https://en.wikipedia.org/wiki/99_Bottles_of_Beer#References_in_computer_science)", используемой при обучении работы с циклами. Для запуска программы, запрограммированной через файлы конфигурации curl, достаточно распаковать[архив](https://seriot.ch/resources/99_bottles.tar.gz)и выполнить команду "curl -q -s -K 99_bottles/main.conf".

Регистровая машина симулируется через представление значения счетчика в виде строки из "n" символов "x". Операции инкремента и декремента реализованы через конкатенацию и усечение строк (синтаксис "[0-0]" для оставления только первого байта и "[1-]" для оставления всего содержимого кроме первого байта), а переходы между состояниями управляются директивой "expand-config", которая динамически подгружает следующий файл конфигурации, используя его имя в качестве метки перехода. Операция INC(R) в регистровой машине реализуется как 'expand-variable = "r={{r}}x"' в файле конфигурации Curl, DEC(R) - как 'expand-variable = "r[1-]={{r}}"', а JMP(S) - как 'expand-config = "S.conf"'. На практике реализуемые через файлы конфигурации вычислительные возможности ограничены размером стека, так как каждый шаг выполнения программы требует загрузки нового вложенного файла конфигурации. При стеке в 8 МБ переполнение возникает примерно после 922 шагов. На возможности также влияет ограничение на размер раскрываемых переменных (параметр MAX_EXPAND_CONTENT выставлен в 10 МБ) и большое потребление памяти из-за сохранения всех старых версий переменных.

Несмотря на то, что выявленная возможность не является уязвимостью, в версиях начиная с[curl 8.17](https://github.com/curl/curl/releases/tag/curl-8_17_0)рассматриваемый трюк уже не сработает из-за[ограничения](https://github.com/curl/curl/pull/19168)глубины вложенности файлов конфигурации[5 уровнями](https://github.com/curl/curl/blob/curl-8_17_0/src/tool_parsecfg.h#L28-L30)для защиты от бесконечной рекурсии.
