# Релиз FreeBSD 14.5

## Краткое содержание

Через шесть месяцев разработки был выпущен FreeBSD 14.5.
Установочные образы доступны для архитектур amd64, i386, aarch64, armv7, powerpc, powerpc64 и riscv64.
Дополнительно подготовлены сборки для систем виртуализации в форматах QCOW2, VHD, VMDK и raw.
Также доступны образы для облачных окружений Amazon EC2, Google Compute Engine и Vagrant.
Таким образом, релиз ориентирован на широкий набор платформ и типов развёртывания.

## Полная статья

После шести месяцев разработки[сформирован](https://www.freebsd.org/releases/14.5R/announce/)релиз[FreeBSD 14.5](https://www.freebsd.org). Установочные образы[подготовлены](https://download.freebsd.org/ftp/releases/ISO-IMAGES/14.5/)для архитектур amd64, i386, aarch64, armv7, powerpc, powerpc64 и riscv64. Дополнительно подготовлены сборки для систем виртуализации (QCOW2, VHD, VMDK, raw) и облачных окружений Amazon EC2, Google Compute Engine и Vagrant.

Следующее обновление FreeBSD 14.6[запланировано](https://www.freebsd.org/releng/)на март 2027 года. Поддержка нынешнего выпуска FreeBSD 14.5 будет[осуществляться](https://www.freebsd.org/security/)до 30 июня 2027 года, а прошлого выпуска FreeBSD 14.4 - до 31 декабря 2026 года. В целом ветка FreeBSD 14 будет сопровождаться до 30 ноября 2028 года. Поддержка ветки FreeBSD 13.x была прекращена 30 апреля 2026 года. Параллельно развивается ветка FreeBSD 15, актуальный выпуск 15.1 для которой был[опубликован](https://www.opennet.ru/opennews/art.shtml?num=65697)три месяца назад.

Основные[изменения](https://www.freebsd.org/releases/14.5R/relnotes/)во FreeBSD 14.5:

- В ядре[реализован](https://cgit.freebsd.org/src/commit/?id=296d7f95aab8)Linux-совместимый механизм inotify для отслеживания изменений в файловых системах. В libc[добавлены](https://cgit.freebsd.org/src/commit/?id=e61884183ed4)функции inotify_init, inotify_init1 и inotify_add_watch.
- [Добавлена](https://cgit.freebsd.org/src/commit/?id=c839c1566147)sysctl-настройка security.bsd.unprivileged_kenv_read для запрета непривилегированного доступа к переменным окружения ядра (kenv).
- В драйвер ФС[msdosfs](https://man.freebsd.org/cgi/man.cgi?query=msdosfs&sektion=4&format=html)добавлена возможность использования Unicode-символов в именах файлов (налажена работа с разделами FAT32 с emoji в именах файлов).
- В скрипте rc.firewall[реализована](https://cgit.freebsd.org/src/commit/?id=10075baae2c1)поддержка подстановки в переменные firewall_allowservices и firewall_trusted содержимого внешних файлов со списками IP-адресов и подсетей.
- В программу для работы с ленточными накопителями[mt](https://man.freebsd.org/cgi/man.cgi?query=mt&sektion=1&format=html)и библиотеку libmt добавлена поддержка картриджей LTO-10 и LTO-10P, а также новых форматов.
- Изменено поведение утилиты вывода текущего пути pwd, которая в соответствии со спецификациями POSIX теперь по умолчанию использует режим отображения имён символических ссылок (-L) вместо показа пути на который указывают символические ссылки (-P).
- В утилиту ipfw добавлен обработчик для вызова утилиты ipfw15 при запуске в системе с новым программным интерфейсом пакетного фильтра, появившемся в ядре FreeBSD 15.
- В утилиту[daemon](https://man.freebsd.org/cgi/man.cgi?query=daemon&sektion=8&format=html)добавлена опция "-m" для указания режима доступа к записываемому файлу для предоставления доступа обработчиков, запускаемых без прав root.
- В скрипте local-unbound-setup реализована поддержка настройки DNS для систем, в которых используется только IPv6.
- В заголовочный файл math.h добавлены предложенные в стандарте C23 тригонометрические функции sinpi, cospi и tanpi, умножающие переданный аргумент на число Pi.
- Обновлён драйвер[smartpqi](https://man.freebsd.org/cgi/man.cgi?query=smartpqi&sektion=4&format=html), в который добавлена поддержка новых контроллеров Microchip Smart Storage SCSI и предоставлена возможность указания 32-разрядных значениях при определении размера буфера ввода/вывода.
- В драйвер[acpi](https://man.freebsd.org/cgi/man.cgi?query=acpi&sektion=4&format=html)добавлена поддержка дополнительных вариантов контроллеров Marvell 88SE9128 SATA (решило проблемы с работой на материнской плате Gigabyte GA-P55A-UD4) и реализована возможность управления энергопотреблением на системах Apple Mac с двумя GPU (включается через sysctl-параметр hw.acpi.apple_darwin_osi).
- В драйвере[asmc](https://man.freebsd.org/cgi/man.cgi?query=asmc&sektion=4&format=html)прекращена поддержка 32-разрядных устройств Apple Mac с CPU Intel.
- В загрузчик lualoader[добавлены](https://cgit.freebsd.org/src/commit/?id=bddfcbd9bbc6)команды be-list и be-switch для просмотра и переключения загрузочных окружений. Обеспечена обработка символических ссылок при поиске загружаемых ядер.[Добавлен](https://cgit.freebsd.org/src/commit/?id=9ef671ef0c6c)callback-обработчик для фильтрации загрузочных окружений в запускаемых загрузчиком Lua-скриптах.
- В инсталляторе bsdinstall[обеспечено](https://cgit.freebsd.org/src/commit/?id=cfdd90abab51)корректное создание загрузочной записи FreeBSD UEFI.
- Модули ядра nvidia, nvidia-modeset и nvidia-drm добавлены в чёрный список загрузчика для избежания аварийного завершения в случае их ранней загрузки через loader.conf.
- Обновлены версии сторонних компонентов: LLVM/Clang 21.1.8, OpenSSL 3.0.21, unbound 1.26.0, Expat 2.8.1, file 5.47, ldns 1.9.2, less 704, libarchive 3.8.7, libpcap 1.10.6, ncurses 6.6, openresolv 3.17.4, NSS 3.123.1, tcpdump 4.99.6, xz 5.8.3.
- В качестве компоновщика при использовании Clang по умолчанию задействован ld.lld (LLD) вместо промежуточного обработчика, определяющего компоновщик с учётом порядка обнаружения при поиске в файловых путях PATH. Старый подход приводил к замене фактически применяемого во FreeBSD компоновщика ld.lld в случае дополнительной установки в систему GNU ld.
- В разряд устаревших переведён набор программ lpr, который будет удалён в выпуске FreeBSD 16.0. Вместо lpr рекомендовано использовать порт print/cups или sysutils/LPRng. В фоновом процессе lpd решена проблема с игнорированием номера порта из /etc/printcap при использовании IPv6.
