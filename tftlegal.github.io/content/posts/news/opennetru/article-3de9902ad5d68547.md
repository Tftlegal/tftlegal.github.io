# Уязвимость в Apache httpd, зксплуатируемая через HTTP/2 для удалённого выполнения кода

## Краткое содержание

Вышел релиз HTTP-сервера Apache 2.4.71, закрывающий критическую уязвимость (CVE-2026-119618) в модуле mod_http2. Суть проблемы: злоумышленник может выполнить произвольный код на сервере, отправив специально сформированный HTTP/2-запрос. Уязвимость затрагивает все версии Apache httpd начиная с 2.4.55, а также отдельный модуль mod_h2, распространяемый через GitHub. Для оценки статуса исправления в конкретных дистрибутивах указаны ссылки на страницы Debian, Ubuntu, SUSE, RHEL, Gentoo и Arch. Пользователям данных версий рекомендуется как можно быстрее обновить сервер до 2.4.71.

## Полная статья

[Опубликован](https://www.mail-archive.com/announce@httpd.apache.org/msg00203.html)релиз HTTP-сервера[Apache 2.4.71](https://httpd.apache.org/), в котором устранена[уязвимость](https://httpd.apache.org/security/vulnerabilities_24.html)([CVE-2026-119618](https://security-tracker.debian.org/tracker/CVE-2026-119618)) в модуле mod_http2, которой присвоен критический уровень опасности. Уязвимость позволяет удалённо выполнить свой код на сервере при отправке специально оформленного запроса по протоколу HTTP/2. Уязвимость проявляется начиная с версий Apache httpd 2.4.55 и также затрагивает отдельный модуль[mod_h2](https://github.com/icing/mod_h2), распространяемый через GitHub. Статус устранения уязвимостей в дистрибутивах можно оценить на данных страницах:[Debian](https://security-tracker.debian.org/tracker/CVE-2026-119618),[Ubuntu](https://people.canonical.com/~ubuntu-security/cve/CVE-2026-119618),[SUSE](https://bugzilla.suse.com/show_bug.cgi?id=CVE-2026-119618),[RHEL](https://bugzilla.redhat.com/show_bug.cgi?id=CVE-2026-119618),[Gentoo](https://bugs.gentoo.org/show_bug.cgi?id=CVE-2026-119618),[Arch](https://security.archlinux.org/package/apache),[Fedora](https://koji.fedoraproject.org/koji/packageinfo?packageID=280),[FreeBSD](https://www.vuxml.org/freebsd/).

Проблема[вызвана](https://github.com/apache/httpd/commit/824beab9b9424d6cfb29595248fdbf6c3dddeab1)состоянием гонки при одновременном вызове функции assign_headers() из разных потоков, возникающем из-за обработки функцией общей для всех потоков структуры (req->headers), а не отдельной для каждого потока копии (r->headers_in). При успешной эксплуатации атакующий может добиться изменения памяти вне выделенного буфера. Уязвимость примерно в одно время выявлена исследователями из компаний Anthropic и Google. Рабочий эксплоит[продемонстрирован](https://access.redhat.com/security/cve/cve-2026-119618)исследователями для сервера с mod_http2 в конфигурации по умолчанию, но пока не опубликован публично. В качестве обходного пути блокирования уязвимости достаточно отключить обработку соединений по протоколу HTTP/2 в файле конфигурации httpd.conf через директиву "Protocols http/1.1".

В соответствии с сентябрьским[отчётом](https://www.netcraft.com/blog/september-2026-web-server-survey)компании Netcraft под управлением Apache httpd работает около 170 млн сайтов (11.56%). На каких из них используется HTTP/2 не сообщается.
