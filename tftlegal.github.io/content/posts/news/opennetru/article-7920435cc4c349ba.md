# Уязвимости в MikroTik RouterOS, допускающие удалённый доступ по SSH без аутентификации

## Краткое содержание

В операционной системе RouterOS для маршрутизаторов MikroTik обнаружено шесть уязвимостей.
Сочетание двух из них позволяет злоумышленнику удалённо захватить устройство с администраторскими правами, если оно доступно по SSH.
Уже зафиксированы реальные случаи эксплуатации этих уязвимостей.
Mikrotik выпустила исправления 3 сентября в версиях RouterOS 7.25 beta 3, 7.24.2, 7.23.4 и 6.49.21.
Вероятно, атакующие смогли определить суть уязвимостей по этим патчам.
