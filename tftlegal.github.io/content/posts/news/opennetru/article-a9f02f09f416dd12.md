# 18 уязвимостей в ядре Linux c эксплоитами для получения прав root в системе

## Краткое содержание

Специалисты Nebula Security обнаружили 18 уязвимостей в ядре Linux.  
Они также разработали эксплойты для этих уязвимостей.  
Эти эксплойты позволяют непривилегированному локальному пользователю получить права root.  
Уязвимости были устранены в различных обновлениях ядра весной и летом.  
Текст описывает выявленные проблемы и их опасность для локальной безопасности системы.

## Полная статья

Исследователи из компании Nebula Security[раскрыли](https://www.openwall.com/lists/oss-security/2026/09/08/1)сведения о 18 уязвимостях в ядре Linux и подготовили для них[эксплоиты](https://github.com/NebuSec/CyberMeowfia/tree/main/security-research), позволяющие непривилегированному локальному пользователю получить права root в системе. Уязвимости устранены в различных весенних и летних[обновлениях ядра](https://www.kernel.org/). Выявленные проблемы:

- [CVE-2026-43502](https://security-tracker.debian.org/tracker/CVE-2026-43502)([эксплоит](https://github.com/NebuSec/CyberMeowfia/tree/main/security-research/Linux-CVE-2026-43502-openSUSE-6.4.0-150600)) - уязвимость в сетевой подсистеме RDS (Reliable Datagram Sockets), вызванная некорректной очисткой закреплённых страниц памяти при сбое отправки данных в режиме zerocopy на этапе до постановки сообщения в очередь. Проблема получила кодовое имя ZcopyReaper, проявляется начиная с версии ядра 4.17 и[устранена](https://git.kernel.org/linus/44b550d88b267320459d518c0743a241ab2108fa)в ядре в мае. Эксплуатации уязвимости возможна на системах с ядром, собранным с опциями CONFIG_INET=y, CONFIG_AIO=y, CONFIG_RDS=y|m и CONFIG_RDS_TCP=y|m (как правило выставляются по умолчанию). Прав для работы с пространствами имён идентификаторов пользователей для атаки не требуется. Работа эксплоита продемонстрирована в openSUSE со штатным ядром 6.4.
- [CVE-2026-80714](https://security-tracker.debian.org/tracker/CVE-2026-80714)([эксплоит](https://github.com/NebuSec/CyberMeowfia/tree/main/security-research/Linux-CVE-2026-80714-Debian-6.12.101)) - уязвимость в подсистеме IPVS (IP Virtual Server), вызванная обращением к памяти после её освобождения из-за ошибочного выставления флага IP_VS_CONN_F_ONE_PACKET при синхронизации соединения, которое после истечения времени жизни соединения приводит к оставлению в хэш-таблице висячих указателей, ссылающихся на уже освобождённую структуру ip_vs_conn. Проблема[устранена](https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/commit/?id=06d1d9b56ef8132fbf85006885eb43d9510b8b02)19 августа. Работа эксплоита продемонстрирована в Debian 13 c ядром 6.12.
- [CVE-2026-74597](https://security-tracker.debian.org/tracker/CVE-2026-74597)([эксплоит](https://github.com/NebuSec/CyberMeowfia/tree/main/security-research/Linux-CVE-2026-74597-Centos-10-6.12.0-264)) - уязвимость в драйвере ip6_tunnel, вызванная ошибочным применением к инкапсулированному пакету смещения для опции HAO (Home Address Option), вычисленного на основании внешнего пакета. Через передачу инкапсулированного пакета со специально оформленным заголовком можно добиться записи данных за пределы выделенного буфера. Проблема[устранена](https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/commit/?id=0dadb0620ab65949a8bc2439dd28ea3c942fe87d)19 августа. Работа эксплоита продемонстрирована в CentOS c ядром 6.12.
- [CVE-2026-74581](https://security-tracker.debian.org/tracker/CVE-2026-74581)([эксплоит](https://github.com/NebuSec/CyberMeowfia/tree/main/security-research/Linux-CVE-2026-74581-Debian-6.12.101)) - уязвимость в коде для работы с таблицами маршрутизации IPv6, вызванная обращением к памяти после её освобождения (после освобождения памяти под маршрут оставался активный указатель на этот маршрут). Проблема[устранена](https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/commit/?id=354db6243eca59e9d187ffbf8b7955b044ce84dc)19 августа. Работа эксплоита продемонстрирована в Debian 13 c ядром 6.12.
- [CVE-2026-74480](https://security-tracker.debian.org/tracker/CVE-2026-74480)([эксплоит](https://github.com/NebuSec/CyberMeowfia/tree/main/security-research/Linux-CVE-2026-74480-RHEL-6.12.0-211.7.3.el10_2)) - уязвимость в подсистеме сетевых мостов, вызванная обращением к памяти после её освобождения в коде выхода из multicast-группы (после удаления элемента из связного списка цикл не прерывался и в ходе итераций производилось обращение по указателю на список портов, оставшемуся после удаления). Проблема[устранена](https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/commit/?id=0309ebbc570000ea0df11c06b69798e5860c5f6f)9 августа. Работа эксплоита продемонстрирована в RHEL 10 c ядром 6.12.
- [CVE-2026-72255](https://security-tracker.debian.org/tracker/CVE-2026-72255)([эксплоит](https://github.com/NebuSec/CyberMeowfia/tree/main/security-research/Linux-CVE-2026-72255-Ubuntu-7.0.0-28)) - уязвимость в модуле nf_queue подсистемы netfilter, вызванная обращением к памяти после её освобождения, возникающим в ситуации, если после удаления сетевого моста связанный с ним пакет ещё находился в очереди NFQUEUE. - [CVE-2026-68376](https://security-tracker.debian.org/tracker/CVE-2026-68376)([эксплоит](https://github.com/NebuSec/CyberMeowfia/tree/main/security-research/Linux-CVE-2026-68376-Ubuntu-7.0.0-30)) - уязвимость в реализации протокола SCTP, приводящая к переполнению буфера из-за некорректного расчёта размера массива для хранения HMAC-идентификаторов.
