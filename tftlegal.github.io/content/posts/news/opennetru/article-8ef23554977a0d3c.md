# Выпуск пользовательского окружения Dux Shell 2.0

## Краткое содержание

Выпущено пользовательское окружение Dux Shell 2.0, работающее поверх композитных серверов niri, Hyprland, Sway, MangoWC, labwc, Scroll, Aqueous и Miracle WM. Это первый релиз после переименования проекта из DankMaterialShell (DMS) в Dux Shell. Новое название проще, отсылает к пингвину Tux и не содержит чужого бренда. Dux Shell представляет собой набор согласованных между собой компонентов рабочего стола: панель задач, переключатель виртуальных рабочих столов, навигатор по приложениям и конфигуратор. Оформление окружения выдержано в концепции Material Design 3.

## Полная статья

[Опубликован](https://github.com/duxlabs-dev/dux-shell/releases/tag/v2.0.0)релиз пользовательского окружения[Dux Shell 2.0](https://duxlabs.dev), поддерживающего работу поверх композитных серверов niri, Hyprland, Sway, MangoWC, labwc, Scroll, Aqueous и Miracle WM. Это первый выпуск после переименования проекта DankMaterialShell (DMS) в Dux Shell. Новое имя проще, созвучно с пингвином Tux и не включает в часть названия чужого бренда. Dux Shell развивает набор сочетающихся между собой компонентов для формирования рабочего стола, таких как панель задач, переключатель виртуальных рабочих столов, интерфейс навигации по установленным приложениям и конфигуратор. Оформление соответствует концепции Material Design 3.

Dux Shell поддерживает динамические темы оформления, автоматически применяемые к GTK, Qt и системным приложениям. Цветовые схемы для тем формируются с учётом цвета выбранных обоев рабочего стола. Имеется возможность включения ночного режима работы, а также переключения между светлой и тёмной темами оформления. Функциональность может расширяться через[плагины](https://github.com/AvengeMedia/dms-plugin-registry). Код фонового процесса для интеграции с системой, инструментария и инсталлятора написаны на языке Go и[распространяются](https://github.com/duxlabs-dev/dux-shell/tree/master/core)под лиценизей MIT. Компоненты интерфейса, панели, виджеты и графические приложения[подготовлены](https://github.com/duxlabs-dev/dux-shell/blob/master/quickshell)на языке QML с применением фреймворка[Quickshell](https://quickshell.org/),[написанного](https://github.com/quickshell-mirror/quickshell)на C++ с использованием Qt.

В состав входят:

- Панель с виджетами для календаря, прогноза погоды, просмотра истории работы с буфером обмена и интеграции с мультимедийными проигрывателями при помощи протокола MPRIS.
- Интерфейс для навигации по установленным в системе приложениям с поддержкой поиска программ, файлов, открытых окон и команд.
- Центр управления с интерфейсом для настройки сети, Bluetooth, звуковых устройств и экрана.
- Встроенные в управляющий фоновый процесс средства сбора метрик о температуре и потреблении ресурсов CPU, ОЗУ и GPU. Наличие интерфейса для управления запущенными процессами.
- Центр уведомлений, поддерживающий группировку уведомлений, использование разметки в тексте и навигацию при помощи клавиатуры.
- Экран блокировки системы с возможностями управления сеансом. Возможна активация спящего режима или блокировка экрана при определённом периоде неактивности пользователя.
- Экран входа в систему[Dux Greeter](https://github.com/AvengeMedia/dank-greeter).
- Универсальный инсталлятор, позволяющий развернуть и настроить окружение на базе Dux Shell в Arch, Fedora, Debian, Ubuntu, openSUSE, Gentoo и Void Linux.
- Инструментарий[Dux Search](https://github.com/AvengeMedia/danksearch)для поиска файлов в системе.
- Календарь-планировщик[Dux Calendar](https://github.com/AvengeMedia/dankcalendar), поддерживающий протокол CalDAV и синхронизируемый с сервисами Google и Microsoft.
- Файловый менеджер Dux Files.
- Приложение DuxConnect для интеграции со смартфоном.
