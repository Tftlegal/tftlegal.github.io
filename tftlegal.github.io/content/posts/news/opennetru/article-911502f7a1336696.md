# Cloudflare поглотила JavaScript-платформу Deno и прекратит её разработку

## Краткое содержание

Компания Cloudflare приобрела Deno Land Inc — фирму, развивающую платформу Deno. В течение ближайшего года будут выходить корректирующие релизы Deno runtime и обновления с устранением уязвимостей. По истечении этого срока разработка Deno будет официально прекращена. Исходный код Deno при этом останется открытым. Сообщество разработчиков при наличии интереса сможет самостоятельно продолжить развитие платформы.

## Полная статья

Компания Cloudflare[купила](https://blog.cloudflare.com/deno-joins-cloudflare/)фирму Deno Land Inc, развивающую платформу[Deno](https://deno.com). Корректирующие релизы[Deno runtime](https://github.com/denoland/deno/)и обновления с устранением уязвимостей планируют публиковать ещё год, после чего разработка Deno будет[прекращена](https://deno.com/blog/cloudflare). Код Deno останется открытым и при наличии интереса сообщество сможет своими силами продолжить развитие платформы.

Что касается других разработок компании Deno Land, то проект[celld](https://celld.dev/), позволяющий запускать Worker-приложения на своих серверах, будет интегрирован с платформой[Cloudflare Workers](https://www.cloudflare.com/products/workers/). Платформа[Deno Deploy](https://deno.com/deploy)будет поддерживаться ещё шесть месяцев, после чего прекратит существование, а платным пользователям обеспечат миграцию на Cloudflare Workers. Репозиторий пакетов[JSR](https://jsr.io/)(JavaScript Registry) продолжит работу, но связанная с ним инфраструктура будет перенесена в Cloudflare. Поддержка[rusty_v8](https://github.com/denoland/rusty_v8), Rust-обвязок для движка V8, будет продолжена, но разработка будет интегрирована с JavaScript runtime[workerd](https://github.com/cloudflare/workerd).

Разработчики Deno переключатся на работу над self-hosting вариантом платформы[Cloudflare Workers](https://www.cloudflare.com/products/workers/)и возможностями для разработки приложений с использованием механизма[Durable Objects](https://developers.cloudflare.com/durable-objects/). Основная идея в том, чтобы сделать модель программирования на основе Worker-ов пригодной для разработки серверных приложений, которые можно запускать не только в сети Cloudflare, но и в собственной инфраструктуре.

Платформа Deno[предназначена](https://www.opennet.ru/opennews/art.shtml?num=62024)для обособленного выполнения серверных приложений на языках JavaScript и TypeScript с использованием движка[V8](https://v8.dev/). Проект возглавлял Райан Даль ([Ryan Dahl](https://en.wikipedia.org/wiki/Ryan_Dahl)), создатель Node.js. Новая платформа была создана с целью предоставления более[защищённого окружения](https://docs.deno.com/runtime/fundamentals/security/)и устранения концептуальных ошибок,[допущенных](https://www.youtube.com/watch?v=M3BM9TB-8yA)в архитектуре Node.js. Для повышения безопасности обвязка вокруг движка V8 написана на языке Rust, а для обработки запросов в неблокирующем режиме применяется платформа[Tokio](https://www.opennet.ru/opennews/art.shtml?num=56072). Runtime поставляется в форме одного самодостаточного исполняемого файла ("deno"), не имеющего внешних зависимостей и не требующего какой-то особой установки в систему. Кроме runtime платформа Deno также выполняет роль пакетного менеджера и позволяет внутри кода обращаться к модулям по URL.
