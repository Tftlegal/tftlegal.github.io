# Выпуск PorteuX 2.9, дистрибутива на основе Slackware

## Краткое содержание

Опубликована новая версия дистрибутива PorteuX 2.9, основанного на Slackware и вдохновлённого проектами Slax и Porteus. Дистрибутив предлагает преднастроенные среды рабочего стола: Cinnamon, COSMIC, GNOME, KDE, LXDE, LXQt, MATE и Xfce. Поддерживается аппаратное ускорение обработки мультимедиа на GPU Intel, AMD и NVIDIA, а загрузка в Live-режиме занимает всего 3 секунды. Системный образ работает в режиме только для чтения, при этом приложения можно доустановить через PorteuX App Store. Также реализованы откат обновлений, загрузка в ОЗУ (copy2ram) и сетевая загрузка. Готовые ISO-образы имеют размер 625 МБ для Cinnamon и 801 МБ для COSMIC.
