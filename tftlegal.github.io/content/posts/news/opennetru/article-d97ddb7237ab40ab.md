# Microsoft опубликовал стабильный выпуск дистрибутива Azure Linux 4.0

## Краткое содержание

Microsoft объявила о выходе первой стабильной версии дистрибутива Azure Linux 4.0, готового к широкому применению. Дистрибутив поддерживает интеграцию с WSL, Azure Kubernetes Service, Azure App Service и Azure Cosmos DB. Компания позиционирует Azure Linux 4 как универсальное решение, оптимизированное для платформы Azure. Он пригоден для использования в виртуальных машинах, контейнерах, узлах кластеров Kubernetes и системах разработчиков. Специфичные для дистрибутива изменения распространяются по лицензии MIT. Сборки доступны через каталоги Azure Marketplace и Microsoft Artifact Registry.

## Полная статья

Компания Microsoft[объявила](https://techcommunity.microsoft.com/blog/linuxandopensourceblog/azure-linux-4-is-generally-available/4573381)о готовности первой стабильной версии дистрибутива[Azure Linux 4.0](https://learn.microsoft.com/en-us/azure/azure-linux/intro-azure-linux), признанной готовой для широкого применения в виртуальных машинах и контейнерах. Поддерживается интеграция с[WSL](https://learn.microsoft.com/azure/azure-linux/windows-subsystem-for-linux-overview)(Windows Subsystem for Linux), Azure Kubernetes Service, Azure App Service и Azure Cosmos DB. Ветка Azure Linux 4 преподносится как универсальное решение, оптимизированное для платформы Azure и пригодное для использования во всех связанных с ней сферах, от виртуальных машин и контейнеров до узлов в кластере Kubernetes и систем разработчиков. Специфичные для дистрибутива изменения[поставляются](https://github.com/microsoft/azurelinux/tree/4.0)под лицензией MIT. Сборки распространяются через каталоги[Azure Marketplace](https://marketplace.microsoft.com/en-us/product/microsoftazurelinux.azurelinux-4?tab=Overview)и[Microsoft Artifact Registry](https://mcr.microsoft.com/en-us/artifact/mar/azurelinux/core/tags).

По сравнению с[Azure Linux 3.0](https://www.opennet.ru/opennews/art.shtml?num=65419)новая ветка переведена с собственной пакетной базы на использование пакетов из дистрибутива Fedora. В качестве основы используются штатные SRPM-пакеты из репозиториев Fedora, для которых поставляется набор[оверлеев](https://github.com/microsoft/azurelinux/tree/4.0/base/comps/)- файлов конфигурации в формате TOML, дающих возможность пересобирать пакеты с дополнениями, оптимизациями и изменениями, необходимыми для Azure Linux. Для генерации результирующих RPM-пакетов на основе SRPM-пакетов Fedora и оверлеев применяется инструментарий[azldev](https://github.com/microsoft/azure-linux-dev-tools), написанный на языке Go и поставляемый под лицензией MIT. Система сборки Azure Linux даёт возможность генерировать как классические установочные окружения с RPM-пакетами, так и монолитные атомарно обновляемые системные образы.

В Azure Linux 4.0 поставляется ядро Linux 6.18 с дополнительными оптимизациями, добавлена защита от атак через зависимости (supply chain), обеспечен предсказуемый цикл поддержки и выпуска обновлений, реализованы инструменты для интеграции с облаком Azure и включены возможности для усиления безопасности, такие как фильтрация системных вызовов, шифрование дисковых разделов, верификация репоизиториев и пакетов по цифровой подписи, защита от атак, связанных с символическими ссылками и сборка с опциями для защиты от переполнений буфера.
