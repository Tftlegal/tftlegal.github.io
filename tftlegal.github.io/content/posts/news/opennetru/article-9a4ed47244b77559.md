# AxonOS - real-time ОС для нейрокомпьютерных интерфейсов

## Краткое содержание

AxonOS — открытый проект, создающий программную инфраструктуру для систем с нейрокомпьютерными интерфейсами.
Его цель — обеспечить детерминированный слой выполнения между нейронным оборудованием и ИИ.
Ядро разработано на Rust в режиме no_std для предсказуемого реального времени.
Система использует формализованный ABI системных вызовов и capability-модель доступа.
Обмен сообщениями построен на IPC без блокировок.
Исходный код доступен по лицензиям MIT или Apache 2.0.
