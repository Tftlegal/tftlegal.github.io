# Релиз дистрибутива openSUSE Leap 16.1

## Краткое содержание

Вышел релиз дистрибутива openSUSE Leap 16.1, разрабатывавшийся в течение года и основанный на технологиях коммерческого SUSE Linux Enterprise Server 16.1. Для загрузки доступны два образа: универсальный DVD объёмом 4,3 ГБ (поддержка архитектур x86-64-v2, aarch64, ppc64le, 390x) и урезанный сетевой образ размером 700 МБ. Поддержка выпусков ветки openSUSE Leap 16.x рассчитана на два года, что соответствует двум полным циклам подготовки релизов. Ветка 16.x будет сопровождаться параллельно с коммерческим SUSE Linux Enterprise 16 до осени 2031 года. Финальным выпуском ветки станет openSUSE Leap 16.6. Обновления для него будут выходить до осени 2033 года.

## Полная статья

После года разработки[опубликован](https://news.opensuse.org/2026/11/03/leap-unites-traditional-and-immutable/)релиз дистрибутива[openSUSE Leap 16.1](https://www.opensuse.org/), построенного на технологиях коммерческого дистрибутива[SUSE Linux Enterprise Server 16.1](https://www.suse.com/products/server/), релиз которого ожидается позднее в этом месяце. Для загрузки[доступна](https://get.opensuse.org/leap/16.1#download)универсальная DVD-сборка, размером[4.3 ГБ](https://download.opensuse.org/distribution/leap/16.1/offline/)(x86-64-v2, aarch64, ppc64le, 390x) и урезанный образ для установки с загрузкой пакетов по сети ([700 МБ](https://download.opensuse.org/distribution/leap/16.1/installer/iso/)). Обновления для выпусков openSUSE Leap 16.x формируются в течение двух лет (два полных цикла подготовки релизов). Промежуточные выпуски в ветке openSUSE Leap 16, сопровождаемой параллельно с коммерческим дистрибутивом SUSE Linux Enterprise 16, будут формироваться до осени 2031 года - финальным станет выпуск openSUSE Leap 16.6, обновления для которого будут выпускаться до осени 2033 года.

Основные[особенности](https://en.opensuse.org/Features_16.1)openSUSE Leap 16.1:

- В инсталлятор добавлен режим установки в виде атомарно обновляемой системы с базовой начинкой, монтируемой в режиме только для чтения. Ранее подобная возможность распространялась в форме отдельного дистрибутива[openSUSE Leap Micro](https://www.opennet.ru/opennews/art.shtml?num=62359), а теперь интегрирована в openSUSE Leap в форме специального режима, поддерживаемого наряду с возможностью построения системного окружения с использованием традиционных пакетов. Пользователям openSUSE Leap Micro предоставлены[инструменты](https://github.com/openSUSE/opensuse-migration-tool)для миграции на openSUSE Leap 16.1.
- Обновлены пользовательские окружения KDE Plasma 6.6 (было 6.4) и LXQt 2.4 (было 2.2). Как и в прошлом выпуске поставляются GNOME 48, Cinnamon 6.4, MATE 1.28, Sway 1.10 и Xfce 4.20 (задействован Wayland).
- Компоненты графического стека обновлены до Mesa 26.0.7 и Qt 6.1.
- [Обновлены](https://download.opensuse.org/distribution/leap/16.1/repo/oss/x86_64/)версии пакетов, среди которых wine 11, QEMU 11.0.4, MariaDB 12.3.2, PostgreSQL 18, PHP 8.5.12, Node.js 24.11.3, Python 3.14, Rust 1.98, Ruby 3.4.10, LLVM/Clang 21, libvirt 12.4, Podman 5.8, LibreOffice 26.2 и GIMP 3.2. Как и в прошлом выпуске поставляются ядро Linux 6.12, systemd 257, gcc 15 и glibc 2.40.
- Инсталлятор[Agama](https://agama-project.github.io/)обновлён до версии[24](https://agama-project.github.io/blog/2026/09/11/agama-24).
- Добавлена утилита[osdiff](https://github.com/openSUSE/osdiff)и[web-сервис](https://opensuse.github.io/osdiff/)для сравнения версий пакетов в 16.0 openSUSE Leap 16.0, openSUSE Leap 16.1, Tumbleweed и upstream-проектами. Предоставляются возможности для фильтрации вывода и экспорта данных в JSON или CSV.
- Как и в прошлом выпуске по умолчанию включена система мандатного контроля доступа SELinux, в ядре отключена поддержка 32-разрядных систем x86 и запуска 32-разрядных исполняемых файлов (возвращается через параметр "ia32_emulation=1" и пакет grub2-compat-ia32).
