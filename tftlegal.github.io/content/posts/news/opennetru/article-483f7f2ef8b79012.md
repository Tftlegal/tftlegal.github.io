# Уязвимости в Ruby, допускающие удалённое выполнение кода, в том числе при атаке на GitLab

## Краткое содержание

Опубликованы корректирующие версии языка Ruby — 3.3.14, 3.4.13 и 4.0.10 — закрывающие семь уязвимостей (CVE-2026-132825). Для шести из них уже продемонстрированы рабочие прототипы эксплойтов, позволяющие выполнить код удалённо на пораженных проектах. Конкретные уязвимые проекты на данный момент не раскрыты. Корни проблем лежат в движке регулярных выражений и в функциях преобразования регистра символов. Уязвимости проявляются, когда приложение использует внешние данные внутри регулярных выражений или выполняет смену регистра в строках, полученных извне.

## Полная статья

Опубликованы корректирующие выпуски языка программирования Ruby[3.3.14](https://www.ruby-lang.org/en/news/2026/11/18/ruby-3-3-14-released/),[3.4.13](https://www.ruby-lang.org/en/news/2026/11/18/ruby-3-4-13-released/),[4.0.10](https://www.ruby-lang.org/en/news/2026/11/18/ruby-4-0-10-released/), в которых устранено[7 уязвимостей](https://www.ruby-lang.org/en/news/2026/11/18/multiple-vulnerabilities-in-regexp-and-string/)([CVE-2026-132825](https://security-tracker.debian.org/tracker/CVE-2026-132825)), для 6 из которых продемонстрированы прототипы эксплоитов для удалённого выполнения кода при атаке на некоторые проекты, написанные на языке Ruby (какие именно проекты пока не раскрывается). Уязвимости вызваны ошибками в движке регулярных выражений и функциях преобразования регистра символов, и проявляются в приложениях, использующих внешние данные внутри регулярных выражений или преобразующих регистр символов в полученных извне строках.

- [Переполнение буфера](https://github.com/ruby/ruby/security/advisories/GHSA-34m4-m9fh-gqp5)([CVE-2026-132825](https://security-tracker.debian.org/tracker/CVE-2026-132825)) на один байт в коде преобразования регистра символов, возникающее при преобразовании специально оформленных строк в некоторых однобайтовых кодировках, таких как ISO-8859-1 и Windows-1252. Проблема[вызвана](https://github.com/ruby/ruby/commit/d582f8f13d700d8e39714d3a8f11eb4bd2bc69f0)тем, что символ[ß](https://en.wikipedia.org/wiki/%C3%9F)(0xDF) преобразовывался в двухбайтовый код, при том что место в буфере выделялось только для одного байта.
- [Целочисленное переполнение](https://github.com/ruby/ruby/security/advisories/GHSA-87fm-7w84-j2px)в коде преобразования регистра символов, приводящее к записи данных за пределы выделенного буфера если размер преобразованного варианта строки превышает 4 ГБ. Проблема[вызвана](https://github.com/ruby/ruby/commit/bdff3c5d66dd40b591f2dcda4d4694dcfabf8db4)использованием типа int при возвращении размера строки.
- [Двойное освобождение памяти](https://github.com/ruby/ruby/security/advisories/GHSA-7x2q-68qv-6p8x)(double free) в коде компиляции регулярных выражений, возникающее при обработке специально оформленных регулярных выражений, в которых используется оператор "&&" для выделения символов, присутствующих в двух наборах (например, "[a-z&&[^aeiou]]" для проверки только согласных букв).
- [Чтение из области вне выделенного буфера](https://github.com/ruby/ruby/security/advisories/GHSA-wpqw-5qxg-m68r), приводящее к контролируемому повреждению содержимого в памяти при обработке регулярных выражений в режиме без учёта регистра символов.
- [Целочисленное переполнение](https://github.com/ruby/ruby/security/advisories/GHSA-3p8q-wmhx-vm2w)при компиляции регулярных выражений, приводящее к переполнению буфера при обработке специально оформленных шаблонов.
- [Переполнение буфера](https://github.com/ruby/ruby/security/advisories/GHSA-7whj-cfh7-xgm4)в реализации метода[Regexp#to_s](https://github.com/ruby/ruby/commit/12da5c284aa1e1c1fbd0d620edd41de590d1d3e4), проявляющееся при преобразовании в строку специально оформленных регулярных выражений.
- [Чтение из области вне выделенного буфера](https://github.com/ruby/ruby/security/advisories/GHSA-pvgc-g7gj-pv6h)при использовании регулярных выражений с обратными ссылками в режиме без учёта регистра символов. Уязвимость может привести к утечке содержимого памяти или аварийному завершению процесса.

Дополнительно можно отметить, что разработчики проекта PHP[анонсировали](https://www.php.net/archive/2026.php#2026-11-18-1)публикацию сегодня в 17:00 (MSK) корректирующих обновлений, устраняющих критическую уязвимость в PHP, проявляющуюся в некоторых нестандартных конфигурациях.

Дополнение: Уязвимостям[присвоено](https://blog.cloudflare.com/ruby2shell-waf-protection/)кодовое имя ruby2shell. Уязвимость CVE-2026-132825[может быть](https://docs.gitlab.com/releases/patches/patch-release-gitlab-19-6-1-released/)эксплуатирована в GitLab для удалённого выполнения кода.
