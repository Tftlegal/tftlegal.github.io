# Релиз Mesa 26.3, свободной реализации OpenGL и Vulkan

## Краткое содержание

Вышел релиз Mesa 26.3.0 — свободной реализации API Vulkan, OpenGL, OpenGL ES и OpenCL. Разработка данного выпуска заняла три месяца. Первый выпуск ветки 26.3.0 имеет экспериментальный статус, что означает, что код ещё не полностью стабилизирован. После завершения финальной стабилизации будет выпущена стабильная версия 26.3.1. Таким образом, текущий релиз предназначен в первую очередь для тестирования и обратной связи.

## Полная статья

После трёх месяцев разработки[опубликован](https://gitlab.freedesktop.org/mesa/mesa/-/tags/mesa-26.3.0)релиз свободной реализации API Vulkan, OpenGL, OpenGL ES и OpenCL -[Mesa 26.3.0](http://mesa3d.org/). Первый выпуск ветки Mesa 26.3.0 имеет экспериментальный статус - после проведения окончательной стабилизации кода будет выпущена стабильная версия 26.3.1.

В Mesa 26.3 доступна поддержка графического API[Vulkan 1.4](https://www.opennet.ru/opennews/art.shtml?num=62331)в драйверах ANV для GPU Intel, RADV для GPU AMD, NVK для GPU NVIDIA, HoneyKrisp (hk) для GPU Apple, Turnip для GPU Qualcomm, PanVK для GPU ARM Mali, в программном растеризаторе lavapipe (lvp) и в режиме эмулятора (vn). В драйверах v3dv (GPU Broadcom VideoCore для Raspberry Pi 4+) и dzn (реализация Vulkan поверх Direct3D 12) поддерживается Vulkan 1.0, в драйвере kk (KosmicKrisp, Vulkan поверх Metal) - Vulkan 1.1, а в драйвере pvr (GPU Imagination PowerVR) - Vulkan 1.2.

В Mesa также[обеспечивается](https://mesamatrix.net/)полная поддержка OpenGL 4.6 для драйверов iris (GPU Intel Gen 8+), radeonsi (AMD), Crocus (старые GPU Intel Gen4-Gen7.5), AMD (r600), zink, llvmpipe, virgl (виртуальный GPU[Virgil3D](https://www.opennet.ru/opennews/art.shtml?num=37456)для QEMU/KVM), freedreno (Qualcomm Adreno), d3d12 (прослойка для организации работы OpenGL поверх DirectX 12) и asahi (GPU AGX, используемый в чипах Apple M1 и M2). Поддержка OpenGL 4.5 доступна для GPU NVIDIA (nvc0). Поддержка OpenGL 3.3 присутствует в драйверах softpipe (программный растеризатор) и nv50 (NVIDIA NV50). В драйверах panfrost (GPU ARM Mali) и v3d (GPU Broadcom VideoCore) поддерживается OpenGL 3.1.
