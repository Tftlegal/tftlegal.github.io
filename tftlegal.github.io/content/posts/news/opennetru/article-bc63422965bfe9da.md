# Выпуск дистрибутива Fedora Linux 45

## Краткое содержание

Вышел релиз дистрибутива Fedora Linux 45. Для загрузки доступны официальные сборки: Fedora Workstation, KDE Plasma Desktop, Server, IoT, CoreOS, Cloud Base, IoT Edition, Silverblue и Kinoite. Кроме того, представлены Live-сборки в формате спинов с различными пользовательскими окружениями — Xfce, MATE, Cinnamon, LXDE, Phosh, Miracle, LXQt, Budgie, Sway и Cosmic. Издания сформированы для трёх архитектур: x86_64, Power64 и ARM64 (AArch64). Таким образом, релиз охватывает широкий спектр задач — от настольных систем до серверных и IoT-решений. Выбор окружений позволяет подобрать дистрибутив как для опытных пользователей, так и для тех, кто предпочитает лёгкие или оконные-менеджерные сессии.

## Полная статья

[Представлен](https://fedoramagazine.org/announcing-fedora-linux-45/)релиз дистрибутива[Fedora Linux 45](https://fedoraproject.org/). Для загрузки[подготовлены](https://getfedora.org/)сборки[Fedora Workstation](https://getfedora.org/en/workstation/prerelease/), Fedora KDE Plasma Desktop, Fedora Server, Fedora IoT, Fedora CoreOS, Fedora Cloud Base,[Fedora IoT Edition](https://iot.fedoraproject.org/),[Fedora Silverblue](https://silverblue.fedoraproject.org/download), Fedora Kinoite и Live-сборки, поставляемые в форме[спинов](https://spins.fedoraproject.org/)c пользовательскими окружениями Xfce, MATE, Cinnamon, LXDE, Phosh, Miracle, LXQt, Budgie, Sway и Cosmic. Сборки сформированы для архитектур x86_64, Power64 и ARM64 (AArch64).

Наиболее значимые[изменения](http://fedoraproject.org/wiki/Releases/45/ChangeSet)в Fedora Linux 45:

- Среда рабочего стола GNOME обновлена до ветки[51](https://www.opennet.ru/opennews/art.shtml?num=66292), в котором предложены оптимизации для повышения плавности вывода и исключения подвисаний во время анимации и при большой нагрузке на систему. Появилась опция для автоматической смены ландшафтной и портретной ориентации экрана при повороте устройства с акселерометром. Добавлена возможность проброса смарт-карт при удалённом подключении к рабочему столу. В экран входа в систему добавлена поддержка аутентификации через корпоративные web-сервисы. Задействованы векторные изображения курсоров, поставляемые в формате SVG.
- В установочных iso-образах атомарно обновляемых редакций Fedora Atomic Desktop (Silverblue, Kinoite и т.п.) вместо классического инсталлятора Anaconda на базе GTK[задействован](https://www.opennet.ru/opennews/art.shtml?num=65960)новый инсталлятор Anaconda WebUI на базе web-интерфейса, уже применяемый в Fedora Workstation и в live-сборках. Новый инсталлятор поддерживает удалённое управление установкой - пользователи теперь могут загрузить Fedora на целевой системе с опцией "inst.webui.remote" и управлять установкой через web-браузер на другом компьютере с аутентификацией по PIN-коду и с шифрованием трафика.
- Все файлы конфигурации репозиториев RPM, изначально устанавливаемые при подключении репозитория,[перенесены](https://fedoraproject.org/wiki/Changes/RelocateRpmRepoConfigsToUsr)из каталога /etc/yum.repos.d в /usr/share/dnf5/repos.d. PGP-ключи перенесены в /usr/share/pki/rpm-gpg. Изменение упростит разделение изначальных настроек репозиториев и файлов конфигурации, изменённых пользователем.
- В RPM по умолчанию[включена](https://fedoraproject.org/wiki/Changes/Enforcing_signature_checking_by_default)[проверка](https://www.opennet.ru/opennews/art.shtml?num=64107)пакетов по цифровой подписи. При попытке установки пакетов без подписи или с некорректной подписью теперь будет выводиться ошибка, если пользователь явно не запустил rpm с флагом "--nosignature". Ранее на уровне RPM выполнялась только проверка целостности по хэшам, а подлинность пакетов из репозиториев проверялась в YUM и DNF.
- Пакетный менеджер RPM[обновлён](https://fedoraproject.org/wiki/Changes/RPM-6.1)до версии[6.1](https://www.opennet.ru/opennews/art.shtml?num=66106), в которой реализован новый синтаксис модификаторов для макросов (имя_макроса<модификаторы>), изменяющих поведение макросов. Возвращено использование по умолчанию системы NSS (Name Service Switch) для поиска пользователей и групп. Решена проблема с остановкой обработки всех запросов к rpmdb во время выполнения транзакций. Добавлена возможность заверения файлов цифровой подписью с использованием токенов PKCS11.
- Для RPM-пакетов[реализован](https://fedoraproject.org/wiki/Changes/Sequoia_openpgpverify)макрос "%openpgpverify", позволяющий использовать написанный на Rust инструментарий Sequoia вместо GnuPG для верификации пакетов.
- В десктоп-редакциях для управления ключами вместо gnome-keyring и kwallet[задействован](https://fedoraproject.org/wiki/Changes/oo7_Secrets_Service_Provider)компонент[oo7](https://linux-credentials.github.io/oo7/oo7/)(D-Bus Secret Service provider), написанный на Rust.
- Работающий на уровне ядра драйвер консоли fbcon[заменён](https://fedoraproject.org/wiki/Changes/UseKmsconVTConsole)на[kmscon](https://www.freedesktop.org/wiki/Software/kmscon/), выполняемый в пространстве пользователя, использующий механизм KMS (Kernel Mode Setting), обеспечивающий более качественную отрисовку и лучше поддерживающий шрифты и Unicode.
- Разработчикам атомарных редакций[предоставлена](https://fedoraproject.org/wiki/Changes/FilterFedoraFlatpaksAtomicDesktopsv2)возможность разрешить установку из каталога FlatHub избранных проверенных приложений, вместо установки flatpak-пакетов с теми же приложениями из репозитория Fedora. В Fedora поддерживается собственный flatpak-репозиторий, содержимое которого формируется на основе пересборки rpm-пакетов, в то время как большинство пользователей[предпочло бы](https://www.opennet.ru/opennews/art.shtml?num=63617)установку пакетов из каталога FlatHub, собираемых основными разработчиками приложений, а не сопровождающими Fedora.
- Для сборки iso-образов атомарных редакций Fedora[задействован](https://fedoraproject.org/wiki/Changes/BuildAtomicDesktopsWithImageBuilder)инструментарий image-builder вместо lorax.
- В Fedora CoreOS добавлена поддержка systemd-oomd и zram swap.
- В инсталлятор[добавлена](https://fedoraproject.org/wiki/Changes/StratisAnacondaSupport)поддержка[установки](https://fedoramagazine.org/installing-fedora-45-on-stratis-storage/)в логические разделы, управляемые через инструментарий[Stratis](https://www.opennet.ru/opennews/art.shtml?num=57939). На этапе установки можно создавать пулы из одного или нескольких накопителей, к которым применимы такие возможности, как динамическое выделение места в хранилище, снапшоты, обеспечение целостности и подключение слоёв для кэширования.
- По умолчанию непривилегированным пользователям[запрещён](https://fedoraproject.org/wiki/Changes/Restrict_ptrace_by_default)доступ к отладочным возможностям, использующим механизм ptrace.
- [Реализован](https://fedoraproject.org/wiki/Changes/DrmPanicFrontend)web-фронтэнд для получения более детальной информации об аварийных остановках работы ядра. При переходе ядра в состояние "paniс" показывается QR-код со ссылкой, при открытии которой будут наглядно отображены данные трассировки вызовов, помогающие диагностировать проблему, предложены рекомендации по дальнейшим действиям и предоставлена возможность отправки отчёта об ошибке.
- В сетевом конфигураторе NetworkManager по умолчанию[задействован](https://fedoraproject.org/wiki/Changes/IPv6-Mostly_Support_In_NetworkManager)режим "IPv6-mostly",[включающий](https://www.opennet.ru/opennews/art.shtml?num=65943)DHCPv4-опцию 108 (по возможности использование только IPv6) и поддержку механизма CLAT (Customer-side Translator, 464XLAT) для обеспечения работы приложений, поддерживающих только IPv4, на хосте с IPv6.
- В утилитах chpasswd и newusers[включена](https://fedoraproject.org/wiki/Changes/UsePAMInChpasswdNewusers)поддержка PAM (Pluggable Authentication Modules), благодаря которой в данных утилитах теперь учитываются системные политики для аутентификации и паролей, например,[выставление](https://linux.die.net/man/8/pam_pwquality)требований к качеству пароля,[запрет](https://linux.die.net/man/8/pam_pwhistory)установки ранее используемых паролей, блокировка учётных записей и централизованный аудит смены паролей.
- [Добавлен](https://fedoraproject.org/wiki/Changes/Grub2LightForConfidentialComputing)пакет grub-cc с урезанным вариантом загрузчика, предназначенным для применения на системах с UEFI Secure Boot. В урезанном варианте поставляется только минимальный набор вложенных модулей и поддерживается загрузка UKI-образов (Unified Kernel Image). Удаление поддержки форматов изображений jpeg/png и дополнительных ФС позволяет снизить поверхность атаки на фоне периодического выявления уязвимостей в GRUB ([1](https://www.opennet.ru/opennews/art.shtml?num=64298),[2](https://www.opennet.ru/opennews/art.shtml?num=62771),[3](https://www.opennet.ru/opennews/art.shtml?num=59868),[4](https://www.opennet.ru/opennews/art.shtml?num=58130),[5](https://www.opennet.ru/opennews/art.shtml?num=57316),[6](https://www.opennet.ru/opennews/art.shtml?num=54691),[7](https://www.opennet.ru/opennews/art.shtml?num=53454)).
- [Добавлена](https://fedoraproject.org/wiki/Changes/Encapsule_devel_containers)поддержка использования инструментария[encapsule](https://github.com/juhp/encapsule)для запуска приложений в изолированном окружении, в котором вместо доступа к реальному домашнему каталогу пользователя, предоставляется доступ к его временному варианту.
- Обновлены версии пакетов, включая ядро Linux 7.2, GCC 16.2, LLVM 23, glibc 2.44, binutils 2.47, Perl 5.44, Python 3.15, Go 1.27, Lua 5.5, Ruby on Rails 8.1, Erlang 27, Fontconfig 2.18, IBus 1.5.35, Podman 6, OpenSSL 4.0, MySQL 9.7, MariaDB 12.3.
- [Предложены](https://fedoraproject.org/wiki/Changes/LazarusWithMultipleWidgetsets)варианты пакетов с интегрированной средой разработки Lazarus (для Free Pascal), собранные с виджетами на базе GTK3, Qt5 и Qt6 (до этого пакет собирался только с GTK2).
- [Реализована](https://fedoraproject.org/wiki/Changes/Disable_CRYPTO_USER_API)первая стадия подготовки к удалению API для доступа к криптоподсистеме ядра Linux из пространства пользователя (CRYPTO_USER_API - Crypto Userspace API). Данный API объявлен в ядре устаревшим из-за потенциальных проблем с безопасностью и запланирован к удалению. Crypto Userspace API применяется в таких пакетах, как iwd, cryptsetup (используется в tcplay и VeraCrypt) и libkcapi (используется в dracut), но первая стадия не повлияет на их работу.
- Из репозитория[удалены](https://www.opennet.ru/opennews/art.shtml?num=65480)пакеты со средой рабочего стола Deepin, из-за проблем с сопровождением (в пакетах длительное время остаются неисправленными серьёзные ошибки и уязвимости).
- [Объявлены](https://fedoramagazine.org/migrating-away-from-unmaintained-networkmanager-vpnpluginsvpnc-and-fortisslvpn/)устаревшими VPN-плагины NetworkManager-vpnc и NetworkManager-fortisslvpn, вместо которых рекомендуется использовать плагины NetworkManager-libreswan и NetworkManager-openconnect.

Для Fedora 45[введены в строй](https://rpmfusion.org/)репозитории "free" и "nonfree" от проекта RPM Fusion, в которых доступны пакеты с дополнительными мультимедиа приложениями (MPlayer, VLC, Xine), видео/аудио кодеками, поддержкой DVD, проприетарными драйверами AMD и NVIDIA, игровыми программами и эмуляторами. <
