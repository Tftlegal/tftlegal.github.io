# Релиз видеоплеера MPV 0.42

## Краткое содержание

Вышел релиз 0.42 открытого видеоплеера MPV, прошедший почти год разработки. Проект был выделен из кодовой базы MPlayer2 в 2013 году. MPV делает акцент на создании новых возможностей, не стремясь сохранять совместимость с MPlayer. Основная часть кода распространяется под лицензией LGPLv2.1+, хотя отдельные компоненты пока остаются под GPLv2. Процесс перехода на LGPL практически завершён. Для отключения оставшегося GPL-кода предусмотрен параметр «--enable-lgpl».

## Полная статья

После почти года разработки[сформирован](https://github.com/mpv-player/mpv/releases/tag/v0.42.0)выпуск открытого видеоплеера[MPV 0.42](http://mpv.io/), в 2013 году[ответвившегося](https://www.opennet.ru/opennews/art.shtml?num=37600)от кодовой базы проекта[MPlayer2](https://www.opennet.ru/opennews/art.shtml?num=30005). В MPV основное внимание уделяется разработке новых возможностей, не заботясь о сохранении совместимости с MPlayer. Код MPV[распространяется](https://github.com/mpv-player/mpv)под лицензией LGPLv2.1+, некоторые части[остаются](https://github.com/mpv-player/mpv/blob/master/Copyright)под GPLv2, но процесс перехода на LGPL почти завершён и для отключения оставшегося GPL-кода можно использовать опцию "--enable-lgpl".

Среди изменений в новой версии:

- Добавлен новый сетевой бэкенд, использующий библиотеку libcurl и поддерживающий HTTP/2, HTTP/3 и повторное использование уже установленных соединений.
- Реализованы меню для навигации по дискам DVD-Video, Blu-ray HDMV и BD-J.
- Добавлена поддержка воспроизведения звуковых DVD (DVD-Audio).
- Предоставлена возможность прямого воспроизведения iso-образов дисков DVD-Video, DVD-Audio и Blu-ray.
- В модуле вывода[vo_gpu_next](https://github.com/mpv-player/mpv/wiki/GPU-Next-vs-GPU)добавлена поддержка расширенных слоёв Dolby Vision Profile 7.
- Добавлена опция "--audio-spdif=dsd" для проброса DSD поверх PCM (DoP).
- При помощи библиотеки subrandr реализована поддержка субтитров в формате SRV3, применяемых в YouTube.
- Предоставлена возможность создания собственных контекстных меню, показываемых при клике правой кнопкой мыши и задаваемых в файле конфигурации menu.conf.
- Во встроенный графический интерфейс OSC (On Screen Controller) добавлен режим отображения плавающих кнопок с пиктограммами[Fluent](https://fluenticons.co/), включаемый опцией "--script-opts=osc-layout=floating"
- Добавлен API для интеграции с интерфейсом OSC внешних генераторов миниатюр.
- Добавлена поддержка расширений протокола Wayland для управления сеансами и цветностью.
- Добавлена опция "--target-trc=scrgb" для вывода в формате scRGB.
- В сборках для Linux улучшена поддержка цветовых пространств для HDR.
- В libmpv добавлен API для отрисовки через D3D11.
- Переработаны возможности для отрисовки видео в текстовых терминалах, используя расширения sixel, kitty и tct.
- Добавлен фильтр "--vf=amf_frc" (AMD Frame Rate Conversion) для изменения частоты кадров.
- Переписан код для компенсации накапливающейся со временем рассинхронизации звука с отображаемыми кадрами видео.
- По умолчанию включена проверка TLS-сертификатов (--tls-verify).
- Повышены требования к версиям FFmpeg (6.1+) и libplacebo (7.387+).
