# Выпуск дистрибутива для одноплатных ПК DietPi 10.7

## Краткое содержание

Выпущен DietPi 10.7 — дистрибутив для одноплатных ПК на архитектурах ARM и RISC-V, включая Raspberry Pi, Orange Pi, NanoPi, Rock Pi, Quartz64, Pine64, Asus Tinker, Odroid и VisionFive 2.  
Он построен на пакетной базе Debian.  
DietPi доступен в сборках для более чем 50 плат.  
Его также можно использовать для создания компактных окружений в виртуальных машинах и на обычных ПК на базе x86_64.  
Сборки для плат отличаются небольшим размером — в среднем около 150 МБ в сжатом виде, что меньше, чем у Raspberry Pi OS и Armbian.  
Инструментарий для сборки и сопровождения дистрибутива распространяется под лицензией GPLv2.
