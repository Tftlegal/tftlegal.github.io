# Выпуск GNU Automake 1.19, инструментария для генерации сборочных файлов

## Краткое содержание

Опубликован релиз Automake версии 1.19.  
Automake — это утилита для автоматической генерации make-файлов.  
Она предназначена для создания файлов, соответствующих стандартам проекта GNU.  
Релиз касается инструментов автоматизации сборки программного обеспечения.  
Версия 1.19 представляет собой новый выпуск данной утилиты.
