# Опубликована среда рабочего стола LXQt 2.5.0

## Краткое содержание

Вышел релиз рабочего окружения LXQt 2.5.0, разработанного в течение шести месяцев. Проект продолжает развитие идей LXDE и Razor-qt, сочетая классическую организацию рабочего стола с современным оформлением. LXQt позиционируется как лёгкое, модульное и быстрое окружение, объединяющее лучшие черты своих предшественников. Исходный код размещён на GitHub и распространяется под лицензиями GPL 2.0+ и LGPL 2.1+. Готовые сборки ожидаются для Ubuntu (включая Lubuntu), Arch Linux, Fedora, openSUSE, Mageia, FreeBSD, ROSA и ALT Linux.

## Полная статья

После 6 месяцев разработки[представлен](https://lxqt-project.org/release/2026/11/05/release-lxqt-2-5-0/)релиз среды рабочего стола[LXQt 2.5.0](https://lxqt.github.io/)(Qt Lightweight Desktop Environment),[продолжающей](https://www.opennet.ru/opennews/art.shtml?num=37473)развитие проектов LXDE и Razor-qt. Интерфейс LXQt следует идеям классической организации рабочего стола, но привносит современное оформление и приёмы, увеличивающие удобство работы. LXQt позиционируется как легковесное, модульное, быстрое и удобное окружение, вобравшее лучшие черты LXDE и Razor-qt. Код[размещён](https://github.com/lxqt)на GitHub и поставляется под лицензиями GPL 2.0+ и LGPL 2.1+. Появление готовых сборок ожидается для[Ubuntu](https://launchpad.net/lxqt)(LXQt по умолчанию предлагается в Lubuntu),[Arch Linux](https://wiki.archlinux.org/title/LXQt),[Fedora](https://fedoraproject.org/wiki/Changes/LXQt),[openSUSE](http://download.opensuse.org/repositories/X11:/LXQt/),[Mageia](http://mageia.madb.org/package/show/release/cauldron/application/0/name/task-lxqt),[FreeBSD](https://wiki.freebsd.org/LXQt),[ROSA](http://wiki.rosalab.ru/ru/index.php/LXQt)и[ALT Linux](http://packages.altlinux.org/ru/search?branch=sisyphus&name=lxqt).

В[новой версии](https://github.com/lxqt/lxqt/releases/tag/2.5.0):

- В эмуляторе терминала QTerminal и виджете QTermWidget появилась поддержка: escape-последовательности OSC 8 (Operating System Command 8) для вставки гиперссылок; возможности выделения области через Shift+click; новых режимов размещения фоновых изображений; визуальной индикации кода гудка (0x07); кнопки для раскрытия текущего вложенного терминала; опции для вывода уведомления при прекращении появления новой информации в терминале; показа предупреждения при аварийном завершении процесса.
- Прекращено использование компонента menu-cache, который оставался последней зависимостью из LXDE. Для кэширования элементов меню в библиотеку libfm-qt добавлена необходимая встроенная функциональность, обеспечивающая более высокую производительность.
- В файловом менеджере PCManFM-Qt в панель добавлена кнопка для остановки поиска и реализован инкременталный режим вывода результатов поиска, позволяющие в любой момент остановить поиск, не потеряв список уже найденных к этому моменту файлов. В настройки добавлена опция для отключения кэширования обоев рабочего стола для показа изображений в исходном качестве.
- Изменения в панели: В плагине отслеживания состояния сети реализовано корректное масштабирование пиктограммы и возможность использования единой системной темы пиктограмм. В плагине отображения вывода запускаемых команд (Custom Command) реализована опция для задания минимального размера, исключающая сжатие панели при изменении длины выводимого текста. В плагине управления яркостью экрана появилась всплывающая подсказка с информацией о текущем уровне яркости. Налажено использование шины D-Bus при включении функции автоскрытия панели. В диалогах с настройками плагинов по умолчанию выставлен фокус на кнопке "Закрыть" для исключения случайного применения изменений при нажатии Enter.
- Добавлен интерфейс для выбора кодека для Bluetooth.
- Временно отключена возможность настройки параметров монитора в окружениях на базе X11 из-за прекращения поддержка X11 в библиотеке libkscreen-6.8 из KDE. Поддержку данной возможности намерены вернуть в ближайшем корректирующем выпуске через разработку замены.
- В качестве минимально поддерживаемой версии Qt заявлен выпуск 6.10.0.
