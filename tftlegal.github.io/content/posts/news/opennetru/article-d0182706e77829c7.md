# Выпуск дистрибутива MX Linux 25.3

## Краткое содержание

Опубликован релиз легковесного дистрибутива MX Linux 25.3, созданного в результате совместной работы сообществ, образовавшихся вокруг проектов antiX и MEPIS. Выпуск основан на пакетной базе Debian с улучшениями от проекта antiX и пакетами из собственного репозитория. В дистрибутиве на выбор можно использовать системы инициализации sysVinit и systemd. Поставляются собственные инструменты для настройки и развёртывания системы. Для загрузки доступны  64-разрядные сборки (x86_64) с рабочим столом Xfce (2.7 ГБ), а также сборки  с рабочим столом KDE (3.4 ГБ) и сборки (2.3 ГБ) с оконным менеджером Fluxbox.

## Полная статья

[Опубликован](https://mxlinux.org/blog/mx-25-3-infinity-isos-now-available/)релиз легковесного дистрибутива[MX Linux 25.3](https://mxlinux.org), созданного в результате совместной работы сообществ, образовавшихся вокруг проектов[antiX](https://www.opennet.ru/opennews/art.shtml?num=50269)и[MEPIS](https://en.wikipedia.org/wiki/MEPIS). Выпуск основан на пакетной базе Debian с улучшениями от проекта antiX и пакетами из собственного репозитория. В дистрибутиве на выбор можно использовать системы инициализации[sysVinit](https://www.nongnu.org/sysvinit/)и systemd. Поставляются собственные инструменты для настройки и развёртывания системы. Для загрузки[доступны](https://sourceforge.net/projects/mx-linux/files/Final/)64-разрядные сборки (x86_64) с рабочим столом[Xfce](https://sourceforge.net/projects/mx-linux/files/Final/Xfce/)(2.7 ГБ), а также[сборки](https://sourceforge.net/projects/mx-linux/files/Final/KDE/)с рабочим столом KDE (3.4 ГБ) и[сборки](https://sourceforge.net/projects/mx-linux/files/Final/Fluxbox/)(2.3 ГБ) с оконным менеджером Fluxbox.

В новом выпуске:

- Осуществлена синхронизация с пакетной базой Debian 13.7. Ядро Linux обновлено до версии 6.12.107.
- Обновлены[сборки](https://sourceforge.net/projects/mx-linux/files/Final/Xfce/)с расширенной поддержкой оборудования (AHS), которые поставляются с Xfce, ядром 7.2 c патчами от проекта[liquorix](https://liquorix.net/)и Мesa 26.1.4.
- Обновлён интерфейс утилит MX-Welcome, MX-Tools и custom-toolbox.
- Добавлена утилита Verify-iso-sig для проверки iso-образов по цифровой подписи.
- Добавлена утилита MX-Theme-Colors, для создания собственных цветовых тем на основе существующих тем оформления GTK.
