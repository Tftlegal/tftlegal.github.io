# Выпуск дистрибутивов OpenIndiana 2026.10 и OmniOS r151060 на технологиях OpenSolaris

## Краткое содержание

Вышел свободный дистрибутив OpenIndiana 2026.10, ставший преемником OpenSolaris, развитие которого было прекращено компанией Oracle. Дистрибутив построен на актуальном срезе кодовой базы проекта Illumos. Именно Illumos продолжает развивать технологии OpenSolaris: ядро, сетевой стек, файловые системы, драйверы, а также базовые системные утилиты и библиотеки. Для загрузки предложено три варианта ISO-образов: серверная редакция с консольными приложениями (594 МБ), минимальная сборка (543 МБ) и вариант с графическим окружением MATE (2,5 ГБ).

## Полная статья

[Представлен](https://www.openindiana.org/announcements/openindiana-hipster-2026-10-announcement/)релиз свободного дистрибутива[OpenIndiana 2026.10](https://www.openindiana.org/), пришедшего на смену дистрибутиву OpenSolaris, развитие которого было прекращено компанией Oracle. OpenIndiana предоставляет пользователю рабочее окружение, построенное на базе свежего среза кодовой базы проекта[Illumos](http://www.illumos.org/). Непосредственно разработка технологий OpenSolaris продолжается проектом Illumos, в котором развивается ядро, сетевой стек, файловые системы, драйверы, а также базовый набор пользовательских системных утилит и библиотек. Для загрузки[сформировано](https://dlc.openindiana.org/isos/hipster/20261030/)три вида iso-образов - серверная редакция с консольными приложениями (594 МБ), минимальная сборка (543 МБ) и сборка с графическим окружением MATE (2.5 ГБ).

Основные изменения в OpenIndiana 2026.10:

- В Live-сборках реализована поддержка UEFI framebuffer и включён X.org-драйвер illumosfb. Обеспечена автоматическая настройка консолей на базе фреймбуфера.
- Обновлено 644 пакета.
- Обновлены пользовательские компоненты, включая Firefox 159, Thunderbird 159, GIMP 3.2.6, inkscape 1.4.4, librecad 2.2.1.6, MATE 1.28.3, nvidia drv 580.178.04.
- Обновлены инструменты для разработчиков, такие как Python 3.15.2, Perl 5.44.0, Rust 1.99.0, Clang 23.1.4, GCC 15.3.0, Go 1.26.10, netbeans 31, PHP 8.5, ruby 4.0.9.
- Обновлены средства виртуализации и эмуляции, например QEMU 11.1.2, VirtualBox 7.2.22. В отдельный пакет из QEMU вынесен guest agent.
- Обновлены серверные пакеты, такие как OpenSSH 10.6p1, OpenSSL 3.5.9, MariaDB 12.3.3, apache httpd 2.4.69, bind 9.20.30, postfix 3.11.7.
- Добавлены новые пакеты с TeX Live 2026 и Foliate 3.2.1
- В сборки для архитектуры SPARC включены OpenJDK 11/17, ripgrep и Claws Mail.

Помимо этого[опубликован](https://omnios.org/article/r60)релиз дистрибутива[OmniOS Community Edition r151060](https://omnios.org/), основанного на наработках проекта[Illumos](https://illumos.org/), продолжающего развитие ядра, сетевого стека, файловых систем, драйверов, библиотек и базового набора системных утилит OpenSolaris. OmniOS примечателен предоставлением поддержки гипервизоров bhyve и KVM, виртуального сетевого стека Crossbow, файловой системы ZFS и средств запуска легковесных Linux-контейнеров. Дистрибутив может применяться для построения масштабируемых web-систем, виртуализации и создания систем хранения.

Среди изменений в[новом выпуске](https://github.com/omniosorg/omnios-build/blob/r151060/doc/ReleaseNotes.md):

- Проведена оптимизация производительности системы управления пакетами IPS, позволившая сократить время запуска утилиты pkg, снизить потребление памяти и ускорить операции установки и удаления пакетов. Внесены изменения в формат БД с информацией о пакетах (для преобразования старых файлов в новый формат требуется запуск команды "pkg update-format").
- В NFS-сервер добавлена поддержка делегирования операций с каталогами клиенту (directory delegation), что позволяет определённое время выполнять операции без проверки изменения состояния на сервере.
- В SMB-клиент добавлена поддержка протокола SMB 3.1.1.
- В ядре реализован системный вызов posix_spawn() для ускорения создания дочерних процессов.
- В virtio реализована поддержка множественных очередей и индексов событий, позволяющих повысить производительность сетевых операций в виртуальных машинах. Для IPv6 добавлена поддержка механизма аппаратного ускорения TSO (TCP Segmentation Offload) для выноса на сторону сетевой карты операций объединения пакетов.
- Добавлена новая команда "zpool wait".
- По умолчанию в новых установках включена рандомизация адресного пространства (ASLR).
- Обновлён OpenSSH 10.6p1.
