# Выпуск Proton 11.0-3, пакета для запуска Windows-игр в Linux

## Краткое содержание

Компания Valve выпустила новую версию проекта Proton — 11.0-3. Проект основан на кодовой базе Wine. Его главная цель — обеспечить запуск игровых приложений, созданных для Windows, в среде Linux. В первую очередь Proton ориентирован на игры, доступные в каталоге Steam. Проект распространяется под свободной лицензией BSD.

## Полная статья

Компания Valve[опубликовала](https://github.com/ValveSoftware/Proton/releases/tag/proton-11.0-3)релиз проекта[Proton 11.0-3](https://github.com/ValveSoftware/Proton/), основанного на кодовой базе проекта Wine и нацеленного на обеспечение запуска в Linux игровых приложений, созданных для Windows и представленных в каталоге Steam. Наработки проекта[распространяются](https://github.com/ValveSoftware/Proton/)под лицензией BSD.

Proton позволяет напрямую запускать в Linux-клиенте Steam игровые приложения, поставляемые только для Windows. Пакет включает в себя реализацию DirectX 8/9/10/11 (на базе пакета[DXVK](https://www.opennet.ru/opennews/art.shtml?num=65775)) и DirectX 12 (на базе[vkd3d-proton](https://github.com/HansKristian-Work/vkd3d-proton)), работающие через трансляцию вызовов DirectX в API Vulkan, предоставляет улучшенную поддержку игровых контроллеров и возможность использования полноэкранного режима независимо от поддерживаемых в играх разрешений экрана. Для увеличения производительности многопоточных игр поддерживаются механизмы "[esync](https://www.opennet.ru/opennews/art.shtml?num=50475)" (Eventfd Synchronization) и "[futex/fsync](https://www.opennet.ru/opennews/art.shtml?num=51197#fsync)".
