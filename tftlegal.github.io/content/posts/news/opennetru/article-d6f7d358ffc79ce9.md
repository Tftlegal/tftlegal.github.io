# Выпуск GhostBSD 26.2

## Краткое содержание

GhostBSD 26.2 — это десктопный дистрибутив, основанный на FreeBSD 15. Он предлагается в трёх вариантах пользовательского окружения: Gershwin, MATE и Xfce. По умолчанию используется файловая система ZFS. Дистрибутив поддерживает как работу в Live-режиме, так и полноценную установку на диск. Для установки применяется собственный инсталлятор ginstall, написанный на Python. Загрузочные образы доступны для архитектуры x86_64.

## Полная статья

[Представлен](https://ghostbsd.org/node/68)релиз десктоп-ориентированного дистрибутива[GhostBSD 26.2](https://ghostbsd.org/), построенного на базе FreeBSD 15 и предлагающего сборки с пользовательскими окружениями[Gershwin](https://www.opennet.ru/opennews/art.shtml?num=63780), MATE и Xfce. По умолчанию в GhostBSD применяется файловая система ZFS. Поддерживается как работа в Live-режиме, так и установка на жесткий диск (используется собственный инсталлятор ginstall, написанный на языке Python). Загрузочные образы[сформированы](https://www.ghostbsd.org/download)для архитектуры x86_64.

В новой версии:

- Реализован новый инсталлятор. Процесс установки разделён на два этапа: Install Station для установки системных компонентов на носитель и Setup Station для настройки и создания пользователей при первой загрузке новой системы. Добавлены новые страницы для настройки ZFS и сети. Реализована поддержка полнодискового шифрования c использованием инструментария[GELI](https://man.freebsd.org/cgi/man.cgi?geli).
- Осуществлён переход на[FreeBSD 15.1](https://www.opennet.ru/opennews/art.shtml?num=65697)(ранее дистрибутив базировался на FreeBSD 15.0).
- По умолчанию скрыто загрузочное меню, которое теперь появляется после нажатия любой клавиши. В загрузочное меню добавлена опция для включения отображения загрузочного лога.
- Приложение Backup Station переименовано в BE Station и может использоваться для создания загрузочных окружений.
- В приложении Update Station реализована установка обновлений в загрузочном окружении.
- В NetworkMgr для управления Wi-Fi задействована утилита wpa_cli и обеспечено сохранение параметров беспроводной сети только после успешного подключения.
- В менеджер приложений Software Station добавлена поддержка поиска без учёта регистра символов.
- Сокращён размер iso-образа, за счёт[удаления](https://github.com/ghostbsd/ghostbsd-build/pull/276)из базовой системы устаревших и серверных пакетов: audit, autofs, bsnmp, hast, inetd, kerberos, nuageinit, quotacheck, rdma, librpcsec_gss, yp, cxgbe-tools, mlx-tools, librss, netmap, apm, at, ftp, ppp, natd, rcmds, ccdconfig, libvgl, ipf, pf, ctf, dtrace, dwatch, lldb, lib9p, libvmmapi.
- Добавлена комбинация клавиш Ctrl+Alt+T для открытия терминала в MATE.
- Через фоновый процесс usbhid реализована поддержка устройств ввода с интерфейсом USB.
