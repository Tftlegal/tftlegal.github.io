# Дистрибутив Cutefish развивает прослойку для запуска macOS-приложений в Linux

## Краткое содержание

Разработчики дистрибутива Cutefish, создающего среду рабочего стола в стиле macOS, анонсировали создание прослойки Reef. Данная прослойка предназначена для запуска приложений, собранных под macOS, непосредственно в Linux. Программы для macOS устанавливаются с помощью файлов в формате dmg. После установки они интегрируются с основным рабочим столом Linux. Таким образом, пользователи Cutefish получают возможность использовать macOS-софт без необходимости перехода на другую операционную систему.

## Полная статья

Разработчики дистрибутива[Cutefish](https://cutefish.org/), развивающего одноимённую[среду рабочего стола](https://www.opennet.ru/opennews/art.shtml?num=55319)в стиле macOS,[объявили](https://cutefish.org/blog/mac-apps-first-milestone/)о разработке прослойки[Reef](https://cutefish.org/blog/running-mac-apps)для запуска приложений macOS в Linux. Собранные для macOS программы устанавливаются из файлов в формате dmg и интегрируются с основным рабочим столом в Linux.

Приложения выполняются без эмуляторов, виртуальных машин и проприетарных компонентов macOS. Reef развивается с нуля без использования наработок проекта[Darling](https://github.com/darlinghq/darling/)и без обратного инжиниринга закрытого ПО Apple. В процессе разработки функциональность реализуется отталкиваясь от возможностей, необходимых для запуска конкретных приложений - разработчики пытаются запустить какую-то программу, выявляют неработающие функции и реализуют их. Код Reef пока не опубликован публично, но в скором времени прослойку обещают добавить в состав дистрибутива[Cutefish](https://download.cutefish.org/).

Созданная проектом Cutefish прослойка насчитывает около 460 тысяч строк кода и использует некоторые компоненты macOS, поставляемые Apple под открытыми лицензиями, такие как Core Foundation ([swift-corelibs-foundation](https://github.com/swiftlang/swift-corelibs-foundation)), Grand Central Dispatch ([swift-corelibs-libdispatch](https://github.com/swiftlang/swift-corelibs-libdispatch)), стандартная библиотека языка[Swift](https://github.com/swiftlang/swift), библиотеки[Libc](https://github.com/apple-oss-distributions/Libc)и[lzfse](https://github.com/lzfse/lzfse). Загрузчик и Objective-C runtime написаны с нуля на основе изучения кода[objc4 runtime](https://github.com/apple-oss-distributions/objc4), компоновщика[dyld](https://github.com/apple-oss-distributions/dyld)и ядра[xnu](https://github.com/apple-oss-distributions/xnu), но без его копирования. В проекте также используются WebKit, LLVM libc++, libc++abi, libunwind, curl, SQLite и Tcl. Графический API Metal реализован поверх OpenGL. Предоставляется сетевой фреймворк, реализация API Core Data, поддержка автосохранения окон и инерционная прокрутка в стиле macOS.

Из уже запускаемых поверх Reef программ отмечены RSS-ридер NetNewsWire, эмулятор терминала Ghostty, архиватор Keka, текстовые редакторы CotEditor и TextMate, календарь Itsycal, система заметок Things 3 и тест Speedtest. При тестировании производительности, программы для macOS пока выполняются в несколько раз медленнее, например, исполняемый файл CotEditor для Linux запускается за 115 мс, а для macOS за 235 мc, различия во времени открытия файла с 20 тысячами строк составляют 0.12 сек. против 0.50 сек., реагирование на нажатие клавиши - 18 мс против 21 мс, а время отрисовки при прокрутке - 1.2 мс против 4.4 мс.
