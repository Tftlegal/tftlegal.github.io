# Релиз Firefox 156

## Краткое содержание

Вышел браузер Firefox 156.
Одновременно подготовлены обновления веток с длительной поддержкой: 153.3.0, 140.16.0 и 115.41.0.
Эти версии поддерживают прежние линии Firefox.
Ветка Firefox 157 переведена на бета-тестирование.
Её релиз запланирован на 29 сентября в рамках нового двухнедельного цикла.

## Полная статья

[Состоялся](https://www.mozilla.org/en-US/firefox/156.0/releasenotes/)релиз web-браузера[Firefox 156](https://www.mozilla.org/en-US/firefox/156.0/releasenotes/)и сформированы обновления[прошлых веток](https://www.mozilla.org/en-US/firefox/organizations/all/)с длительным сроком поддержки -[153.3.0](https://www.mozilla.org/en-US/firefox/153.3.0/releasenotes/),[140.16.0](https://www.mozilla.org/en-US/firefox/140.16.0/releasenotes/)и[115.41.0](https://www.mozilla.org/en-US/firefox/115.41.0/releasenotes/). В рамках нового[двухнедельного цикла](https://www.opennet.ru/opennews/art.shtml?num=65900)формирования релизов на стадию[бета-тестирования](https://firefox.com/channel)[переведена](https://www.mozilla.org/en-US/firefox/157.0beta/releasenotes/)ветка Firefox 157, релиз которой намечен на 29 сентября.

Основные новшества в Firefox 156 ([1](https://www.mozilla.org/en-US/firefox/156.0/releasenotes/),[2](https://developer.mozilla.org/en-US/docs/Mozilla/Firefox/Releases/156),[3](https://bugzilla.mozilla.org/buglist.cgi?query_format=advanced&resolution=FIXED&target_milestone=156%20Branch&limit=0&short_desc_type=anywords&short_desc=Allow Enable Add Drop Support Implement)):

- На 45% ускорен запуск встроенного PDF-просмотрщика.
- Снижено потребление памяти и уменьшена нагрузка на CPU при отображении больших JPEG-изображений, отмасштабированных для того, чтобы вместиться на страницу.
- На платформе Windows с процессорами на базе архитектуры ARM64 в видеовызовах на базе WebRTC задействовано аппаратное ускорение декодирования потоков H264.
- На платформе macOS добавлена возможность автоматического открытия браузера после загрузки компьютера.
- CSS-свойство text-box-trim, определяющее область обрезки отступов вокруг текста, теперь рассчитывает размеры обрезки с учётом метрик шрифта, применяемого для отрисовки первой строки текста, стилизованной при помощи псевдоэлемента "::first-line".
- В[версии](https://www.firefox.com/en-US/firefox/android/156.0/releasenotes/)для платформы Android добавлен встроенный VPN с 50 ГБ ежемесячного трафика (активириван для части пользователей). Добавлена возможность смены позиции в воспроизводимом в браузере видео или музыке прямо из области уведомлений. Задействовано предоставляемое платформой Android меню для обмена данными (share) c дополнительными опциями, такими как отправка вкладки на другое устройство и сканирование QR-кода.

Кроме новшеств и исправления ошибок, в Firefox 156 устранено 74[уязвимости](https://www.mozilla.org/en-US/security/advisories/mfsa2026-90/), большинство из которых вызваны проблемами при работе с памятью, такими как переполнения буферов и обращение к уже освобождённым областям памяти. Потенциально данные проблемы способны привести к выполнению кода злоумышленника при открытии специально оформленных страниц.
