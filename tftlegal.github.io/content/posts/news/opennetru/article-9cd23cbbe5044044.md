# Выпуск видеоредактора KeyCut 1.0

## Краткое содержание

Вышел релиз видеоредактора KeyCut 1.0.  
Он позволяет нарезывать и склеивать видео без перекодирования.  
Обрезка выполняется строго по ключевым кадрам.  
При экспорте сохраняется прямая копия исходных данных, поэтому качество остаётся прежним, а обработка идёт быстро даже на больших файлах.  
Проект написан на JavaScript, использует FFmpeg и распространяется под лицензией MIT.  
Готовые сборки доступны для Linux, Windows и macOS.
