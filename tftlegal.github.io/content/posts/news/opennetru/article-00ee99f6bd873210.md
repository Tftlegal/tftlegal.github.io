# Первый выпуск программы для ведения списка задач QGoForIt

## Краткое содержание

Состоялся первый релиз программы QGoForIt, предназначенной для ведения списка задач. По функциональности она напоминает приложение GoForIt. Однако QGoForIt реализована с использованием фреймворка Qt. Исходный код проекта написан на языке C++. Программа распространяется под свободной лицензией GPLv3.

## Полная статья

[Состоялся](https://github.com/ivnish/QGoForIt/releases/tag/0.1)первый релиз программы для ведения списка задач[QGoForIt](https://github.com/ivnish/QGoForIt), напоминающей по своим возможностям приложение[GoForIt](https://github.com/Manuel-Kehl/Go-For-It), но написанной с использованием Qt. Код проекта написан на С++ и[распространяется](https://github.com/ivnish/QGoForIt/)под лицензией GPLv3.

Возможности, реализованные в QGoForIt:

- Два списка: активные задачи (To-Do) и завершённые (Done).
- Хранение задач в простых текстовых файлах todo.txt и done.txt (формат todo.txt).
- Переименование задачи двойным кликом прямо в списке.
- Изменение порядка задач перетаскиванием.
- Завершённая задача перемещается в список Done с датой завершения, снятие галочки возвращает её в список To-Do.
- Встроенный таймер с настраиваемой длительностью работы и перерыва, управлением старт/пауза/продолжить/пропустить/сброс, автоматическим перерывом после рабочего периода и уведомлениями на рабочем столе о завершении каждой фазы.
- Запоминание размера и положения окна между запусками.

Среди отличий от GoForIt: автоматическая очистка завершённых задач старше N дней; отслеживание внешних изменений todo.txt; защита от запуска второй копии; portable-режим, при котором данные, конфигурация, иконки и переводы хранятся рядом с исполняемым файлом.

Пока не реализовано: несколько списков задач, фильтрация по проектам и контекстам и поддержка плагинов.
