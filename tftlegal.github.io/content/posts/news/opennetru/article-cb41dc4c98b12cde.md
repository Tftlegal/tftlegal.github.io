# Выпуск системы тестирования памяти Memtest86+ 9.0

## Краткое содержание

Вышел новый выпуск программы Memtest86+ версии 9.0, предназначенной для тестирования оперативной памяти. Программа не зависит от операционной системы и запускается непосредственно из BIOS/UEFI или загрузчика. Она позволяет провести полную проверку RAM. При обнаружении ошибок программа строит карту сбойных участков памяти. Эта карта может быть использована в ядре Linux через опцию memmap для исключения проблемных областей из использования. Исходный код проекта распространяется под лицензией GPLv2.
