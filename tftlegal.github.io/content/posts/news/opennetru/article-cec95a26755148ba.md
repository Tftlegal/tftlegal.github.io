# Первый выпуск osu!cpp, неофициального клиента для игры osu! на C++23 и Skia

## Краткое содержание

Опубликован первый выпуск osu-cpp — неофициального клиента ритм-игры osu!.
Он написан на C++23 с использованием модулей и рендерится через библиотеку Skia.
Код распространяется под лицензией AGPLv3.
Клиент собирается для Linux, Flatpak, Nix, Guix, браузеров на WebAssembly, Android и Ubuntu Touch.
Браузерную версию можно запустить без установки, а вместе с клиентом развиваются библиотеки skiff и skiff-widgets для построения графического интерфейса.

## Полная статья

[Опубликован](https://github.com/j4niwzis/osu-cpp/releases/tag/v0.1.0)первый выпуск[osu-cpp](https://github.com/j4niwzis/osu-cpp), неофициального клиента ритм-игры[osu!](https://ru.wikipedia.org/wiki/Osu!), написанного на C++23 в виде модулей и использующего для отрисовки библиотеку[Skia](https://skia.org/). Код[распространяется](https://github.com/j4niwzis/osu-cpp/)под лицензией AGPLv3. Клиент собирается для Linux (обычная сборка, Flatpak, Nix, Guix), для браузера (WebAssembly), для Android и для Ubuntu Touch.[Браузерную версию](https://j4niwzis.github.io/osu-cpp/)можно запустить без установки. Вместе с клиентом под лицензией AGPLv3 развиваются библиотеки для построения графического интерфейса[skiff](https://github.com/j4niwzis/skiff)и[skiff-widgets](https://github.com/j4niwzis/skiff-widgets).

Основные возможности:

- Режим osu!standard;
- pp (Performance Points), которые считаются прямо во время игры;
- Запись и воспроизведение реплеев, экспорт реплея в видео MP4;
- Загрузка карт через зеркала osu.direct и catboy.best, импорт архивов .osz;
- Отрисовка через OpenGL, через Vulkan или программно;
- Поддержка частичной локализованной отрисовки в меню;
- Отсутствие отрисовки, когда на экране ничего не меняется.

Выпуск собирается дважды, второй раз без кеша компилятора, и результаты сравниваются для проверки воспроизводимости сборок: у 0.1.0 все сборки полностью совпали. Для Android используется сборка минимального Android NDK посредством[minimal-android-ndk.cpp](https://github.com/j4niwzis/minimal-android-ndk.cpp)(AGPLv3), так как официальные бинарные сборки Android NDK распространяются под проприетарной лицензией. Весь код распространяется под AGPLv3, но при первом запуске опционально скачивается несвободный скин под лицензией CC-BY-NC-4.0. Приложение может работать и без него.
