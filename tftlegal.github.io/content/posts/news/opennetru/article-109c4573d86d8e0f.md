# Третий альфа-выпуск мессенджера Pidgin 3

## Краткое содержание

Представлен третий альфа-выпуск Pidgin 3.0 (версия 2.97) — клиента для мгновенного обмена сообщениями. Выпуск носит тестовый характер и официально не готов к ежедневному использованию. Сборки доступны в формате Flatpak. Они размещены в бета-репозитории на платформе Flathub. Таким образом, проект находится на этапе активного тестирования перед полноценным релизом. Пользователям следует учитывать возможную нестабильность при установке данной версии.

## Полная статья

[Представлен](https://discourse.imfreedom.org/t/pidgin-3-0-alpha-3-2-97-0-has-been-released/436)третий альфа-выпуск клиента для мгновенного обмена сообщениями[Pidgin 3.0](https://pidgin.im/)(2.97). Выпуск отмечен как ещё не готовый для повседневного применения. Сборки подготовлены в формате[Flatpak](https://flathub.org/en/apps/im.pidgin.Pidgin)и размещены в[beta-репозитории](https://docs.flathub.org/docs/for-users/installation)на Flathub.

Ветка Pidgin 3[разрабатывается](https://developer.pidgin.im/wiki/Roadmap3.0.0)с 2011 года, а до этого ещё три года обсуждалась на уровне концепций и идей. В Pidgin 3 выполнен переход на систему типов GObject, библиотек GTK4 и Adwaita, сборочную систему Meson, GPlugin для обработки плагинов, SQLite для хранения истории чатов и GSettings для работы с настройками. Полностью переработан API. Для определения элементов интерфейса задействован GTK Builder XML, а для отображения истории чатов создана собственная библиотека виджетов[Talkatu](https://keep.imfreedom.org/talkatu/talkatu).

В интерфейсе Pidgin 3 объединены в одном окне список контактов и чат. Прекращена поставка консольного клиента Finch (не исключено, что его могут вернуть в будущем). Из протоколов пока развиваются реализации протоколов IRCv3, XMPP, SIP, Demo, Bonjour и Zulip. Ветка Pidgin 3 несовместима с Pidgin 2 и ранее созданными плагинами, но может быть установлена параллельно с имеющимися сборками Pidgin 2.
