# Выпуск Gotcha 1.0, платформы мониторинга ошибок и производительности

## Краткое содержание

Вышел выпуск Gotcha 1.0 — self-hosted-платформы мониторинга.
Она объединяет отслеживание ошибок, распределённые трейсы, метрики, профили, логи, доступность со status-страницами и мониторинг хостов.
Проект написан на Go и распространяется под лицензией Apache-2.0.
Данные принимаются по протоколам Sentry SDK и OTLP, хранятся в PostgreSQL и ClickHouse, а минимальные требования — 2 vCPU и 2 ГБ ОЗУ.
Интерфейс, шаблоны писем и документация доступны на русском и английском языках.

## Полная статья

[Опубликован](https://github.com/OtezVikentiy/gotcha/releases/tag/v1.0.0)выпуск[Gotcha 1.0](https://getgotcha.ru/)- self-hosted-платформы мониторинга, объединяющей отслеживание ошибок, распределённые трейсы, метрики, профили, логи, мониторинг доступности с публичными статус-страницами и мониторинг хостов. Проект написан на Go и[распространяется](https://github.com/OtezVikentiy/gotcha/)под лицензией Apache-2.0. Приём данных совместим с протоколом Sentry SDK и OTLP, данные хранятся в PostgreSQL и ClickHouse. Минимальные требования - 2 vCPU и 2 ГБ ОЗУ. Интерфейс, шаблоны писем и документация доступны на русском и английском языках.

Номер версии 1.0 свидетельствует о фиксации обратной совместимости: имена переменных окружения, адреса приёма и форматы тел запросов, направление миграций, формат резервных копий, тело исходящего вебхука и адреса уже опубликованных статус-страниц с этого выпуска меняются только обратно совместимо, всё остальное - в ветке 2.0. Три устаревших адреса Web API (/logs, /profiles/pprof и /api/{project}/deployments/) продолжают работать и будут удалены только в следующем значительном выпуске.

Со времени[освещавшихся ранее](https://www.opennet.ru/opennews/art.shtml?num=66041)выпусков 0.5-0.17 добавлены:

- Группы инцидентов, сворачивающие каскадную аварию в одну карточку;
- Подавление уведомлений по графу зависимостей;
- Готовые конфигурации коллектора для PostgreSQL, nginx, Redis, Docker и MariaDB;
- Фоновые выгрузки ошибок и событий в CSV, JSON и NDJSON с маскированием персональных данных;
- Ротация мастер-ключа шифрования без остановки;
- Собственные метрики приёма и живости фоновых обработчиков;
- Отдельное пространство имён /api/v1/* для точек приёма и типы DSN-ключей, при которых раскрытый браузерный ключ не может зарегистрировать хост.
- При конфигурации, которую процесс не может выполнить, запуск теперь останавливается с явной ошибкой вместо подстановки значения по умолчанию.
