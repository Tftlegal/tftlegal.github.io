# Nitter и XCancel возобновили работу после консультации с юристами

## Краткое содержание

Сервисы Nitter и XCancel возобновили работу.
Они позволяют просматривать сообщения из X (Twitter) без регистрации.
Репозиторий проекта Nitter был выведен из архивного режима.
Проект развивал свободный фронтенд для X.com без навязываемого JavaScript, аналитики, трекеров и сторонних сервисов.
Автор Nitter сообщил, что проект вернулся после консультации с юристами.
Создатели XCancel также объявили о возобновлении работы.
Дополнительные подробности планируют раскрыть позже.
