# Выпуск мультимедиа-пакета FFmpeg 9.1

## Краткое содержание

Вышел мультимедиа-пакет FFmpeg версии 9.1. Разработка данной версии заняла три месяца. Пакет представляет собой набор приложений и коллекцию библиотек. Он предназначен для работы с различными мультимедиа-форматами. Основные операции включают запись, преобразование и декодирование звуковых и видеофайлов. Код проекта написан на языке Си. Распространение осуществляется под лицензиями LGPL и GPL.

## Полная статья

После трёх месяцев разработки[опубликован](https://ffmpeg.org/download.html#releases)мультимедиа-пакет[FFmpeg 9.1](http://ffmpeg.org/), включающий набор приложений и коллекцию библиотек для операций над различными мультимедиа-форматами (запись, преобразование и декодирование звуковых и видеоформатов). Пакет написан на языке Си и[распространяется](https://github.com/FFmpeg/FFmpeg)под лицензиями LGPL и GPL.

Среди[изменений](https://github.com/FFmpeg/FFmpeg/blob/master/Changelog)в FFmpeg 9.1:

- Добавлен сетевой бэкенд на базе библиотеки[libcurl](https://curl.se/libcurl/).
- [Предложен](https://github.com/FFmpeg/FFmpeg/commit/32a256f619a344a7a351b89709f4a7de732268eb)экспериментальный API для создания[bitstream-фильтров](https://ffmpeg.org/ffmpeg-bitstream-filters.html)для прямой модификации упакованного битового потока без его декодирования. Новый API позволяет объединять фильтры в нелинейные графы, допускающие сложную маршрутизацию, слияние и разделение потоков.
- В утилиту командной строки ffmpeg[добавлена](https://github.com/FFmpeg/FFmpeg/commit/4eb56054c203a4e5139ef485ec51ffa214cb469f)возможность работы с двутрековыми представлениями формата кодирования видео[LCEVC](https://en.wikipedia.org/wiki/LCEVC)(Low Complexity Enhancement Video Coding), в которых базовое видео и метаданные для улучшения качества хранятся в форме отдельных треков.
- [Добавлена](https://github.com/FFmpeg/FFmpeg/commit/acbaf420aade95d5965260ede91945b194093b32)поддержка передачи декодированных видеокадров из аппаратного декодера NVIDIA NVDEC в память GPU с использованием текстурных массивов[CUARRAY](https://docs.nvidia.com/video-technologies/video-codec-sdk/13.1/nvdec-video-decoder-api-prog-guide/NVDEC)(CUDA array) вместо буфера CUdeviceptr для улучшения совместимости с графическим API Vulkan. Поддержка CUARRAY добавлена для кодеков H.264, HEVC, AV1, MPEG-1, MPEG-2, MPEG-4, VC-1, WMV3, VP8 и VP9.
- Добавлены упаковщики и распаковщики медиаконтейнеров astc и KTX 1.0, применяемых для хранения текстур. При помощи библиотеки[libastcenc](https://github.com/ARM-software/astc-encoder)реализована поддержка сжатия и распаковки текстур в формате[ASTC](https://en.wikipedia.org/wiki/Adaptive_scalable_texture_compression)(Adaptive Scalable Texture Compression).
- [Реализована](https://github.com/FFmpeg/FFmpeg/commit/c2802e520a08dbf0c939ec8b5653b29dfd886427)поддержка выбора устройств захвата видео и звука[AVFoundation](https://developer.apple.com/documentation/avfoundation)по уникальному идентификатору иди серийному номеру USB-устройства. Для указания идентификаторов добавлены опции "-video_device_id" и "-audio_device_id".
- [Добавлен](https://github.com/FFmpeg/FFmpeg/commit/876d10f68346f7c1d4efcdb73e06cb4545ea0528)вариант кодировщика (apv_vulkan) для формата[APV](https://www.opennet.ru/opennews/art.shtml?num=66282)(Advanced Professional Video), использующий для ускорения возможности графического API Vulkan и вычислительные шейдеры.
- Добавлен кодировщик для формата DSD (dsd_msbf).
- Значительно улучшен кодировщик для звукового формата[AAC](https://en.wikipedia.org/wiki/Advanced_Audio_Coding)(Advanced Audio Coding). Добавлена поддержка декодирования формата[xHE-AAC](https://en.wikipedia.org/wiki/Unified_Speech_and_Audio_Coding#xHE-AAC)(Extended High-Efficiency AAC, стандарт ISO/IEC 23003-3, используется в потоковом вещании Netflix) при помощи библиотеки[libfdk-xhe-aac](https://github.com/mstorsjo/fdk-aac/).
- [Добавлена](https://github.com/FFmpeg/FFmpeg/commit/5212830ee809d09fec41b220871cb9eeab87716c)поддержка декодирования секционированных (partitioning) видеопотоков H.264, в которых каждый кадр разделяется на несколько частей.
- Добавлены декодировщики для форматов Infinity IMM6, Rhetorex ADPCM, ADPCM IMA Citrix и Panasonic RW2.
- Реализованы декодировщик и распаковщик медиаконтейнеров для формата[DVD-Audio LPCM](https://en.wikipedia.org/wiki/DVD-Audio)(Linear Pulse Code Modulated).
- Добавлены упаковщики медиаконтейнеров в форматах iTerm2 и JPEG Multi-Picture.
- Добавлены распаковщики медиаконтейнров в форматах MVR и JPEG Multi-Picture.
- Для платформы Windows реализована поддержка протокола "handle:", позволяющего использовать дескрипторы HANDLE из WinAPI и поддерживающего произвольный доступ, а не только линейное чтение как при использовании протокола "pipe:".
- В бэкенд ONNX Runtime добавлена возможность запуска нейросетевых фильтров в Windows, используя реализованную поверх API Direct3D 12 библиотеку DirectML в режиме zero-copy (без копирования видеокадров между видеопамятью ОЗУ).
- Новые[фильтры](https://ffmpeg.org/ffmpeg-filters.html):

- [vf_fruc_vulkan](https://github.com/FFmpeg/FFmpeg/commit/67d341f49eba27a8e52404bdce8915ad07a1c12f)- повышает частоту кадров видео через дорисовку промежуточных кадров с помощью аппаратного ускорителя NVIDIA Optical Flow Accelerator, используя Vulkan-расширение VK_NV_optical_flow.
- [gainmap](https://ffmpeg.org/ffmpeg-filters.html#gainmap)- вычисляет карту повышения яркости (HDR Gain Map) на основе SDR- и HDR-версий одного и того же изображения.
- [latticepal](https://ffmpeg.org/ffmpeg-filters.html#latticepal)- преобразует полноцветное RGB/BGR-изображение в формат c 8-разрядной палитрой PAL8.
- [vf_vqe_amf](https://github.com/FFmpeg/FFmpeg/commit/fc4b5235963441cf29fa3c9f0f6d6ad1e61b8749)- повышает качество видео на системах с GPU AMD, используя механизм подавления шумов VQE (Video Quality Enhancer), доступный в Advanced Media Framework (AMF).
- Добавлены bitstream-фильтры:[trim](https://ffmpeg.org/ffmpeg-bitstream-filters.html#trim)(удаление пакетов вне заданного диапазона),[jpegapp](https://ffmpeg.org/ffmpeg-bitstream-filters.html#jpegapp)(подстановка сегментов JPEG APP0..APP15) и[side_data](https://ffmpeg.org/ffmpeg-bitstream-filters.html#side_005fdata)(удаление служебных метаданных).
- Добавлен фильтр[слияние слоёв](https://github.com/FFmpeg/FFmpeg/commit/4eb56054c203a4e5139ef485ec51ffa214cb469f)(слой с базовым видео и слой с метаданными для улучшения качества) для видео в формате LCEVC.
