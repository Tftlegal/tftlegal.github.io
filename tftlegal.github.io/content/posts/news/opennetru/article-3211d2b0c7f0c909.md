# Релиз шрифтового движка FreeType 2.15

## Краткое содержание

Вышел релиз FreeType 2.15.0 — модульного движка обработки шрифтов, разработка которого заняла около года. Проект предоставляет единый API для унификации работы с шрифтовыми данными в различных векторных и растровых форматах. Благодаря этому FreeType позволяет единообразно обрабатывать и выводить шрифты независимо от используемого формата. Код написан на языке Си. Распространение проекта осуществляется под лицензией FreeType, которая является аналогом BSD-лицензии.
