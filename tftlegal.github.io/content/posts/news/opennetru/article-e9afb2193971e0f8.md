# Выпуск среды рабочего стола Budgie 10.10.4

## Краткое содержание

Представлен  выпуск  среды рабочего стола  Budgie  10.10.4, ставший четвёртым обновлением ветки 10.10, переведённой на использование протокола Wayland. Одновременно сформированы аналогичные выпуски для сопутствующих компонентов, таких как рабочий стол Budgie Desktop View и набор сервисов Budgie Desktop Services (обновление  менеджера сеансов Budgie Session и  интерфейса для настройки системы Budgie Control Center   задерживается). Код проекта распространяется под лицензией GPLv2.

## Полная статья

[Представлен](https://buddiesofbudgie.org/blog/budgie-10-10-4-released)выпуск среды рабочего стола[Budgie 10.10.4](https://github.com/BuddiesOfBudgie/budgie-desktop/), ставший четвёртым обновлением ветки 10.10,[переведённой](https://www.opennet.ru/opennews/art.shtml?num=64587)на использование протокола Wayland. Одновременно сформированы аналогичные выпуски для сопутствующих компонентов, таких как рабочий стол[Budgie Desktop View](https://github.com/BuddiesOfBudgie/budgie-desktop-view/tags)и набор сервисов[Budgie Desktop Services](https://forge.moderndesktop.dev/BuddiesOfBudgie/budgie-desktop-services/tags)(обновление менеджера сеансов[Budgie Session](https://github.com/BuddiesOfBudgie/budgie-session/tags)и интерфейса для настройки системы[Budgie Control Center](https://github.com/BuddiesOfBudgie/budgie-control-center/tags)задерживается). Код проекта[распространяется](https://github.com/BuddiesOfBudgie/)под лицензией GPLv2. Пакеты с Budgie 10.10.4[доступны](https://packages.fedoraproject.org/pkgs/budgie-desktop/budgie-desktop/)в Fedora Rawhide.

Основу Budgie составляет панель, близкая по организации работы к классическим панелям рабочего стола. Все элементы панели являются апплетами, что позволяет гибко настраивать состав, менять размещение и заменять реализации основных элементов панели на свой вкус. Среди доступных апплетов можно отметить классическое меню приложений, систему переключения задач, область со списком открытых окон, просмотр виртуальных рабочих столов, индикатор управления питанием, апплет управления уровнем громкости, индикатор состояния системы и часы.

Среди изменений в новой версии:

- Реализована поддержка автоматического скрытия панели для предоставления всего экранного пространства окнам, развёрнутым на весь экран. Также полностью переписана реализация режима закрепления панели (Dock Mode). После перехода на Wayland из-за отсутствия передачи информации о точных координатах и размерах окон старая логика автоскрытия и закрепления перестала нормально работать и её пришлось полностью переделать. Панель больше не резервируют место на экране, а размещается поверх других окон, но при скрытии становится невидимой и оставляет 3-пиксельную область у края экрана для раскрытия при наведении на неё курсора. Автоскрытие отключается когда открыто меню, виджеты или любые другие всплывающие окна панели.

Предложено два режима автоматического скрытия панели: автоматический (Automatic) и умный (Intelligent), которые работают в привязке к состоянию раскрытия окон на весь экран. В первом случае панель скрывается, когда любое окно на текущем экране развёрнуто на весь экран, а во втором - только когда развёрнуто активное окно, у которого фокус ввода.

При просмотре видео на весь экран в случае наведения мыши на край экрана панель показывается поверх видео, но не активируется при запуске полноэкранных игр, захватывающих курсор. В случае включения в настройках опции для запрета скрытия панели, при выполнении полноэкранных приложений панель остаётся позади их окон, но её можно принудительно вывести на передний план комбинацией клавиш Super+T или нажатием клавиши Super для открытия меню Budgie.

- В боковой панели Raven реализована возможность переключения между виджетами и уведомлениями при помощи комбинаций клавиш Super+A и Super+N.
- Улучшена интеграция с композитным менеджером Labwc. Возвращена поддержка комбинации клавиш "Super+Shift+стрелка" для перемещения активного окна на другой монитор. Для окон в режиме "картинка в картинке, применяемых в "Firefox", обеспечено постоянное размещение поверх других окон. При клике левой кнопкой мыши на рабочем столе теперь просто переключается фокус на рабочий стол для предотвращения случайного открытия меню или запуска приложений при использовании тачпада.
- Добавлена возможность настройки времени неактивности, после которого снижается яркость экрана. В графическом конфигураторе опция пока отсутствует, но её уже можно выставить в командной строке ("gsettings set com.solus-project.budgie-wm dimming-delay 90")
- Добавлен параметр для выбора программы блокировки экрана (поддерживаются gtklock и swaylock), который пока можно изменить только в командной строке ("gsettings set org.buddiesofbudgie.budgie-locker locker-choice 'swaylock'").
- Реализовано кэширование списка установленных приложений, используемого в меню, списке задач и на странице автозапуска. Данная оптимизация ускорила запуск панели, но повысила потребление разделяемой памяти на 810 КБ.
- Для разработчиков предоставлена возможность использования команды "meson devenv" для запуска панели, апплетов и боковой панели Raven напрямую из сборочного каталога без установки в систему (например, "meson devenv -C build budgie-panel --replace &").
