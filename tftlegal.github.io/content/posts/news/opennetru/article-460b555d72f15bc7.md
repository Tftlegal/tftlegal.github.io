# Релиз Firefox 155

## Краткое содержание

Состоялся релиз веб-браузера Firefox 155.
Одновременно вышли обновления прошлых веток с длительной поддержкой: 153.2.0, 140.15.0 и 115.40.0.
Firefox 155 стал первым выпуском в рамках нового двухнедельного цикла формирования релизов.
Такой подход позволит чаще доводить новые возможности до пользователей, сделает процесс более предсказуемым и снизит нагрузку на разработчиков.
Ветка Firefox 156 переведена в стадию бета-тестирования, а её релиз запланирован на 15 сентября.

## Полная статья

[Состоялся](https://www.mozilla.org/en-US/firefox/155.0/releasenotes/)релиз web-браузера[Firefox 155](https://www.mozilla.org/en-US/firefox/155.0/releasenotes/)и сформированы обновления[прошлых веток](https://www.mozilla.org/en-US/firefox/organizations/all/)с длительным сроком поддержки -[153.2.0](https://www.mozilla.org/en-US/firefox/153.2.0/releasenotes/),[140.15.0](https://www.mozilla.org/en-US/firefox/140.15.0/releasenotes/)и[115.40.0](https://www.mozilla.org/en-US/firefox/115.40.0/releasenotes/). Firefox 155 стал первым выпуском, сформированным в рамках нового[двухнедельного цикла](https://www.opennet.ru/opennews/art.shtml?num=65900)формирования релизов, который позволит чаще доводить новые возможности до пользователей, обеспечит более предсказуемый процесс формирования релизов и снизит нагрузку на разработчиков перед релизами. На стадию[бета-тестирования](https://firefox.com/channel)[переведена](https://www.mozilla.org/en-US/firefox/156.0beta/releasenotes/)ветка Firefox 156, релиз которой намечен на 15 сентября.

Основные новшества в Firefox 155 ([1](https://www.mozilla.org/en-US/firefox/155.0/releasenotes/),[2](https://developer.mozilla.org/en-US/docs/Mozilla/Firefox/Releases/155),[3](https://bugzilla.mozilla.org/buglist.cgi?query_format=advanced&resolution=FIXED&target_milestone=155%20Branch&limit=0&short_desc_type=anywords&short_desc=Allow Enable Add Drop Support Implement)):

- Для всех пользователей из США, Канады и Франции активирован режим "[Smart Window](https://support.mozilla.org/kb/smart-window)", предоставляющий отдельное пространство взаимодействия с AI, дополняющее имеющийся стандартный режим навигации в Web и режим приватного просмотра. В новой версии добавлены персонализированные подсказки для быстрого запуска чата с AI на ранее затрагиваемые темы, значительно ускорено цитирование источников при поиске через сервис[exa.ai](https://exa.ai), улучшены рекомендации по группировке связанных вкладок и автоназначение имён группам вкладок.[

- В сборках для платформы Windows в web-играх появилась возможность использования игровых контроллеров, совместимых с Nintendo Switch Pro.
- Вложенность блоков и функций CSS ограничена 75 уровнями для защиты от аварийного завершения при обработке конструкций со слишком большим уровнем вложенности.
- Домен для проверки сетевой доступности и выявления наличия captive-портала изменён с detectportal.firefox.com на firefox-portal-detection.com.
- Прекращена обработка ссылок "mailto:" без явных действий пользователя (web-страница теперь не может автоматически инициировать открытие почтового клиента).
- При печати PDF-файлов, содержимое документа, размером меньше печатной страницы, теперь может быть отмасштабировано для заполнения всего листа.
- В инструментах для web-разработчиков опции для эмуляции возможностей CSS перенесены в новую панель, показываемую при нажатии кнопки "@" в окне Rules. Добавлена опция для эмуляции медиазапроса "prefers-reduced-motion". В отладчик JavaScript добавлена комбинация клавиш Ctrl+Alt+B для включения или отключения разом всех точек останова.
- В просмотрщике JSON реализована поддержка показа документов в формате "[JSON Lines](https://jsonlines.org/)" (JSONL и NDJSON), в которых в каждой строке размещается отдельный JSON-объект.
- Реализована CSS-функция[progress()](https://developer.mozilla.org/docs/Web/CSS/Reference/Values/progress)для вычисления позиции величины относительно указанных минимального и максимального значений ("progress(5, 0, 10)" вернёт 0.5).
- Добавлена CSS-функция[alpha()](https://developer.mozilla.org/docs/Web/CSS/Reference/Values/color_value/alpha), позволяющая изменить альфа-канал (степень прозрачности) для указанного цвета.
- Добавлена поддержка нового синтаксиса CSS-функции[attr(attr-name attr-type, fallback-value)](https://developer.mozilla.org/docs/Web/CSS/Reference/Values/attr), допускающего работу со значениями HTML-атрибутов любых типов, а не только со строками.
- Добавлена поддержка методов[Promise.allKeyed](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise/allKeyed)и[Promise.allSettledKeyed](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise/allSettledKeyed), которые аналогичны Promise.all() и Promise.allSettled(), за исключением принятия и возвращения объектов вместо массивов.
- Добавлена поддержка[расширения](https://github.com/WebAssembly/compact-import-section)бинарного формата WebAssembly, позволяющего сократить размер WebAssembly-модулей с большим числом импортируемых элементов.
- В WebAssembly добавлена поддержка[128-разрядных](https://github.com/WebAssembly/wide-arithmetic)арифметических инструкций i64.add128, i64.sub128, i64.mul_wide_s и i64.mul_wide_u.
- Предоставлена возможность использования в HTTP/3 второй версии протокола QUIC ([RFC 9369](https://www.rfc-editor.org/rfc/rfc9369.html)).
- Для SVG-элемента <a> в JavaScript-интерфейсе[SVGAElement](https://developer.mozilla.org/en-US/docs/Web/API/SVGAElement)предоставлен тот же набор[свойств](https://developer.mozilla.org/docs/Web/API/HTMLAnchorElement#instance_properties)URL, что доступны для ссылок в HTML.
- Добавлено CSS-свойство "[font-width](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/font-stretch)", аналогичное ранее доступному свойству "font-stretch".
- В API[WebTransport](https://developer.mozilla.org/en-US/docs/Web/API/WebTransport_API)реализована поддержка групп отправки для управления распределением пропускной способности между потоками ([createSendGroup()](https://developer.mozilla.org/en-US/docs/Web/API/WebTransport/createSendGroup)), отправки датаграмм ([createWritable()](https://developer.mozilla.org/en-US/docs/Web/API/WebTransportDatagramDuplexStream/createWritable)) и генерации ключей, привязанных к TLS-сессии (exportKeyingMaterial()).
- В[версии для Android](https://www.firefox.com/en-US/firefox/android/155.0/releasenotes/)реализован переход к редактированию панели инструментов после длительного нажатия на любую кнопку на панели. Упрощено исключение вкладок из группы. Изменена чувствительность активации функции резюмирования страницы[встряхиванием](https://blog.mozilla.org/en/firefox/shake-to-summarize-expansion/)смартфона.

Кроме новшеств и исправления ошибок в Firefox 155 устранено 109[уязвимостей](https://www.mozilla.org/en-US/security/advisories/mfsa2026-82/), большинство из которых вызваны проблемами при работе с памятью, такими как переполнения буферов и обращение к уже освобождённым областям памяти. Потенциально данные проблемы способны привести к выполнению кода злоумышленника при открытии специально оформленных страниц.
