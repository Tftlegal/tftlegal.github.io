# Выпуск пакета тестирования производительности ChimbaBenchCL 1.2, использующего OpenCL

## Краткое содержание

Вышел новый выпуск кроссплатформенного бенчмарка ChimbaBenchCL 1.2, предназначенного для оценки производительности видеокарт и процессоров. Тестирование осуществляется с использованием API OpenCL. Проект написан на языке C при участии искусственного интеллекта и распространяется под свободной лицензией MIT. Для 64-битных систем (x86_64) доступны готовые исполняемые файлы под Linux (Glibc 2.7+), FreeBSD и Windows 7+. 32-битная версия (x86) поддерживается на Windows XP+ и Linux с Glibc 2.7+. Таким образом, бенчмарк охватывает широкий спектр операционных систем и архитектур.
