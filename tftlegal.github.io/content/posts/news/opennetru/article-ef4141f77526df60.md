# Проект LiberNT развивает форк ReactOS, нацеленный на совместимость с Windows 11

## Краткое содержание

В рамках проекта LiberNT создан форк операционной системы ReactOS, ориентированный на совместимость с приложениями и драйверами для Windows 11 24H2. Форк также нацелен на стилизацию интерфейса в духе современных версий Windows и поддержку 64-разрядных архитектур: ARM64, PowerPC и RISC-V 64. Отличительной чертой проекта является активное применение AI-инструментов в процессе разработки. Собственные разработки LiberNT распространяются под лицензией GPLv3, тогда как заимствованный код ReactOS сохраняет лицензию GPLv2+. Основные загрузочные сборки доступны для платформ x86_64 и ARM64. Экспериментальные сборки публикуются для PowerPC и RISC-V 64, последняя из которых проверена на устройстве Banana Pi BPI-F3.

## Полная статья

В рамках проекта[LiberNT](https://libernt.com/)создан форк операционной системы[ReactOS](https://reactos.org/), нацеленный на достижение совместимости с приложениями и драйверами для Windows 11 24H2, стилизацию внешнего вида под современные Windows и поддержку 64-разрядных аппаратных платформ, включая системы на базе архитектур ARM64, PowerPC и RISC-V 64. Отличительной особенностью форка также является активное[использование](https://github.com/MjRi999/LiberNT/blob/main-nt10/AGENTS.md)AI-инструментов при разработке. Собственные наработки LiberNT[распространяются](https://github.com/MjRi999/LiberNT)под лицензией GPLv3, но код заимствованный из ReactOS продолжает поставляться под лицензией GPLv2+. Основные загрузочные сборки[сформированы](https://libernt.com/download/)для систем x86_64 и ARM64, дополнительно публикуются[экспериментальные сборки](https://github.com/LiberNT/LiberNT/releases/)для PowerPC и RISC-V 64 (Banana Pi BPI-F3).

Среди достижений проекта:

- [Реализация](https://libernt.com/hardware/)поддержки работы на ARM-платах Raspberry Pi 3 и Raspberry Pi 5, включая драйверы для GPU, звуковой подсистемы и сетевого адаптера.
- Задействование новой системы управления памятью NVS, по заявлению разработчиков работающий быстрее, чем вариант от ReactOS.
- Поддержка запуска Windows-приложений, собранных для архитектуры x86, на системах с архитектурой ARM64 (используется эмулятор[FEX](https://www.opennet.ru/opennews/art.shtml?num=63666)).
- Более современные графические драйверы, использующие архитектуру драйверов[WDDM](https://ru.wikipedia.org/wiki/Windows_Display_Driver_Model)и поддерживающие аппаратное ускорение для OpenGL. Новые драйверы пока доступны для плат Raspberry Pi 5 и 3, и находятся на стадии реализации для GPU Intel и AMD.
- Новый стек для систем хранения и USB, включая новые драйверы для устройств NVMe, USB 3.0, SD-карт, сетевых устройств и игровых контроллеров (поддерживаются PlayStation 5 DualSense, PlayStation 5 DualSense Edge и Xbox Series X|S). Новый драйвер для ФС NTFS.
