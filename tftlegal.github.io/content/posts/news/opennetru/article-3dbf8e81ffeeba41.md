# Проект GNOME представил предварительный выпуск GNOME OS для обычных пользователей

## Краткое содержание

Проект GNOME приступил к формированию сборок дистрибутива «GNOME OS Preview». Они основаны на последнем стабильном релизе GNOME 51.1. Цель выпуска — дать возможность обычным пользователям познакомиться с системой. До этого публиковались исключительно ночные сборки GNOME OS. Они строились по срезу кодовой базы, находящейся в разработке в Git. Такие сборки были ориентированы на разработчиков и тестировщиков проекта. Размер предлагаемого ISO-образа составляет 3,7 ГБ.

## Полная статья

Проект GNOME[начал формирование](https://blogs.gnome.org/adrianvovk/2026/10/16/gnome-os-preview/)сборок дистрибутива "[GNOME OS Preview](https://os.gnome.org/)", основанных на последнем стабильном релизе[GNOME 51.1](https://www.opennet.ru/opennews/art.shtml?num=66292)и предназначенных для ознакомления обычными пользователями. До этого публиковались только ночные сборки GNOME OS, основанные на срезе находящейся в разработке кодовой базы GNOME из Git и ориентированные на применение разработчиками и тестировщиками проекта. Размер предлагаемого для загрузки[iso-образа](https://os.gnome.org/download/stable/51/gnome_os_x86_64.iso)3.7 ГБ.

GNOME OS использует компонент[systemd-sysupdate](https://www.freedesktop.org/software/systemd/man/latest/systemd-sysupdate.html)для организации атомарного обновления системы и формат пакетов flatpak для установки дополнительных программ. Для установки задействован прототип инсталлятора. Из недавних улучшений в GNOME OS отмечены:

- Поддержка механизма zswap для сжатия памяти, претендующей на вытеснение в раздел подкачки, для повышения эффективности работы на системах с небольшим ОЗУ;
- Поставка приложения[Test Center](https://flathub.org/en/apps/cx.modal.TestCenter)для[упрощения](https://www.opennet.ru/opennews/art.shtml?num=65897)тестирования экспериментальных версий программ;
- Создание проекта[Toolpak](https://blogs.gnome.org/alatiera/2026/09/26/introducing-toolpak/)для установки независимых от дистрибутивов сборок консольных утилит (как Flatpak и Flathub, но для консольных программ).

Сборка GNOME OS Preview пока позиционируется как экспериментальная и будет объявлена стабильной после реализации недоделанных возможностей и поддержки механизмов подготовки, доставки и установки обновлений для поддержания системы в актуальном состоянии. Среди планов на будущее:

- Доработка инсталлятора до полнофункционального состояния;
- Поддержка дельта-обновлений в systemd-sysupdate для загрузки при обновлении только изменений, а не всего образа;
- Интеграция[systemd-homed](https://www.opennet.ru/opennews/art.shtml?num=51532)для организации работы с шифрованными переносимыми домашними каталогами;
- Улучшение поддержки устройств на базе архитектуры ARM;
- Более тесная интеграция с TPM и графический интерфейс для восстановления ключей;
- Поставка предустановленных программ в формате Flatpak;
- [Создание](https://www.opennet.ru/opennews/art.shtml?num=66157)новых порталов и возможностей Flatpak, например, для поставки VPN-приложений.
