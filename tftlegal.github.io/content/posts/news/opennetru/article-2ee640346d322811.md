# Выпуск инсталлятора Archinstall 4.5, применяемого в дистрибутиве Arch Linux

## Краткое содержание

Вышел инсталлятор Archinstall версии 4.5.
С 2021 года он опционально входит в установочные ISO-образы Arch Linux.
Программа работает в консольном режиме.
Её можно использовать вместо стандартной ручной установки дистрибутива.
Код написан на Python и распространяется под лицензией GPLv3.

## Полная статья

[Опубликован](https://github.com/archlinux/archinstall/releases/tag/4.5)выпуск инсталлятора[Archinstall 4.5](https://archinstall.archlinux.page/), который с 2021 года в качестве опции входит в состав установочных iso-образов Arch Linux. Archinstall работает в консольном режиме и может использоваться вместо предлагаемого по умолчанию ручного режима установки дистрибутива. Код Archinstall написан на языке Python и[распространяется](https://github.com/archlinux/archinstall)под лицензией GPLv3.

Archinstall предоставляет диалоговый ([guided](https://github.com/archlinux/archinstall/blob/master/docs/installing/guided.rst)) и[автоматизированный](https://github.com/archlinux/archinstall/blob/master/examples/minimal_installation.py)режимы работы. В автоматизированном режиме имеется возможность использования скриптов для развёртывания типовых конфигураций. Инсталлятор также поддерживает[профили установки](https://github.com/archlinux/archinstall/tree/master/archinstall/default_profiles), например, профиль "desktop" для выбора рабочего стола (KDE, GNOME, Awesome) и установки необходимых для его работы пакетов, или профили "webserver" и "database" для выбора и установки начинки web-серверов и СУБД. Шесть лет назад была предпринята попытка[создания](https://github.com/Torxed/archinstall_gui)варианта Archinstall с графическим интерфейсом установки, но она не получила развития.

![](/news/opennetru/article-2ee640346d322811/image-01.png)

В новой версии:

- Добавлена поддержка установки на системы с архитектурой aarch64 с использованием загрузчиков GRUB и Limine EFI.
- Добавлена поддержка использования таблицы разделов GUID для корневого радела на системах с архитектурой AArch64.
- Предоставлена возможность установки[realtime-сборок](https://wiki.archlinux.org/title/Realtime_kernel)ядра Linux.
- Для конфигураций с композитными серверами hyprland, labwc, niri и sway вместо polkit задействован systemd-logind.
- Добавлен новый абстрактный класс SubConfig для хранения дополнительных настроек и метод "summary" для генерации сводной информации о настройках.
- Добавлена возможность выбора опциональных вариантов пакета linux-firmware с прошивками.
