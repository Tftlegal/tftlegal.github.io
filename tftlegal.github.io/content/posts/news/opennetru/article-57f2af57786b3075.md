# Дистрибутив Peppermint OS переходит с X.Org Server на XLibre

## Краткое содержание

Разработчики Linux-дистрибутива Peppermint OS объявили о переходе на XLibre. XLibre является форком сервера X.Org. Дистрибутив построен на базе Debian и использует окружение Xfce с файловым менеджером Thunar. XLibre станет сервером по умолчанию в Peppermint OS. Он будет включен в следующую версию ISO-образов. До официального выхода доступны экспериментальные сборки для тестирования.

## Полная статья

Разработчики Linux-дистрибутива[Peppermint OS](https://peppermintos.com/), построенного на пакетной базе Debian GNU/Linux и предлагающего пользовательское окружение на основе рабочего стола Xfce и файлового менеджера Thunar,[анонсировали](https://peppermintos.com/2026/09/testing-updated-pepdebian-build-and-shift-to-xlibre/)переход на использование по умолчанию[XLibre](https://www.opennet.ru/opennews/art.shtml?num=65737), форка X.Org Server. XLibre будет задействован в следующем обновлении iso-образов PeppermintOS, до публикации которых для тестирования предложены[экспериментальные сборки](https://nightly.peppermintos.org/deb64/flagship/).

В обозримом будущем Peppermint OS планирует оставаться на стеке X11, так как в среде рабочего стола Xfce намерены продолжать полноценную поддержку X11. По мнению разработчиков Peppermint OS, проект XLibre отлично подходит для пользователей, предпочитающих использовать X11 вместо Wayland, так как в нём продолжена работа по исправлению ошибок, сопровождению, чистке и модернизации оригинальной кодовой базы X.Org Server.
