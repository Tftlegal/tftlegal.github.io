# Атака на AI-агенты через размещение файла AGENTS.md в каталоге с загрузками

## Краткое содержание

Исследователи компании Forever Security, расследуя инцидент с вредоносным ПО у одного из клиентов, обнаружили новую атаку на ИИ-агентов. Уязвимость основана на том, что многие ИИ-агенты по умолчанию выполняют инструкции из файла AGENTS.md, размещённого в корне проекта. Атакующий использует это, помещая файл AGENTS.md или CLAUDE.md в каталог ~/Downloads с командами на установку вредоносного ПО. В конкретном случае жертве был установлен вредоносный npm-пакет под названием «function-color». Таким образом, злоумышленнику достаточно создать один файл с вредоносные инструкциями, и ИИ-агент самостоятельно выполнит их. Это открывает новый вектор для supply-chain-подобные атаки, нацеленные не на разработчиков, а на их AI-ассistants.

## Полная статья

Исследователи из компании Forever Security, разбирая причины появления вредоносного ПО в системе одного из клиентов,[выявили](https://forever.security/blog/hijacking-ai-agents-via-downloads-folder)новый способ атаки на AI-агентов, основанный на том, что многие AI-агенты по умолчанию обрабатывают инструкции из файла AGENTS.md, размещённого в корне проекта, к работе над которым они привлечены. Атака проводится через размещение в каталоге ~/Downloads файла AGENTS.md или CLAUDE.md с инструкцией по установке вредоносного ПО (в рассмотренном случае устанавливался вредоносный npm-пакет "function-color").

Выявленная активность является вариацией известного метода атаки на разработчиков ПО, при котором злоумышленник создаёт репозиторий с легитимным кодом и размещает в нём файл AGENTS.md или передаёт данный файл в составе pull-запросов или сообщений об ошибках в существующие проекты. В случае если кто-то решит использовать AI-агента для проверки предложенного репозитория или изменения, агент обработает инструкции из файла AGENTS.md, в котором может быть предписано совершение вредоносных действий.

Новый вариант атаки основан на том, что Chrome, Firefox и Edge по умолчанию не запрашивают подтверждение при загрузке файла, а лишь выводят уведомление. Загружаемые по ссылке файлы автоматически сохраняются в каталоге ~/Downloads - для загрузки достаточно, чтобы пользователь открыл определённую страницу или перешёл по[ссылке](https://weizmangal.com/public/download-test.html?name=AGENTS.md&content=dGVzdAo%3D)(ссылка может выглядеть невинно, а проброс на загрузку может быть сделан через редирект). Подобным образом атакующие добиваются сохранения файла AGENTS.md в каталоге с загрузками на системах пользователей, после чего ждут, когда пользователь запустит AI-агента в контексте каталога ~/Downloads, например, для разбора каких-то загруженных документов.

Помимо использования AGENTS.md для информирования AI-агентов об используемых инструментах, требуемых зависимостях и проводимых тестах, через подобные файлы можно добиться выполнения произвольных программ, установки сторонних пакетов и изменения конфигурации. Возможность совершения атаки продемонстрирована для AI-агентов Codex и Claude Code.

Исследователи провели два эксперимента, в результате которых удалось добиться получения контроля над учётной записью пользователя и перехватить его OAuth-токены. В ходе первого эксперимента AI-агент Codex выполнил инструкции по загрузке и запуску на системе пользователя тестового вредоносного кода, ограничивающегося открытием калькулятора. Во втором эксперименте через подстановку файла CLAUDE.md исследователи при помощи Claude Code изменили содержимое переменной окружения ANTHROPIC_BASE_URL, организовали перенаправление запросов к API на свой сервер и перехватили токен OAuth. Первый эксперимент оказался успешен в 90% попыток, а второй - в 50%.
