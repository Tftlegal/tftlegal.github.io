# Релиз видеоредактора OpenShot 4.1

## Краткое содержание

Выпущена версия 4.1 бесплатной системы нелинейного видеомонтажа OpenShot. Исходный код проекта распространяется под лицензией GPLv3. Пользовательский интерфейс написан на Python с использованием библиотеки Qt, а ядра обработки видео (libopenshot) и звука (libopenshot-audio) реализованы на C++ с задействованием пакета FFmpeg. Готовые сборки доступны для Linux (в формате AppImage), Windows и macOS. Параллельно были опубликованы обновления базовых библиотек: libopenshot 1.1 и libopenshot-audio 1.0.2.

## Полная статья

[Представлен](https://www.openshot.org/blog/2026/10/25/openshot-41-direct-text-editing-auto-optimize-command-line-editing/)выпуск свободной системы нелинейного видеомонтажа[OpenShot 4.1](https://www.openshot.org). Код проекта поставляется под лицензией GPLv3: интерфейс[реализован](https://github.com/OpenShot/openshot-qt/)на языке Python и библиотеке Qt, а ядра обработки видео ([libopenshot](https://github.com/OpenShot/libopenshot)) и звука ([libopenshot-audio](https://github.com/OpenShot/libopenshot-audio)) написаны на C++ и используют возможности пакета FFmpeg. Готовые сборки[подготовлены](https://www.openshot.org/download/)для Linux (AppImage), Windows и macOS. Одновременно опубликования версии базовых библиотек[libopenshot 1.1](https://github.com/OpenShot/libopenshot/releases/tag/v1.1.0)и[libopenshot-audio 1.0.2](https://github.com/OpenShot/libopenshot-audio/releases/tag/v1.0.2).

Видеоредактор предоставляет простой пользовательский интерфейс, позволяющий редактировать видео даже начинающим пользователям. Программа поддерживает несколько десятков визуальных эффектов, даёт возможность работы с многотрековыми монтажными шкалами с возможностью перемещения мышью элементов между ними, позволяет масштабировать, кадрировать, выполнять слияние блоков видео, обеспечивать плавное перетекание из одного ролика в другой, производить наложение полупрозрачных областей. Имеется возможность перекодирования видео с предварительным просмотром изменений на лету. Благодаря задействованию библиотек проекта FFmpeg OpenShot поддерживает большое число форматов видео, звука и изображений, включая полную поддержку SVG.

Основные[изменения](https://github.com/OpenShot/openshot-qt/releases/tag/v4.1.0):

- Добавлен новый интерфейс командной строки для автоматизации процесса редактирования видео, который может использоваться для привлечения к работе над видео AI-агентов, таких как Claude Code и Codex, а также автоматизации рутинных задач и выполнения операций экспорта в пакетном режиме из скриптов. Возможно выполнение команд как в фоне, так и с отображением действий в графическом интерфейсе.
- Добавлена встроенная возможность редактирования и размещения текста поверх видео, без запуска внешних редакторов. Реализована плавающая панель для изменения стиля текста с предпросмотром результата изменения настроек, возможностью копирования стилей между клипами и поддержкой анимированного изменения оформления текста в привязке к ключевым кадрам. Обеспечено сохранение чёткости текста при масштабировании.[

![](/news/opennetru/article-b13f3e28f5dcf896/image-01.png)

](https://www.openshot.org/images/uploads/zinnia/2026/10/25/openshot-4-1/quick-text-style-bar.webp)
- Добавлен режим автоматической оптимизации, при которой для ускорения декодирования, препросмотра и навигации по потоку создаются уменьшенные (по умолчанию 720p) варианты видео, изначально поставляемого в высоком разрешением. При экспорте используются оригинальные файлы без потери качества.[

![](/news/opennetru/article-b13f3e28f5dcf896/image-02.jpeg)

](https://www.openshot.org/images/uploads/zinnia/2026/10/25/openshot-4-1/auto-optimize.webp)
- Реализована фоновая проверка настроек экспорта через FFmpeg, выполняемая по мере изменения настроек, не дожидаясь запуска экспорта. Проблемные поля сразу выделяются красным цветом и снабжаются рекомендацией по устранению проблемы. После выполнения экспорта настройки сохраняются и остаются редактируемыми, что позволяет исправить недочёты по горячим следам и повторить операцию экспорта. Добавлена новая вкладка с информацией о результатах экспорта.
- Расширены возможности для навигация по файлам в проекте, работы с эффектами, перемещения клипов, помещения элементов на временную шкалу и выбора Emoji с использованием только клавиатуры, без мыши.
- Изменено оформление окна предпросмотра, которое теперь унифицировано и применяется для файлов и клипов, а также в режиме Split File. Реализован автоматический запуск воспроизведения при переходе к предпросмотру и добавлена наглядная навигация по кадрам.[

![](/news/opennetru/article-b13f3e28f5dcf896/image-03.jpeg)

](https://www.openshot.org/images/uploads/zinnia/2026/10/25/openshot-4-1/split-file.webp)
- Добавлен режим "Auto Keyframes", обеспечивающий автоматическую запись ключевых кадров для анимации. Для создания ключевого кадра в указанной позиции теперь достаточно переместить ползунок на временной шкале и изменить любое свойство клипа.
- Убраны задержки и исключена рассинхронизация при изменении масштаба на временной шкале. Добавлена возможность настройки размера дорожек для регулирования их количества на экране. Улучшена визуальная обратная связь при наведении указателя и перетаскивании элементов. Обновлены темы оформления Retro и Humanity Dark.
- Ускорено выполнение операций на временной шкале, таких как перемещение, обрезка, разделение и запуск предпросмотра.
- Размер файлов проекта сокращён за счёт выноса данных для визуализации звука (waveform) в отдельные сжатые файлы и использования формата PNG для сжатия сохранённых кадров без потерь.
- Обеспечено корректное выставление громкости для дорожек с моно-звуком, которые раньше могли звучать тише, чем стерео. Повышено качество записи звука с моно-микрофонов. Исправлена проблема c искажением звука при одновременном воспроизведении нескольких клипов.
- Реализована поддержка архитектуры ARM64 для Linux.
