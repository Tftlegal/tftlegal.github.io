# Альфа-версия CusDeb OS, Windows-подобной ОС на базе Linux и пользовательского окружения ReactOS

## Краткое содержание

Спустя полгода после публикации прототипа C:\\Deb была выпущена первая альфа-версия проекта под новым названием CusDeb OS. Прототип представлял собой обычное Linux-окружение, стилизованное под Windows 95/98 с помощью PCManFM, LXPanel и аналогичных компонентов. В отличие от него, CusDeb OS Alpha 1 предлагает полноценное классическое Win32-окружение. Оно построено на пользовательских компонентах ReactOS, работающих через Wine. Пользовательское окружение проекта получило название CDEX (CusDeb Desktop Environment X). CDEX представляет собой редакцию оболочки ReactOS, адаптированную для работы без ядра самой операционной системы ReactOS.

## Полная статья

Через полгода после[публикации](https://www.opennet.ru/opennews/art.shtml?num=65333)прототипа Windows-подобной операционной системы C:\\Deb[сформирована](https://github.com/cusdeb-com/os/releases/tag/main-8b35988)первая альфа-версия проекта, получившего новое название -[CusDeb OS](https://cusdeb.com/os). В отличие от прототипа, который представлял собой обычное Linux-окружение, стилизованное под Windows 95/98 с использованием PCManFM, LXPanel и других компонентов, CusDeb OS Alpha 1 предлагает полноценное классическое Win32-окружение, основанное на пользовательских компонентах ReactOS, работающих через Wine. Пользовательское окружение развивается как часть CusDeb OS под именем CDEX (CusDeb Desktop Environment X) и представляет собой редакцию оболочки ReactOS, адаптированную для работы без ядра данной операционной системы.

На текущем этапе CDEX содержит лишь минимальные изменения, направленные на устранение различных шероховатостей в работе Win32-окружения под Linux. В дальнейшем разработчики планируют развивать его дальше, добавляя возможности, которые пока не реализованы в ReactOS. Как и в случае с прототипом, основой системы остаётся Debian 13. Для загрузки[предлагается](https://github.com/cusdeb-com/os/releases)(894 MB) live-система, которую можно запустить в виртуальной машине или на реальном компьютере.

Разработчики CusDeb OS поставили перед собой цель - за год довести систему до состояния, в котором она могла бы стать полноценной альтернативой Windows 10. Автором проекта является[Евгений Голышев](https://qa.debian.org/developer.php?login=eugulixes%40gmail.com), сопровождающий пакет Elixir в Debian.

Среди основных целей для второй альфа-версии:

- Переход на 64-битную версию CDEX (сейчас в Alpha 1 используется 32-битная версия CDEX в 64-битной Linux-системе).
- Поддержка Direct3D 3-11 через[D7VK](https://www.opennet.ru/opennews/art.shtml?num=64414)и[DXVK](https://www.opennet.ru/opennews/art.shtml?num=65775).
- Миграция графического окружения с Xorg на Wayland.
