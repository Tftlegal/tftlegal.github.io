# Атакующие смогли внедрить вредоносный код в официальное дополнение Claude Code к VS Code

## Краткое содержание

Была зафиксирована компрометация официального дополнения Claude Code для VS Code, разработанного компанией Anthropic и насчитывающего 63 млн загрузок. Злоумышленники опубликовали в репозитории Open-VSX вредоносную версию пакета (anthropic.claude-code@2.1.313), содержащая код для удалённого access к системе пользователя. Аналогичный предупреждающий отчёт был сформирован и для репозитория Microsoft, хотя фактическое размещение вредоносного релиза там не подтверждено. На данный момент проблемная версия удалена из Open-VSX, а за ней последовал корректирующий релиз 2.1.314. Инцидент затрагивает пользователей, установившие именно скомпрометированную версию.

## Полная статья

[Зафиксирована](https://opensourcemalware.com/blog/trojanized-claude-code-extension-plants-persistent-ssh-backdoor)компрометация официального дополнения[Claude Code для VS Code](https://open-vsx.org/extension/Anthropic/claude-code), поставляемого компанией Anthropic и насчитывающего 63 млн загрузок. Атакующим удалось разместить в каталоге[Open-VSX](https://open-vsx.org/)релиз[anthropic.claude-code@2.1.313](https://open-vsx.org/extension/Anthropic/claude-code), содержащий вредоносный код для удалённого доступа к системе пользователя. Публикация вредоносной версии пакета в[репозитории Microsoft](https://marketplace.visualstudio.com/items?itemName=anthropic.claude-code)не подтверждена, но для него тоже сформирован[отчёт](https://opensourcemalware.com/vscode/anthropic.claude-code)c с предупреждением. В настоящее время проблемная версия удалена из репозитория Open-VSX и следом опубликован корректирующий релиз 2.1.314.

Код для загрузки вредоносных компонентов был добавлен в начало файла extension.js и активировался при инициализации дополнения после запуска VS Code (для активации вредоносного кода взаимодействие пользователя с Claude не требовалось). Вредоносная активность сводилась к созданию директории ~/.ssh и добавлению в файл ~/.ssh/authorized_keys открытого ключа ssh-ed25519 c примечанием "svc-telemetry". После этого осуществлялась проверка наличия фонового процесса sshd в Linux и macOS, и активация SSH-сервера в случае его отсутствия. В Windows через PowerShell выполнялась установка OpenSSH.

Далее вредоносный код сохранял закрытый ключ во временный файл с именем ".stk_*" и настраивал обратный туннель с внешним SSH-сервером 134.209.82.225 для удалённого доступа, запуская ssh с опциями "-N -R '*:0:localhost:22'". Соединение обновлялось каждые 60 секунд. Скрипты для обновления туннеля и отправки данных на внешние серверы сохранялись в файлах ~/.config/.smt и ~/.config/.smtk. Периодический запуск в Linux настраивался через cron, в macOS через LaunchAgent (com.apple.sysmond.plist), а в Windows через SysMon и автозапуск.

Помимо этого в системе собирались сведения об имени хоста, зарегистрированных пользователях, операционной системе, домашнем каталоге, email (через git config --global user.email) и переменных окружения c именами, содержащими слова KEY, TOKEN, SECRET, PASS, AWS и GCP. Найденные данные отправлялись в формате JSON по URL http://134.209.82.225:8099/beacon.

Пользователям дополнения Claude Code к VS Code рекомендуется проверить свои системы на предмет установки вредоносной версии 2.1.313. Индикаторами компрометации системы является появление файлов ~/.config/.smt, ~/.config/.smtk, ~/Library/LaunchAgents/com.apple.sysmond.plist, ${TMPDIR}/.stk_*, ~/.config/smt.cmd, ~/.config/smtk, SysMon и sysmon.cmd, а также обращение по портам 22 и 8099 к IP-адресу 134.209.82.225, и отправка HTTP/HTTPS-запросов к хостам ifconfig.me и api.ipify.org.

Как именно злоумышленники добились подстановки вредоносного кода в дополнение пока не ясно, предполагается, что могла быть взломана учётная запись сотрудника Anthropic, занимающегося сопровождением пакета, или была использована проблема с безопасностью в системе публикации релизов.
