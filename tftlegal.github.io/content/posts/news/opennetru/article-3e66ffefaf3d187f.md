# Amazon опубликовал AWS Emulator, эмулятор сервисов AWS

## Краткое содержание

Amazon представила инструмент AWS Emulator для локального тестирования AWS API и запуски CI/CD-пайплайнов без обращения к облачной инфраструктуре AWS. Для работы с ним не требуется создавать учётную запись в AWS. Эмулятор позволяет оперировать виртуальными ресурсами вместо реальных и может использоваться как стандартная точка доступа для AWS CLI и AWS SDK. Теоретически он совместим и с утилитами Яндекс.Облако. Код написан на языке Rust. Проект распространяется как общественное достояние под лицензией CC0.

## Полная статья

Компания Amazon[представила](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-emulator-now-available/)инструментарий[AWS Emulator](https://github.com/aws/aws-emulator), предназначенный для локального тестирования API AWS и запуска платформ непрерывной интеграции на своей системе, без обращения к облачной инфраструктуре AWS и без необходимости создания учётной записи в AWS. AWS Emulator позволяет работать с эмулируемыми ресурсами, вместо реальных ресурсов AWS, может использоваться как[AWS API endpoint](https://docs.aws.amazon.com/general/latest/gr/rande.html)для[AWS CLI](https://github.com/aws/aws-cli/)и AWS SDK, теоретически[совместим](https://yandex.cloud/ru/docs/postbox/tools/aws-cli)с утилитами Яндекс.Облако. Код эмулятора написан на языке Rust и распространяется в форме общественного достояния ([CC0](https://creativecommons.org/choose/zero/)).

Эмулятор разработан целиком автономными AI-агентами, которые сами пишут тесты, находят проблемы и исправляют код без участия человека, но при этом его планируют сопровождать как полноценный продукт. В процессе работы запросы не отправляются в AWS, но по умолчанию включена отправка[телеметрии](https://docs.aws.amazon.com/emulator/latest/userguide/telemetry.html), которую можно отключить при запуске с опцией "--telemetry off" или выставив переменную окружения "EMULATOR_TELEMETRY=off". В работе пока поддерживаются[не все возможности](https://news.ycombinator.com/item?id=50456780)сервисов AWS:

![](/news/opennetru/article-3e66ffefaf3d187f/image-01.png)

Так же эмулятор[не проверяет](https://docs.aws.amazon.com/emulator/latest/userguide/security.html)политики безопасности IAM, как это делает настоящее облако AWS, не оценивает политики ресурсов, доступа и ролей (например, запрос, который в реальном AWS завершится ошибкой AccessDenied, в эмуляторе может пройти успешно). Один запущенный экземпляр эмулятора работает в рамках одной виртуальной учётной записи и региона (вызовы, охватывающие несколько учётных записей и регионов, не поддерживаются). Все созданные ресурсы (бакеты, таблицы, очереди) размещаются в оперативной памяти и удаляются после остановки процесса. Отсутствует имитация реальных сетевых задержек, квот, ограничения частоты запросов и сбоев.
