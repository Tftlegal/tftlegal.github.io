# Выпуск видеоредактора Shotcut 26.9

## Краткое содержание

Вышел релиз видеоредактора Shotcut 26.9, который разрабатывается автором фреймворка MLT и использует его для работы с видео.
Поддержка видео- и аудиоформатов обеспечивается через FFmpeg, а дополнительные эффекты можно подключать с помощью плагинов Frei0r и LADSPA.
Shotcut позволяет выполнять многотрековую сборку видео из фрагментов в разных форматах без предварительного импорта или перекодирования.
В редакторе также есть встроенные средства для записи скринкастов, обработки изображения с веб-камеры и приёма потокового видео.
Программа написана на C++ с использованием Qt, распространяется под лицензией GPLv3 и доступна для Linux, macOS и Windows.
