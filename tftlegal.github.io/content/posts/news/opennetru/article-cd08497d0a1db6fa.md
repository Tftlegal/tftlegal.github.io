# Доступен сервер совместной работы Stalwart 1.2, способный заменить Microsoft Exchange

## Краткое содержание

Вышел релиз платформы Stalwart версии 1.2. Она объединяет функции совместной работы с документами, ведения заметок, планирования событий, адресной книги и электронной почты. Ключевое новинка — поддержка протоколов MAPI over HTTP, EWS, Exchange ActiveSync и Autodiscover. Благодаря этому Stalwart может служить полноценной заменой сервера Microsoft Exchange. Платформа совместима с классическим Outlook и Apple Mail. Проект написан на языке Rust. Распространяется под лицензией AGPLv3.0.

## Полная статья

[Представлен](https://stalw.art/blog/microsoft-exchange-replacement/)релиз платформы[Stalwart 1.2](https://stalw.art/), предоставляющий возможности для совместной работы с документами, ведения заметок, планирования событий, поддержания адресной книги и переписки по электронной почте. Новый выпуск примечателен реализацией поддержки протоколов MAPI over HTTP, EWS (Exchange Web Services), Exchange ActiveSync и Autodiscover, позволяющих использовать Stalwart в качестве замены сервера Microsoft Exchange, совместимой с классическим Outlook и Apple Mail. Код проекта написан на языке Rust и[распространяется](https://github.com/stalwartlabs/stalwart)под лицензией AGPLv3.0.

Среди возможностей Stalwart:

- Почтовый сервер с поддержкой протоколов JMAP, IMAP, POP3, SMTP и расширений DMARC, DKIMv2, DANE, MTA-STS и SMTP TLS;
- Сервер совместной работы, поддерживающий CalDAV, CalDAV и расширения JMAP для календарей, контактов и хранения файлов;
- Средства фильтрации спама и фишинга. Классификаторы спама на основе AI и статистических методов. Поддержка серых списков и DNSBL.
- бэкенды для хранения данных в RocksDB, FoundationDB, PostgreSQL, mySQL, SQLite, S3-хранилищах, Azure и Redis;
- Бэкенды для полнотекстового поиска на базе Meilisearch, ElasticSearch, OpenSearch, PostgreSQL и MySQL;
- Возможности для разбора и индексации форматов PDF, Microsoft Office, OpenDocument, EPUB и RTF;
- Поддержка OpenPGP и S/MIME; скриптинг на языке Sieve;
- Поддержка[мультиарендности](https://ru.wikipedia.org/wiki/%D0%9C%D1%83%D0%BB%D1%8C%D1%82%D0%B8%D0%B0%D1%80%D0%B5%D0%BD%D0%B4%D0%BD%D0%BE%D1%81%D1%82%D1%8C)(multi-tenancy), позволяющей одному экземпляру Stalwart обслуживать несколько изолированных окружений со своими доменами и пользователями;
- Дисковые квоты в привязке к пользователям и окружениям. Ограничение интенсивности запросов (rate limit);
- Автоматическое получение TLS-сертификатов с использованием протокола ACME;
- Средства для аудита. Сохранение метрик и интеграция с OpenTelemetry и Prometheus;
- Поддержка аутентификации через OpenID Connect, OAuth 2.0, бэкенды LDAP, OIDC и SQL. Возможность использования двухфакторной аутентификации и биометрической аутентификации (WebAuthn). Разделение доступа на основе прав доступа, ролей и ACL;
- Возможность создания отказоустойчивых и кластерных конфигураций для высоконагруженных систем. Поддержка масштабирования с развёртыванием новых экземпляров в контейнерах и виртуальных машинах, используя Kubernetes, Apache Mesos и Docker Swarm;
- Web-интерфейс администратора с возможностями для отслеживания состояния в режиме реального времени, управления учётными записями, доменами, списками рассылки и очередями отправляемых сообщений, настройки параметров почтового сервера и анализа логов.

Предполагается, что переход на Stalwart позволит компаниям, использующим Microsoft Exchange на своих серверах, избежать привязки к облачным сервисам Exchange Online, навязываемым Microsoft. Поддержка Exchange 2016 и 2019 уже полностью прекращена Microsoft, развитие функциональности Exchange Server Subscription Edition заморожено, а новый Outlook прекратил поддержку локальных учётных записей Exchange. В Stalwart 1.2 предоставлена близкая к Microsoft Exchange функциональность и имеются инструменты для прозрачной миграции существующих клиентов Microsoft Exchange, что позволяет сохранить полный локальный контроль над данными и начать постепенного переводить клиентов на открытые стандарты, такие как JMAP, по мере устаревания классического Outlook.

При развёртывании сервера Stalwart доступны инструменты для переноса почтовых ящиков, календарей и контактов как из локального сервера Exchange, так и из облака Microsoft 365. Компоненты для поддержки протоколов Microsoft Exchange вынесены в отдельный модуль, который активируется лишь при необходимости (по умолчанию предлагается использовать стек протоколов IMAP, JMAP, WebDAV, CalDAV и CardDAV).

Среди других новшеств Stalwart 1.2.0:

- Выполняемые на сервере правила обработки сообщений, настраиваемые через web-интерфейс, JMAP или Outlook, и компилируемые в представление на языке[Sieve](https://ru.wikipedia.org/wiki/Sieve).
- Поддержка уведомлений о прочтении писем (MDN, Message Disposition Notifications,[RFC 8098](https://www.rfc-editor.org/rfc/rfc8098)).
- Возможность настройки рабочего времени, влияющего на выставление статуса свободен/занят.
- Поддержка создания учётных записей[ресурсов](https://stalw.art/docs/collaboration/resources/), таких как проекторы и переговорные комнаты, для координации доступа к ним и оценки из свободности.
- Вместо библиотеки libfdb_c задействован новый клиент к FoundationDB, написанный на Rust и работающий асинхронно. В проведённых тестах новый клиент продемонстрировал увеличение пропускной способности в 4.5-6.9 раз, снижение задержек в 5-7 раз и снижение нагрузки на CPU примерно наполовину.
- Предложена новая интерактивная консоль Stalwart CLI 2.0 на базе библиотеки[Ratatui](https://ratatui.rs/), позволяющая администрировать сервер Stalwart при входе через SSH.
