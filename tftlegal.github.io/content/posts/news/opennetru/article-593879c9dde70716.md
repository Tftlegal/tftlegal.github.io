# Выпуск FUSE-модуля BTFS 3.3 для монтирования torrent-файлов как ФС

## Краткое содержание

BTFS 3.3 позволяет монтировать torrent-файлы и magnet-ссылки в виде файловой системы.  
Содержимое открывается как обычная директория, но доступна только для чтения.  
Данные подгружаются динамически по мере обращения к ним.  
Например, можно слушать музыкальный альбом из torrent без предварительной полной загрузки.  
Модуль написан на C++ и распространяется под лицензией GPLv3.
