# Обновление редактора кода CudaText 1.236.0

## Краткое содержание

Вышел редактор кода CudaText версии 1.236.0. Он кроссплатформенный и свободный, написан на Free Pascal и Lazarus. Поддерживает расширения на Python и имеет преимущества перед Sublime Text. Встроены функции IDE в виде плагинов, а для программистов доступно более 300 синтаксических лексеров. Код распространяется под лицензией MPL 2.0. Доступны сборки для Linux, Windows, macOS, FreeBSD, OpenBSD, NetBSD, DragonflyBSD, Solaris и Haiku.
