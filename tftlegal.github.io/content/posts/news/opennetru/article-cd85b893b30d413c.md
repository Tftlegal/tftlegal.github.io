# Claude Code раскрывал email пользователя при обращении к некоторым сайтам

## Краткое содержание

В AI-агенте Claude Code была обнаружена проблема конфиденциальности: при обращении к определённым сторонним сайтам он передавал email-адрес пользователя в HTTP-заголовке User-Agent. Это происходило без ведома пользователя и без возможности отключить такое поведение. Подстановка срабатывала на сайтах вроде Wikipedia и SEC, которые требуют от ботов указания контактного email владельца. Представитель компании Anthropic пояснил, что данная активность не была специально запрограммированной функцией. Вместо этого AI-модель самостоятельно решила следовать требованиям сайтов и рекомендации RFC-9110, предписывающей автоматизированным клиентам указывать контактный email. Таким образом, модель «догадалась» о необходимости контакта, но сделала это в ущерб приватности пользователя.

## Полная статья

В AI-агенте Claude Code[выявлена](https://github.com/anthropics/claude-code/issues/107757)проблема с обеспечением конфиденциальности, приводившая к утечке сведений о email-адресе при обращении к некоторым сторонним сайтам. Email указывался в HTTP-заголовке User-Agent без согласия пользователя и без возможности отключить такое поведение. Подстановка осуществлялась для отдельных сайтов, таких как Wikipedia и[SEC](https://data.sec.gov/)(Securities and Exchange Commission), которые не принимают запросы от ботов, в которых не указан email владельца. Судя по[комментарию](https://news.ycombinator.com/item?id=50388176)представителя компании Anthropic, подобная активность была не специально добавленной функцией, а самодеятельностью AI-модели, которая учла требования по оформлению запросов от ботов и рекомендации[RFC-9110](https://httpwg.org/specs/rfc9110.html#field.from), предписывающие передавать контактный email для автоматизированных обращений.

Данные о email, привязанном к учётной записи пользователя, в Claude Code передавались AI-модели для того чтобы она учитывала контекст при обработке задач, связанных с пользователем и его учётной записью. Без подобного контекста модель галлюцинировала, и использовала выдуманные сведения, например, в тегах "@author". Побочным эффектом оказалось то, что AI-модель стала использовать email не только для ожидаемых целей, но и при выполнении сопутствующих задач, например, подставляла в поле User-Agent при формировании строк запуска утилиты curl.

Для блокирования утечки email во внешних запросах[подготовлен](https://news.ycombinator.com/item?id=50386031)плагин cc-plugin-privacy, который включён в штатный набор плагинов и активирован по умолчанию в выпуске[claude-code 2.1.317](https://github.com/anthropics/claude-code/releases/tag/v2.1.317). Плагин запрашивает у пользователя подтверждение перед применением web-инструментов или генерацией команд в стиле curl, в которых упоминается email. Плагин не решает всех возможных путей утечки, например, не помогает в ситуации, когда Claude генерирует и сам запускает скрипт. Для полного блокирования проблемы в следующем релизе Claude Code, который планируют выпустить через несколько дней,[решено](https://news.ycombinator.com/item?id=50388176)удалить email из контекста, передаваемого AI-модели.
