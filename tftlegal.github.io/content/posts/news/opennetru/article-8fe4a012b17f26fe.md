# Выпуск VirtualBox 7.2.18

## Краткое содержание

Oracle выпустила корректирующий релиз системы виртуализации VirtualBox 7.2.18.
В нем внесено 11 изменений и устранено 19 уязвимостей.
Самая серьезная проблема, CVE-2026-87273, получила оценку опасности 8,6 из 10.
Еще пять уязвимостей имеют уровень 7,8 из 10, из них четыре специфичны для Windows.
Судя по этим оценкам, атаки могут позволить перехватить доступ к хост-окружению из гостевой системы.
Oracle не раскрыла детали о характере уязвимостей.
