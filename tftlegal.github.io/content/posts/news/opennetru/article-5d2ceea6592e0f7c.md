# Выпуск дистрибутива CachyOS 261122 с поддержкой Easy Anti Cheat 2

## Краткое содержание

Вышел новый выпуск дистрибутива CachyOS с номером 261122. Проект построен на пакетной базе Arch Linux и использует модель непрерывной доставки обновлений. CachyOS пользуется значительной популярностью среди любителей компьютерных игр. По данным сервиса ProtonDB, именно этот дистрибутив является самым востребованным среди геймеров, использующих Linux. Доля CachyOS в данном сегменте составляет 21,1%.

## Полная статья

[Представлен](https://cachyos.org/blog/2611-november-release/)выпуск дистрибутива[CachyOS 261122](https://cachyos.org), основанного на пакетной базе Arch Linux, применяющего непрерывную модель доставки обновлений и пользующегося популярностью у любителей компьютерных игр. По[данным](https://www.opennet.ru/opennews/art.shtml?num=65157)сервиса ProtonDB проект CachyOS является самым популярным дистрибутивом Linux (доля 21.1%), применяемым геймерами.

Дистрибутив примечателен включением оптимизаций для повышения производительности и предоставлением возможности установки различных сред рабочего стола. Помимо базового окружения на основе KDE, для установки[доступны](https://cachyos.org/download/)GNOME, Xfce, i3WM, Wayfire, LXQT, OpenBox, Cinnamon, Cosmic, Niri, MangoWM, LXDE, Mate, Budgie, Qtile, Hyprland и Sway. Размер установочного[iso-образа](https://sourceforge.net/projects/cachyos-arch/files/gui-installer/desktop/261122/)3.2 ГБ.[Сборки](https://sourceforge.net/projects/cachyos-arch/files/gui-installer/handheld/)для носимых устройств (Handheld Edition) с интерфейсом в стиле GameMode пока не обновлены.

В дистрибутиве по умолчанию включён планировщик задач[BORE](https://github.com/firelzrd/bore-scheduler), оптимизированный для снижения задержек на рабочем столе и повышения приоритета интерактивных процессов. Ядро и пакеты собраны с включением LTO-оптимизаций (Link-Time Optimization) и задействованием инструкций, доступных в процессорах на базе микроархитектур x86-64-v3, x86-64-v4 и Zen4. При сборке базовых пакетов дополнительно[включены](https://wiki.cachyos.org/cachyos_basic/why_cachyos/)оптимизации PGO (Profile-Guided Optimization) или[BOLT](https://github.com/facebookarchive/BOLT)(Binary Optimization and Layout Tool). В качестве файловых систем могут использоваться btrfs, zfs, ext4, xfs и f2fs.

Основные новшества:

- [Реализованы](https://wiki.cachyos.org/configuration/easy_anti_cheat/)возможности, необходимые для использования[Easy Anti Cheat 2](https://www.opennet.ru/opennews/art.shtml?num=66477)в Linux, такие как загрузка в режиме Secure Boot с ядром, подписанным одобренным компанией Epic Games ключом, активация IOMMU и TPM 2.0, включение в ядре режима[lockdown](https://www.opennet.ru/opennews/art.shtml?num=51591). Для работы Easy Anti Cheat 2 поставляется отдельный пакет с ядром linux-cachyos-eac, для которого создаётся отдельная кнопка в загрузочном меню, а также скрипт eac-setup для настройки необходимых загрузочных компонентов. Так как с ядром linux-cachyos-eac не работают модули[DKMS](https://wiki.archlinux.org/title/Dynamic_Kernel_Module_Support_(%D0%A0%D1%83%D1%81%D1%81%D0%BA%D0%B8%D0%B9))(Dynamic Kernel Module Support), модули nvidia-open, nvidia-580xx, ZFS и r8125 упакованы в отдельные пакеты linux-cachyos-eac-*.
- Полностью переделан графический интерфейс установки пакетов ([CachyOS Package Installer](https://github.com/CachyOS/packageinstaller)), в котором помимо установки пакетов из репозиториев CachyOS и Arch добавлена возможность сборки пакетов из AUR (с рецензированием изменений в установочных скриптах и PKGBUILD перед началом сборки), а также установки пакетов в форматах Flatpak и AppImages.[

- Добавлен новый системный образ[cachyos-recovery](https://github.com/CachyOS/cachyos-recovery)с окружением для восстановления после сбоев, загружаемый через загрузчик или напрямую из UEFI и позволяющий обойтись без загрузки с отдельного Live USB. После загрузки в cachyos-recovery через текстовое меню можно просматривать, тестировать (с поддержкой записи в ФС, которая обеспечивается через overlayfs) и откатывать снапшоты Btrfs для корневой ФС с перегенерацией файлов ядра, initramfs и настроек загрузчика. Образ занимает 70 МБ и устанавливается в UEFI командой "sudo pacman -S cachyos-recovery", а на системах с BIOS - "cachyos-recovery-legacy".
- Ядро Linux обновлено до ветки 7.3 (отдельно доступен пакет с LTS-ядром 6.18.64). Добавлена возможность использования компонентов ядра на языке Rust при сборке с оптимизацией[ThinLTO](https://clang.llvm.org/docs/ThinLTO.html). Включена реализация[IPC Binder](https://www.opennet.ru/opennews/art.shtml?num=64092)на Rust. Собран модуль applesmc (Apple System Management Controller) и добавлены готовые сборки модулей nvidia-580xx.
- Обновлены версии Mesa 26.3.1, драйверов NVIDIA 620.73.04, загрузчика Limine 12.10.0 и пакета запуска Windows-приложений proton-cachyos 11.0-20261015.
- Композитный сервер mutter собран с патчами для защиты от появления разрывов при выводе (tearing).
- Добавлены новые пакеты[bpftune-gaming](https://packages.cachyos.org/package/cachyos/x86_64/bpftune-gaming)(автонастройка параметров ядра для игр) и[pahole](https://packages.cachyos.org/package/cachyos/x86_64/pahole)(утилита для разбора отладочной информации), а также собственный вариант пакета[plymouth](https://packages.cachyos.org/package/cachyos/x86_64/plymouth)с загрузочной заставкой. Удалён пакет с редактором Void.
- Добавлен пакет[cachyos-drm-awaiter](https://github.com/CachyOS/CachyOS-PKGBUILDS/tree/master/cachyos-drm-awaiter), пришедший на смену KMS и nvidia-module-loader, который ожидает загрузки драйверов GPU перед запуском дисплейного менеджера, а в случае сбоя загрузки драйвера показывает QR-код.
- [Графический инсталлятор](https://github.com/CachyOS/cachyos-calamares)(Calamares) переведён на общую и с[текстовым инсталлятором](https://github.com/CachyOS/New-Cli-Installer)библиотеку gucc, которая используется как бэкенд для initramfs, machine-id и post-install. Корневой раздел по умолчанию теперь создаётся с типом SD_GPT_ROOT_X86_64. Добавлена опция для отключения заставки Plymouth. В текстовом инсталляторе улучшена поддержка шифрованных разделов LUKS и логических томов LVM.
- В[chwd](https://github.com/CachyOS/chwd)(CachyOS Hardware Detection) инструментарий intel-lpmd теперь используется только на гибридных процессорах и поддерживает чипы Intel Wildcat Lake. Для Framework Laptop 12 добавлена поддержка планшетного режима.
- В[cachyos-settings](https://github.com/CachyOS/CachyOS-Settings)по умолчанию задействован systemd-oomd с настройками для завершения процессов с учётом объёма данных, вытесненных в раздел подкачки, и снижения вероятности завершения процессов пользовательского сеанса. Ограничено применение отложенной записи для медленных дисков и USB-накопителей. В отчётах об сбоях (cachyos-bugreport) реализовано скрытие конфиденциальных данных, таких как SSID, MAC, IPv6 и UUID.
- [Сформирован](https://wiki.cachyos.org/virtualization/wsl/)образ CachyOS для WSL (Windows Subsystem for Linux).
