# Terraphim - приватный локальный AI-ассистент и поисковый движок по графам знаний

## Краткое содержание

Terraphim — это приватный ИИ-ассистент и движок поиска по графам знаний, полностью работающий на устройстве пользователя. Проект написан на Rust и компилируется в WebAssembly. Индексация, поиск и обход графа выполняются локально: без облака, телеметрии и передачи данных наружу. Код открыт под лицензией Apache 2.0. Разработка ведётся с 2023 года, а за последний год активно привлекается ИИ для самой разработки проекта.

## Полная статья

Представлен[Terraphim](https://terraphim.ai/), приватный AI-ассистент и движок поиска по графам знаний, работающий целиком на устройстве пользователя. Проект написан на Rust и компилируется в WebAssembly: индексация, поиск и обход графа выполняются локально, без облака, без телеметрии и без отправки данных наружу. Код[открыт](https://github.com/terraphim/terraphim-ai)под лицензией Apache 2.0. Разработка[ведётся](https://github.com/terraphim/terraphim-ai/graphs/contributors?all=1)с 2023 года, последний год с привлечением AI.

Вместо нейросетевых векторов используются детерминистические графовые эмбеддинги и сопоставление шаблонов на базе алгоритма[Ахо-Корасик](https://ru.wikipedia.org/wiki/%D0%90%D0%BB%D0%B3%D0%BE%D1%80%D0%B8%D1%82%D0%BC_%D0%90%D1%85%D0%BE_%E2%80%94_%D0%9A%D0%BE%D1%80%D0%B0%D1%81%D0%B8%D0%BA)по ролевым тезаурусам - каждое совпадение прослеживается до понятия в графе знаний и занимает меньше миллисекунды. Один запрос покрывает несколько источников: локальные файлы, Confluence, Jira, Discourse, почту и grepapp.

Для AI-агентов есть MCP-сервер (подключение локальных графов знаний к ассистентам), CLI terraphim-agent (поиск по сессиям Claude Code и Cursor, фиксация ошибок и извлечённых уроков), а также хуки до и после вызова инструментов. Отдельно доступен редактор Terraphim с предложением альтернативных формулировок на основе графа знаний.
