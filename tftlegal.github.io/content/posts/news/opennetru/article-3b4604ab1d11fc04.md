# Браузер Blanc с минималистичной плавающей панелью, созданный с использованием AI

## Краткое содержание

Появился новый веб-браузер Blanc с самобытным минималистичным интерфейсом. Вместо традиционных панелей вкладок и инструментов он использует плавающую панель, объединяющую ввод URL, поиск, переключение вкладок, навигацию и выполнение команд. Авторы объясняют создание браузера желанием вернуть веб-страницам роль главного элемента, устранив лишние нагромождения вроде встроенных ИИ-ассистентов. Код написан на JavaScript на базе платформы Electron и движка Chromium, а распространение осуществляется по лицензии MIT. В процессе разработки активно применялись ИИ-инструменты. Собранные версии доступны для Linux (AppImage), Windows и macOS.

## Полная статья

Доступен новый web-браузер[Blanc](https://blancbrowser.com/), предлагающий самобытный интерфейс с минималистичной плавающей панелью, которая заменяет традиционные панели вкладок и инструментов, и сочетает возможности для ввода URL, поиска, переключения между вкладками, навигации и выполнения команд. В качестве причины создания нового браузера упоминается желание вернуть web-страницам роль первичного элемента, избавившись от излишеств и нагромождений, типа встроенных AI-ассистентов. Код написан на JavaScript с использованием платформы Electron и движка Chromium, и[распространяется](https://github.com/bnfy/blanc)под лицензией MIT. При разработке используются AI-инструменты. Сборки[формируются](https://github.com/bnfy/blanc/releases)для Linux (AppImage), Windows и macOS.

Вкладки показываются в форме выпадающего списка, появляющегося при переключении фокуса на адресную стоку. Поддерживается объединение вкладок в группы, выгрузка содержимого вкладок из памяти без закрытия самих вкладок и показ в одном окне бок о бок двух выбранных вкладок. При наборе в адресной строке "/" появляется список команд, применяемый вместо традиционного меню.

По умолчанию включена блокировка рекламы и трекеров на сетевом уровне, используя списки EasyList и EasyPrivacy. Вкладки в приватном режиме открываются в отдельном сеансе, хранящем все данные только в оперативной памяти. Возможно разделения истории, загрузок, данных сайтов и выданных сайтам полномочий через профили.
