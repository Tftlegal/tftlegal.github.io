# Госучреждения Нидерландов и Франции внедряют решения на базе NixOS

## Краткое содержание

Министерство внутренних дел Нидерландов реализует проект DAWO, направленный на создание суверенной рабочей среды для государственных учреждений и снижение зависимости от иностранных технологических корпораций. В качестве операционной системы для рабочих станций выбран дистрибутив Linux NixOS. Разработкой проекта занимаются три государственные IT-компании: DICTU, SSC-ICT и DUO-ICT. Первый стабильный релиз DAWO ожидается в следующем году, а в пилотном тестировании уже участвуют четыре муниципалитета. Исходный код опубликован на государственной платформе совместной разработки на базе Forgejo, а также зеркалируется на Codeberg и GitHub.

## Полная статья

[Министерство](https://ru.wikipedia.org/wiki/%D0%9C%D0%B8%D0%BD%D0%B8%D1%81%D1%82%D0%B5%D1%80%D1%81%D1%82%D0%B2%D0%BE_%D0%B2%D0%BD%D1%83%D1%82%D1%80%D0%B5%D0%BD%D0%BD%D0%B8%D1%85_%D0%B4%D0%B5%D0%BB_%D0%B8_%D0%BF%D0%BE_%D0%B4%D0%B5%D0%BB%D0%B0%D0%BC_%D0%BA%D0%BE%D1%80%D0%BE%D0%BB%D0%B5%D0%B2%D1%81%D1%82%D0%B2%D0%B0_%D0%9D%D0%B8%D0%B4%D0%B5%D1%80%D0%BB%D0%B0%D0%BD%D0%B4%D0%BE%D0%B2)внутренних дел и по делам Королевства Нидерландов развивает проект[DAWO](https://www.dawo.community/en/about-dawo/)(Digitaal Autonome Werkomgeving Overheid), нацеленный на создание суверенной рабочей среды для государственных учреждений, продвигаемой с целью исключения зависимости от иностранных технологических корпораций. В качестве операционной системы для рабочих станций[выбран](https://code.overheid.nl/MinBZK/DAWO)Linux-дистрибутив[NixOS](https://nixos.org/). В разработку проекта вовлечены три государственные IT-компании - DICTU, SSC-ICT и DUO-ICT. Первый стабильный релиз DAWO ожидается в следующем году. В настоящее время в пилотном внедрении платформы участвуют четыре муниципалитета. Наработки опубликованы на[государственной платформе](https://code.overheid.nl/)совместной разработки,[созданной](https://www.opennet.ru/opennews/art.shtml?num=65316)на базе Forgejo, и зеркалируется в[Codeberg](https://codeberg.org/DAWO/DAWO-Core)и[Github](https://github.com/DAWO-community/DAWO-Core).

Платформу DAWO образуют несколько компонентов:

- Операционная система[DAWO-NixOS](https://code.overheid.nl/MinBZK/DAWO-NixOS)на базе NixOS (отдельно предусмотрен[резервный вариант](https://code.overheid.nl/MinBZK/DAWO-Fedora-Kinoite)на[Fedora Kinoite](https://fedoraproject.org/atomic-desktops/kinoite/)).
- Облачная инфраструктура[DAWO-Cloud](https://code.overheid.nl/MinBZK/DAWO-Cloud).
- Инструменты для организации совместной работы[MijnBureau](https://code.overheid.nl/MinBZK/mijn-bureau-infra)[на базе](https://minbzk.github.io/mijn-bureau-infra/)Nextcloud, Collabora, Element и OpenProject.
- Система идентификации и управления доступом[DAWO-IAM](https://code.overheid.nl/MinBZK/DAWO-IAM).
- Инструменты централизованного развёртывания и управления рабочими станциями[DAWO-Sextant](https://code.overheid.nl/minbzk/dawo-sextant). Для управления мобильными устройствами планируют использовать[Fleet](https://github.com/fleetdm/fleet).
- Мобильная платформа[DAWO-Mobile](https://code.overheid.nl/MinBZK/DAWO-Mobile), в качестве основы для которой рассматриваются[/e/OS](https://www.opennet.ru/opennews/art.shtml?num=66394),[GrapheneOS](https://www.opennet.ru/opennews/art.shtml?num=65703)и[CalyxOS](https://www.opennet.ru/opennews/art.shtml?num=66382).
- AI-ассистент[DAWO-AI](https://code.overheid.nl/MinBZK/DAWO-AI).

Дистрибутив NixOS выбран в качестве основного для рабочих станций из-за декларативной модели конфигурации, поддержки воспроизводимых сборок, возможности работы на устаревших системах, наличия средств для аудита и отката изменений, а также развития сообществом без влияния отдельных корпораций. На выбор NixOS также повлияло то, что курирующая проект NixOS некоммерческая организация зарегистрирована в Нидерландах, а авторы пакетного менеджера Nix и первого варианта дистрибутива имеют голландские корни. В качестве претендентов рассматривались openSUSE и Fedora, но были отклонены из-за влияния на их разработку отдельных компаний.

Похожая инициатива по созданию решения для госорганов на базе NixOS параллельно[запущена](https://news.ycombinator.com/item?id=49842480)во Франции. Проект развивает Межминистерское управление по цифровым делам (DINUM) для обеспечения цифрового суверенитета и независимости от иностранного ПО. Для системных администраторов разработан защищённый вариант дистрибутива -[Securix](https://github.com/cloud-gouv/securix), а для обычных пользователей предлагается использовать шаблон[Bureautix](https://github.com/cloud-gouv/bureautix-example), который различные ведомства могут адаптировать под свои нужды. До конца года намечено пилотное внедрение платформы примерно на 250 рабочих станциях.

В Securix применяется аутентификация с использованием аппаратных ключей (FIDO2, TPM2, YubiKey) и загрузка в режиме UEFI Secure Boot. Bureautix представляет собой вариант Securix, адаптированный для установки на системы обычных пользователей. С целью исключения завязки на сетевую инфраструктуру и недопущение подключения других пользователей к системе принципиально не поддерживается централизованный вход через LDAP или FreeIPA. Для ведения и распространения базы пользователей применяется Git.

Базовое пользовательское окружение[основано](https://github.com/cloud-gouv/bureautix-example/blob/f1463a2712c79919095b4ef5b4798c9cfc6d4eba/common/default.nix#L60)на KDE. На выбор[предлагаются](https://github.com/cloud-gouv/bureautix-example/blob/f1463a2712c79919095b4ef5b4798c9cfc6d4eba/common/tools.nix#L78)офисные пакеты LibreOffice, ONLYOFFICE и WPS Office (+ markdown-редактор Typst), для редактирования кода - neovim и vscodium, для электронной почты - thunderbird, neomutt и aerc, для обмена сообщениями - signal-desktop и element-desktop. В качестве браузера задействован Chromium, для просмотра видео - vlc, для ведения заметок obsidian, для просмотра PDF - xournalpp.
