# Выпуск Wifibox 0.17, окружения для использования WiFi-драйверов Linux во FreeBSD

## Краткое содержание

Вышел выпуск проекта Wifibox 0.17.  
Он решает проблему работы беспроводных адаптеров в FreeBSD, для которых отсутствуют нужные драйверы.  
Wifibox обеспечивает их работу за счёт запуска гостевой Linux-системы.  
В этой системе загружаются нативные Linux-драйверы для беспроводных устройств.  
Подобный подход потенциально подходит для любых WiFi-карт, поддерживаемых в Linux.  
Решение протестировано на чипах Intel, AMD/MediaTek, Realtek, Qualcomm и Broadcom.

## Полная статья

[Доступен](https://github.com/pgj/freebsd-wifibox/releases/tag/0.17.0)выпуск проекта[Wifibox 0.17](https://github.com/pgj/freebsd-wifibox/), нацеленного на решение проблемы с использованием во FreeBSD беспроводных адаптеров, для которых отсутствуют необходимые драйверы. Работа проблемных для FreeBSD адаптеров в Wifibox обеспечивается через запуск гостевой системы с Linux, в которой загружаются родные для Linux драйверы беспроводных устройств. Окружение потенциально может применяться для любых WiFi-карт, поддерживаемых в Linux, и протестировано на чипах Intel, AMD/MediaTek, Realtek, Qualcomm и Broadcom.

Установка гостевой системы с драйверами автоматизирована, а все необходимые компоненты оформлены в виде готового пакета[wifibox](https://cgit.freebsd.org/ports/tree/net/wifibox), который запускается при загрузке при помощи поставляемого в комплекте rc-сервиса. Гостевая система запускается при помощи гипервизора Bhyve, в котором организуется проброс доступа к беспроводной карте. Для работы требуется система с поддержкой аппаратной виртуализации (AMD-Vi или Intel VT-d). Начинка гостевой системы основана на дистрибутиве Alpine Linux, построенного на базе системной библиотеки Musl и набора утилит BusyBox.

Для подключения к беспроводной сети используется пакет wpa_supplicant, файлы конфигурации для которого синхронизируются с настройками из основного окружения FreeBSD. Создаваемый для wpa_supplicant управляющий Unix-сокет пробрасывается в хост-окружение, что позволяет использовать штатные утилиты FreeBSD для подключения и работы с беспроводной сетью, такие как wpa_cli и wpa_gui (net/wpa_supplicant_gui).

В новом выпуске[прекращено](https://github.com/pgj/freebsd-wifibox/pull/169)использование для загрузки grub-bhyve, оставлена только возможность запуска гостевых систем с поддержкой UEFI.[Прекращено](https://github.com/pgj/freebsd-wifibox/pull/172)использование сетевых мостов (для корректной работы во FreeBSD 15 сетевой интерфейс tap теперь используется напрямую без заворачивания через интерфейс bridge). Прекращена поддержка ветки FreeBSD 13. Обеспечено завершение управляющего процесса в случае завершения выполнения гостевой системы.
