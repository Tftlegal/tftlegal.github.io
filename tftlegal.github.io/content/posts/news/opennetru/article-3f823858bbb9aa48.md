# Релиз Ubuntu 26.10

## Краткое содержание

Вышел релиз дистрибутива Ubuntu 26.10 под кодовым названием «Stonking Stingray». Данный выпуск относится к категории промежуточных релизов. Поддержка и обновления для него формируются в течение 9 месяцев. Готовые образы доступны для основной редакции Ubuntu, Ubuntu Server, Lubuntu, Kubuntu, Ubuntu Mate, Ubuntu Budgie, Ubuntu Studio и Xubuntu. Отдельно представлены Ubuntu Kylin (специальная редакция для Китая), Ubuntu Unity, Edubuntu и Ubuntu Cinnamon. Всего насчитывается более десяти вариантов дистрибутива.

## Полная статья

[Представлен](https://lists.ubuntu.com/archives/ubuntu-announce/2026-October/000330.html)релиз дистрибутива[Ubuntu 26.10](https://ubuntu.com/download/desktop)"Stonking Stingray", который отнесён к промежуточным выпускам, обновления для которых формируются в течение 9 месяцев. Готовые образы созданы для[Ubuntu, Ubuntu Server](https://releases.ubuntu.com/26.10/),[Lubuntu](http://cdimage.ubuntu.com/lubuntu/releases/26.10/),[Kubuntu](http://cdimage.ubuntu.com/kubuntu/releases/26.10/),[Ubuntu Mate](http://cdimage.ubuntu.com/ubuntu-mate/releases/26.10/),[Ubuntu Budgie](http://cdimage.ubuntu.com/ubuntu-budgie/releases/26.10/),[Ubuntu Studio](http://cdimage.ubuntu.com/ubuntustudio/releases/26.10/),[Xubuntu](http://cdimage.ubuntu.com/xubuntu/releases/26.10/),[UbuntuKylin](https://ubuntukylin.com/index-en.html)(редакция для Китая),[Ubuntu Unity](http://cdimage.ubuntu.com/ubuntu-unity/releases/26.10/),[Edubuntu](http://cdimage.ubuntu.com/edubuntu/releases/26.10/)и[Ubuntu Cinnamon](http://cdimage.ubuntu.com/ubuntucinnamon/releases/26.10/).

Основные[изменения](https://documentation.ubuntu.com/release-notes/26.10/):

- Рабочий стол обновлён до выпуска[GNOME 51](https://www.opennet.ru/opennews/art.shtml?num=66292), в котором предложены оптимизации для повышения плавности вывода и исключения подвисаний во время анимации и при большой нагрузке на систему.[

- Обновлены версии пакетов, включая ядро Linux 7.3-rc6, GCC 15.2.0, LLVM 22.1.6, systemd 261.3, APT 3.3.3, Python 3.14.7, .NET 10.0.112, Go 1.27, PHP 8.5.9, OpenJDK 25.0.4, Rust 1.97.1, Zig 0.16, OpenSSL 4, Mesa 26.2, LibreOffice 26.8.
- Обновлены серверные пакеты: Postfix 3.11.7, Samba 4.24.7, MySQL 9.7.2, FreeRADIUS 3.2.10, FRRouting 10.7.1, HAProxy 3.4.2, iPXE 2.0.0, Valkey 9.1.2, strongswan 6.0.7, cloud-init 26.2, apache httpd 2.4.68, OpenLDAP 2.6.13.
- [Осуществлён](https://www.opennet.ru/opennews/art.shtml?num=66274)полный переход на инструментарий[uutils coreutils](https://github.com/uutils/coreutils/)(Rust Coreutils), написанный на языке Rust. Утилиты из состава Rust Coreutils полностью заменили все компоненты пакета[GNU Coreutils](https://gnu.org/s/coreutils), включая утилиты cp, mv и rm, которые в Ubuntu 26.04 поставлялись в варианте из GNU Coreutils.
- Обеспечена официальная поддержка пакета[Sequoia PGP](https://www.opennet.ru/opennews/art.shtml?num=62421)с реализацией стандарта OpenPGP на языке Rust. В настоящий момент пакет включён в основной репозиторий, но доступен в качестве опции. В будущем намерены перейти по умолчанию на PGP-инструментарий Sequoia, заменив утилиты gpg и gpgv на sq и sqv.
- При использовании Sequoia вместо GnuPG реализована поддержка применения постквантовых алгоритмов для верификации цифровых подписей APT-репозитория. Добавлена поддержка токенов, стойких к подбору на квантовых компьютерах (программные, EP11 и CCA токены с интеграцией поддержки алгоритмов ML-DSA и ML-KEM), реализованная при помощи библиотеки[openCryptoki](https://github.com/opencryptoki/opencryptoki).
- OpenSSH разделён на два пакета - openssh и openssh-gssapi, которые отличаются включением поддержки GSSAPI/Kerberos при сборке. В пакете openssh-gssapi поставляется фоновый процесс openssh-gssapi-server и утилиты openssh-gssapi-client, поддерживающие GSSAPI. По умолчанию в новых установках предлагается openssh, а при обновлении пакет выбирается в зависимости от наличия настроек GSSAPI в файле конфигурации. Разделение произведено для снижения поверхности атаки, так как поддержка GSSAPI реализована в форме внешнего патча, не принятого в основной состав OpenSSH и сомнительного с точки зрения безопасности (весной в патче была[выявлена](https://www.opennet.ru/opennews/art.shtml?num=64983)удалённая уязвимость), при том, что поддержка GSSAPI нужна лишь очень небольшому числу пользователей.
- Сформированы сборки Ubuntu Desktop для архитектуры RISC-V. Обеспечена официальная поддержка плат на базе архитектуры RISC-V - SpacemiT K3 (Pico-ITX, CoM260 kit) и SiFive BigSky.
- Добавлена начальная поддержка ноутбуков на ARM-чипах[Qualcomm Snapdragon X2](https://www.opennet.ru/opennews/art.shtml?num=66334).
- [Предложена](https://www.opennet.ru/opennews/art.shtml?num=66452)для начального тестирования возможность голосового ввода текста с использованием развиваемой компанией Canonical системы распознавания речи[Myna](https://www.opennet.ru/opennews/art.shtml?num=65709). Сеанс работы с приложением сводится к активации через клавиатурную комбинацию, диктовки вслух и вставки распознанного текста в текущее приложение через симуляцию клавиатурного ввода по мере его произнесения. Для распознавания на выбор могут использоваться AI-модели Whisper, Parakeet или Funasr, выполняемые локально. Из компонентов в базовую поставку пока включено только дополнение к GNOME Shell - Myna Shell, а конфигуратор и AI-модели поставляются отдельной через PPA-репозиторий[myna-config](https://launchpad.net/~charles05/+archive/ubuntu/myna-config)и snap-пакеты[myna](https://snapcraft.io/myna),[myna-whisper](https://snapcraft.io/myna-whisper),[myna-parakeet](https://snapcraft.io/myna-parakeet)и[myna-funasr](https://snapcraft.io/myna-funasr).[

- В качестве применяемой по умолчанию реализации шины D-Bus вместо dbus-daemon задействован dbus-broker. D-Bus Broker реализован в пространстве пользователя, но использует для ускорения подсистемы ядра Linux, сохраняет совместимость с эталонной реализацией D-Bus и может быть использован для прозрачной замены dbus-daemon. D-Bus Broker учитывает ресурсы в привязке к пользователям и включает оптимизации для повышения производительности и надёжности (например, сообщение не может быть потеряно без обработки ошибки).
- Механизм обработки ситуаций нехватки памяти в системе (OOM)[переработан](https://discourse.ubuntu.com/t/improving-ubuntu-desktop-stability-under-memory-pressure/87945)для предотвращения аварийного завершения всего десктоп-сеанса (для ключевых десктоп-процессов снижен приоритет, влияющий на выбор претендентов для принудительного завершения с целью высвобождения памяти).
- [Сформированы](https://cdimages.ubuntu.com/ubuntu/stonking/daily-live/current/)экспериментальные установочные образы Ubuntu Desktop 26.10 с пакетами,[собранными](https://www.opennet.ru/opennews/art.shtml?num=64155)с оптимизациями для архитектуры x86-64-v3. Третья версия микроархитектуры x86-64 (x86-64-v3) применяется в процессорах Intel примерно с 2015 года (начиная с Intel Haswell) и отличающейся наличием расширений AVX, AVX2, BMI2, FMA, LZCNT, MOVBE и SXSAVE. Прирост производительности при сборке с оптимизациями для архитектуры x86-64-v3 в большинстве случаев составляет примерно 1%, но в отдельных ситуациях в приложениях с интенсивными вычислениями может наблюдаться более заметное повышение производительности.
- В поставляемое по умолчанию GNOME-дополнение[Tiling Assistant](https://extensions.gnome.org/extension/7065/tiling-shell/)добавлен интерактивный режим выбора раскладки окон - при перетаскивании окна мышью в верхней части экрана появляется плавающая панель-подсказка с вариантами мозаичной компоновки.
- [Добавлена](https://canonical.com//blog/ubuntu-26-10-security)опциональная поддержка NTP-сервера[ntpd-rs](https://github.com/pendulum-project/ntpd-rs), написанного на языке Rust. По умолчанию ntpd-rs планируют задействовать в выпуске Ubuntu 27.04. Проект ntpd-rs станет третьим компонентом, после Rust Coreutils и sudo-rs, интегрированным в Ubuntu в рамках инициативы по повышению качества системного окружения через поставку программ, изначально разрабатываемых с оглядкой на безопасность, надёжность и корректность.
- В заверенных цифровой подписью сборках загрузчика GRUB, применяемого на системах с UEFI Secure Boot, удалена поддержка форматов изображений jpeg и png, таблиц разделов part_appleа и возможности использования для раздела /boot LVM, md-raid (кроме raid1), шифрованных разделов LUKS и ФС btrfs, hfsplus, xfs и zfs. Отмечается, что в инсталляторе Ubuntu для /boot всегда используется только ФС ext4, а другие системы не тестируются и представляют угрозу обхода режима верифицированной загрузки на фоне периодического выявления уязвимостей в GRUB.
- Расширены возможности по использованию[полнодискового шифрования](https://www.opennet.ru/opennews/art.shtml?num=59728), не требующего ввода пароля разблокировки диска при загрузке, благодаря хранению информации для расшифровки ключей в TPM (Trusted Platform Module). Добавлена поддержка оборудования без заслуживающих доверия аппаратных компонентов (RoT, Root of Trust), на которых пользователи могут активировать проверку по PIN-коду или паролю в дополнение к ключу, хранимому в TPM.
- Добавлена поддержка процессоров на базе микроархитектуры Intel Xe3P (Nova Lake) и AMD Zen 6. Добавлена поддержка ноутбуков на чипах Snapdragon X2 Elite, таких как Asus Zenbook A14 (UX3407NA), HP EliteBook X G2q 14 AI и Lenovo Yoga Slim 7x Gen 11, а также на чипах Snapdragon X Elite и X Plus - Lenovo IdeaCentre Mini 01Q8X10 (Snapdragon X Plus model), Lenovo IdeaPad Slim 5x 14Q8X9, HP EliteBook 6 G1q, Acer Swift 14 AI (SF14-11) и Acer Swift Go 14 AI (SFG14-01).
- Реализована поддержка из коробки кластерной файловой системы Lustre (модуль ядра для ФС Lustre теперь собирается по умолчанию).
- В репозиторий добавлены пакеты со стеком[AMD ROCm 10.0](https://www.amd.com/en/products/software/rocm.html)для высокопроизводительных вычислений (HPC) и задействования GPU для ускорения работы AI-систем.
- В менеджере приложений (App Center) унифицировано отображение детальной информации о пакетах в форматах Snap и Deb, включающей такие сведения, как разработчик, рейтинг, права доступа, версия, размер пакета, скриншоты и описание. Добавлена отдельная страница управления драйверами, на которой показаны доступные графические драйверы, включая проприетарные драйверы NVIDIA. Реализована возможность установки недостающих кодеков по мере необходимости - при первой попытке воспроизведения связанного с ними контента.
- Администраторам предоставлена возможность отключения сбора телеметрии (Ubuntu Insights) для всей системы, переопределяя настройки отдельных пользователей (если ранее пользователь дал согласие на сбор телеметрии, она всё равно будет отключена).
- Удалена поддержка скриптов System V - компонент systemd-sysv-generator, применявшийся для генерации systemd-сервисов из скриптов /etc/init.d, больше не входит в поставку.
- В[Kubuntu](https://kubuntu.org/news/kubuntu-26-10-release-notes/)задействованы выпуски[KDE Plasma 6.7](https://www.opennet.ru/opennews/art.shtml?num=65698),[KDE Gear 26.08](https://www.opennet.ru/opennews/art.shtml?num=66105), KDE Frameworks 6.29.0 и Qt 6.11.2. По умолчанию предложен сеанс на базе протокола Wayland. Пакет "plasma-session-x11", обеспечивающий работу сеанса X11, не включён в основную поставку и объявлен не поддерживаемым, но может быть отдельно установлен из репозитория. В выпуске Kubuntu 27.04 намерены полностью прекратить поддержку X11, следом за[удалением](https://www.opennet.ru/opennews/art.shtml?num=64328)поддержки X11 в выпуске KDE Plasma 6.8.
- В[Ubuntu Studio](https://ubuntustudio.org/2026/10/ubuntu-studio-26-10-released/)в инсталляторе реализован минимальный режим установки, позволяющий установить только необходимый базовый набор специфичных пакетов (тема оформления, настройки звука, оптимизированные настройки), а мультимедийные программы инсталлировать по отдельности. Возможна установка категорий программ: звук, видео, графика, обработка фотографий и т.п., и отдельный выбор рекомендованных зависимостей для каждого пакета. Для пользователей других редакций Ubuntu предоставлена возможность использовать пакет[ubuntu-studio-installer](https://ubuntustudio.org/ubuntu-studio-installer)для установки предоставляемых в Ubuntu Studio настроек, пакетов и категорий программ.

Переделан интерфейс настройки звука, который теперь оформлен как одно окно с вкладками. Предоставлена возможность установки отдельного приложения для настройки PipeWire. Добавлены новые приложения для работы со звуком: Sonic Pi, SuperCollider и JNoise, а также набор плагинов SuperCollider 3. Обновлены версии: OBS Studio 32.2.2, FreeShow 1.6.5, QPrompt 2.0.2, RaySession 0.18.0, Patchance 1.4.0, DistroAV 6.2.1, Kdenlive 26.08.1, Krita 6.0.3, GIMP 3.2.6, Ardour 9.8.0, Scribus 1.6.6, Audacity 3.7.8.

- В[Lubuntu](https://lubuntu.me/)задействован выпуск среды рабочего стола[LXQt 2.4](https://www.opennet.ru/opennews/art.shtml?num=65246). Предложен экспериментальный сеанс на базе Wayland, реализованный с использованием дисплейного сервера Mir и композитного менеджера[Miriway](https://miriway.github.io/). Протокол X11 продолжает применяться по умолчанию и прекращать его поддержку в данный момент не планируют, но при этом реализация экрана входа в систему переведена на Miriway и Wayland.
- [Возобновлена](https://ubuntu-mate.org/blog/ubuntu-mate-stonking-stingray-release-notes/)публикация выпусков Ubuntu MATE. Часть компонентов рабочего стола MATE обновлена до последних версий, перенесены исправления ошибок.
- В[Ubuntu Cinnamon](https://ubuntucinnamon.org/ubuntu-cinnamon-26-10-stonking-stingray-released/)задействован выпуск среды рабочего стола[Cinnamon 6.6.9](https://www.opennet.ru/opennews/art.shtml?num=64408).
- В[Xubuntu](https://xubuntu.org/news/releases/26.10/2026-10-15-xubuntu-26-10-released/)продолжает поставляться выпуск Xfce 4.20, в который перенесли накопившиеся исправления. Повышена стабильность работы при использовании Wayland. Обновлены версии Ristretto 0.14.0, Xfce Screenshooter 1.11.3, Xfce Terminal 1.2.0, Xfce Power Manager 4.20.1.[

Упрощено перемещение апплетов на рабочем столе. Добавлен новый виджет для поиска и прослушивания интернет-радиостанций. Предоставлена опциональная возможность запуска Budgie поверх композитного сервера[wayfire](https://www.opennet.ru/opennews/art.shtml?num=65986).[
