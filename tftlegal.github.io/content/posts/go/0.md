# Функции в GO

Давайте разберем **Функции** в GO  — это фундаментальная часть любого языка, и в Go они очень понятны.

### 🌊 Что такое Функция? (Простыми словами)

Представьте, что вы хотите что-то сделать много раз, но каждый раз вы хотите, чтобы процесс был **повторяемым** и **правильно структурированным**.

**Функция — это по сути "готовый к исполнению блок инструкций"**. Это рецепт, который вы можете использовать много раз, чтобы добиться одного и того же результата, не переписывая код.

**Пример:** Если вам нужно посчитать налог за 100 разных чеков, вы не будете писать 100 раз "Найти Налог". Вы напишете одну функцию `CalculateTax(amount)` и будете вызывать её 100 раз.


### 🛠️ Как работают функции в Go?

В Go функция — это просто именованная блок кода, который **принимает входные данные** (Аргументы) и **может вернуть результат** (Возвращаемое значение).

#### ⚙️ Основные правила работы:

1.  **Обязательное объявление:** Вы всегда должны объявлять функцию с помощью ключевого слова `func`.
2.  **Параметры (Вход):** Вы передаете данные в функцию через аргументы.
3.  **Возврат (Выход):** Функция возвращает результат. В Go мы **явно** указываем, что функция возвращает, даже если ничего не возвращает (в этом случае мы возвращаем `(nil)` или пустую структуру).

### 🐍 Особенности Go в контексте функций

Говоря о функциях, у Go есть очень важные и особенные черты, которые стоит знать:

**1. Многовозвратности (Multiple Returns):**
В Go очень распространено возвращать сразу несколько значений (особенно ошибки).

**2. Присвоение (Assignment) и Ошибки:**
Мы **никогда** не используем `if (переменная)` как в других языках. Мы проверяем **возвращаемую ошибку** (`err`)!

**3. Функции как значения (First-Class Functions):**
Это самая мощная особенность! Вы можете присвоить функцию переменной, передать её в другую функцию или вернуть её из другой функции.

### 💻 Примеры с понятными объяснениями

#### Пример 1: Простая функция (Без ошибок)

**Что делать:** Простой калькулятор.
```go
// Функция, которая складывает два числа
func Add(a int, b int) int {
    // Мы просто складываем аргументы, которые пришли в функцию
    return a + b
}

func main() {
    // Вызов функции
    result := Add(5, 3) 
    fmt.Println("Результат:", result) // Вывод: Результат: 8
}
```

#### Пример 2: Функция с ошибкой (Самая важная особенность Go)

**Что делать:** Разделить число, но что делать, если вы пытаетесь разделить на ноль?
В Go мы всегда возвращаем два значения: `(результат, ошибка)`.

```go
// Функция, которая пытается разделить число
func Divide(numerator float64, denominator float64) (float64, error) {
    if denominator == 0 {
        // Если делитель равен 0, мы возвращаем 0 и ошибку
        return 0, fmt.Errorf("Деление на ноль невозможно!")
    }
    // Если все хорошо, мы возвращаем результат и nil (успех)
    return numerator / denominator, nil 
}

func main() {
    // --- 1. Успешный вызов ---
    res, err := Divide(10, 2)
    if err != nil {
        // Здесь мы ловим ошибку
        fmt.Println("Ошибка:", err)
    } else {
        fmt.Println("Успех:", res) // Вывод: Успех: 5
    }

    // --- 2. Неудачный вызов ---
    res, err = Divide(10, 0)
    if err != nil {
        fmt.Println("Поймана ошибка:", err) // Вывод: Поймана ошибка: Деление на ноль невозможно!
    }
}
```
**Объяснение:** Мы не можем просто проверить, равен ли `err` нулю. Мы используем `if err != nil`. Это стандартный и очень важный паттерн Go!

#### Пример 3: Функции как значения (Высокоуровневая особенность)

**Что делать:** Мы можем создать функцию, которая будет "принимать" другую функцию.

```go
// 1. Определим функцию, которая принимает другой аргумент (это будет наша "условная" функция)
func executeAction(action func(int)) {
    fmt.Println("--- Начинаем выполнение...")
    // Мы вызываем функцию, которую передали
    action(5) 
    fmt.Println("--- Завершено.")
}

// 2. Создадим нашу конкретную функцию
func printStep(data int) {
    fmt.Printf("Шаг: %d\n", data)
}

func main() {
    // Мы передаем функцию printStep как аргумент в executeAction
    executeAction(printStep)
}
```
**Что здесь происходит?** Мы передали `printStep` не как данные, а как **команда**. `executeAction` просто "запомнила" эту команду и выполнила её. Это называется **"обрабатывать функцию"** или **"функциональное программирование"**.

### 📚 Вывод

Функции в Go — это чистый, минималистичный набор блоков. Главный особенный момент Go — это **явное управление ошибками**
