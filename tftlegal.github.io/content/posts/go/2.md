# Gnerics

**Дженерики (Generics) в Go — это способ написать код, который работает с любым типом данных, но при этом остается типобезопасным.**

### 🤯 Проблема, которую решают дженерики

Представьте, что вам нужно написать функцию, которая принимает список, и вы хотите, чтобы эта функция могла работать как с целыми числами (`[]int`), так и с числами с плавающей точкой (`[]float64`).

**До дженериков (или без них),** вам бы пришлось писать три версии этой функции: одну для `int`, одну для `float64`, третью для `string`, и так далее. Это очень много дублирования кода!

**Дженерики позволяют вам написать одну универсальную функцию, которая работает для *любого* типа данных, который вы ей передадите.**


### 🎯 Что такое дженерики? (Простыми словами)

Дженерики позволяют вам писать **один раз** код, который будет работать **многократно** для разных типов данных.

Если бы вы хотели создать функцию для суммирования двух чисел:
*   **Без дженериков:** Вы должны писать: `addInt(a, b) -> a + b` и `addFloat(a, b) -> a + b`.
*   **С дженериками:** Вы пишете: `add[T any](a, b) -> a + b`. Вы используете `T` (тип-заполнитель) вместо конкретного типа.

### 🛠️ Как это выглядит на практике? (Примеры)

В Go мы используем **"типы-заполнители"** (Type Parameters). Мы объявляем их с помощью конструкции `[T any]` или `[T comparable]` и т.д.

#### 💡 Пример 1: Универсальная функция "Получить Максимум"

Предположим, мы хотим функцию, которая сравнивает два числа и возвращает большее.

```go
// T any означает, что T может быть любым типом данных, который 
// соответствует минимальным требованиям (в данном случае, что-либо).

func max[T any](x, y T) T {
    if x > y {
        return x
    }
    return y
}

func main() {
    // Используем с int
    resultInt := max(10, 5) // Работает идеально!
    fmt.Println(resultInt) 
    
    // Используем с float64
    resultFloat := max(3.14, 2.71) // Работает идеально!
    fmt.Println(resultFloat)
}
```
**Что здесь произошло?** Мы написали код один раз, но благодаря `[T any]`, он может работать с `int`, `float64` и другими типами, пока они удовлетворяют базовому требованию (например, что они сравнимы, т.е. `comparable`).

#### 💡 Пример 2: Универсальная функция "Найти Максимум" (С учетом ограничений)

Если бы мы писали функцию, которая требует, чтобы тип данных был, например, "сравнимым" (`comparable`), мы бы использовали ограничение в синтаксисе.

```go
// T comparable означает, что тип T должен быть сравнимым (можно ли сравнить x и y)
func findMax[T comparable](x, y T) T {
    if x > y {
        return x
    }
    return y
}

func main() {
    // Работает для int, потому что int сравнимы
    i := findMax(5, 10) 
    fmt.Println(i)
}
```

### 🔑 Резюме для запоминания

1.  **Проблема:** Дублирование кода для разных типов.
2.  **Решение:** Дженерики.
3.  **Как это работает:** Вы используете **"заполнитель"** (`[T any]`), который заменяет конкретный тип данных, который вы используете в коде.
4.  **Преимущество:** Код становится **очень кратким**, потому что вы пишете один универсальный шаблон, который работает для множества типов.

Дженерики делают код **более гибким** и **более надежным** (потому что компилятор сам проверяет, что вы используете тип правильно).
