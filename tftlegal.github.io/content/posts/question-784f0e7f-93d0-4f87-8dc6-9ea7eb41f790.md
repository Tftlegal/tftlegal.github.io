## 🚀 Этап 1: Фундамент и Подготовка Среды

**Цель:** Обеспечить, что контрольная машина (Ansible Control Node) и целевые хосты (Target Nodes) готовы к безопасной и автоматизированной коммуникации.

### 1.1. Контрольная Машина (Ansible Control Node)
Установите Ansible. **Критически важно:** Убедитесь, что у вас есть SSH-ключи, настроенные для бесклюрового входа на целевые хосты.

```bash
# Для Ubuntu/Debian
sudo apt update
sudo apt install ansible -y

# Проверка SSH-ключей (Убедитесь, что ваш публичный ключ в authorized_keys на целевых серверах)
ssh-keygen -t rsa -b 4096
ssh-copy-id user@clickhouse_server
ssh-copy-id user@mongodb_server
```

### 1.2. Определение Инвентаризации (Inventory File)
Мы должны явно указать Ansible, какие хосты существуют и какие роли им присвоены. Создайте файл `inventory.ini` на вашей контрольной машине.

**`inventory.ini`:**
```ini
[db_servers]
clickhouse_server ansible_host=192.168.1.10
mongodb_server ansible_host=192.168.1.20

[clickhouse_cluster]
clickhouse_server

[mongodb_cluster]
mongodb_server

[all:vars]
ansible_user=your_ssh_username  # <-- ЗАМЕНИТЬ!
ansible_ssh_private_key_file=~/.ssh/id_rsa # <-- ЗАМЕНИТЬ, если используете другой ключ
```

### 1.3. Подготовка Целевых Хостов (Target Nodes)
На `clickhouse_server` и `mongodb_server` убедитесь, что установлены базовые утилиты, необходимые для работы Ansible (например, `wget`, `curl`, `epel-release` для RHEL, или `apt` для Debian).

**💡 Ключевой Момент:** Мы **автоматизируем** установку БД, но убедитесь, что ОС имеет доступ к интернету для загрузки репозиториев.
