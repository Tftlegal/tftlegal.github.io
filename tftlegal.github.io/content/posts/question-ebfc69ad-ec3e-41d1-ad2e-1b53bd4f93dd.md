# Руководство по установке AWX для автоматизации Ansible

**AWX** — это корпоративная платформа для управления Ansible, предоставляющая веб-интерфейс, систему управления очередями (Task Engine) и API. Современная установка AWX базируется на **AWX Operator** внутри кластера Kubernetes.

---

## Шаг 1: Подготовка инфраструктуры

Для стабильной работы AWX рекомендуется использовать выделенный сервер (VPS/Dedicated) со следующими характеристиками:
*   **CPU:** Минимум 2 ядра (рекомендуется 4+).
*   **RAM:** Минимум 4 ГБ (рекомендуется 8 ГБ+).
*   **ОС:** Ubuntu 22.04 LTS или RHEL/AlmaLinux 9.
*   **Базовое ПО:** Установленный Docker и `kubectl`.

**Важно:** AWX требует наличия кластера Kubernetes. Для простых задач рекомендуется использовать **K3s** или **MicroK8s**.

---

## Шаг 2: Установка Kubernetes (K3s)

Если у вас еще нет кластера, установите K3s (легковесный Kubernetes):

```bash
curl -sfL https://get.k3s.io | sh -
# Проверьте статус
sudo kubectl get nodes
```
*Примечание: Чтобы использовать kubectl без sudo, добавьте пользователя в группу или настройте конфиг.*

---

## Шаг 3: Установка AWX Operator

AWX Operator — это контроллер, который управляет жизненным циклом установки AWX.

1.  **Установите необходимые зависимости (cert-manager):**
    AWX требует `cert-manager` для управления сертификатами.
    ```bash
    kubectl apply -f https://github.com/cert-manager/cert-manager/releases/download/v1.11.0/cert-manager.yaml
    ```

2.  **Установите сам Operator:**
    ```bash
    kubectl apply -f https://github.com/ansible/awx-operator/releases/latest/download/awx.yml
    ```

3.  **Проверьте статус установки:**
    ```bash
    kubectl get pods -n awx -w
    ```

---

## Шаг 4: Развертывание экземпляра AWX

Теперь, когда оператор запущен, нужно создать сам экземпляр AWX с помощью YAML-манифеста.

1.  **Создайте файл `awx.yml`** (создайте его в текущей директории):
    ```yaml
    apiVersion: awx.ansible.com/v1beta1
    kind: AWX
    metadata:
      name: awx-instance
      namespace: awx
    spec:
      service_type: NodePort
    ```

2.  **Примените манифест:**
    ```bash
    kubectl apply -f awx.yml
    ```

3.  **Ожидайте развертывания:**
    Процесс может занять 5-10 минут. Следите за прогрессом:
    ```bash
    kubectl get pods -n awx -w
    ```

---

## Шаг 5: Настройка доступа и сети

1.  **Определение портов:**
    Так как мы использовали `NodePort`, AWX будет доступен на случайном порту в диапазоне 30000-32767. Узнайте его:
    ```bash
    kubectl get svc -n awx
    ```

2.  **Настройка Firewall:**
    Откройте соответствующий порт (например, 30080) в системном фаерволе:
    ```bash
    # Для Ubuntu (UFW)
    sudo ufw allow 30080/tcp
    # Для CentOS/RHEL (Firewalld)
    sudo firewall-cmd --add-port=30080/tcp --permanent
    sudo firewall-cmd --reload
    ```

---

## Шаг 6: Первичная настройка интерфейса

1.  **Вход в систему:** Откройте браузер и перейдите по адресу `http://<IP_вашего_сервера>:30080`.
2.  **Учетные данные:** По умолчанию логин — `admin`. Пароль можно получить командой:
    ```bash
    kubectl get secret awx-instance-admin-password -n awx -o jsonpath="{.data.password}" | base64 --decode
    ```
3.  **Импорт данных:**
    *   **Inventories:** Загрузите списки ваших серверов.
    *   **Credentials:** Добавьте SSH-ключи или пароли для доступа к хостам.
    *   **Project:** Подключите ваш Git-репозиторий с Ansible-плейбуками.

---

## Шаг 7: Создание Job Templates

Для запуска автоматизации:
1.  Перейдите в раздел **Templates**.
2.  Нажмите **Add** и выберите ваш проект и плейбук.
3.  Нажмите **Launch**, чтобы запустить выполнение. Вы сможете видеть лог выполнения в реальном времени.
